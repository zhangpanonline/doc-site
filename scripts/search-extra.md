# 岗位市场情报

站内岗位地图「市场情报」页面的术语与口径说明（数据来源：BOSS 直聘 / 前程无忧 / 猎聘）。

## 薪资分位数与箱线图

- P10 / P25 / P50 / P75 / P90 是分位数：P50 即中位数，表示一半样本的薪资低于该值，一半高于该值。
- 例：某城市 P50 为 18 表示该城市一半岗位的薪资中点不高于 18K/月。
- P10 是低分位（约一成样本低于它），P90 是高分位（约一成样本高于它）；P10-P90 区间可视为该城市岗位薪资的主流区间。
- 箱线图展示的是各城市薪资中点的分布（P10/P25/P50/P75/P90 五个分位点），不是单个岗位的薪资。
- 所有薪资口径均为「K/月」。

## 样本与统计口径

- 每城市样本不足 20 份时不绘制箱线图，显示「待扩充」。
- BOSS 直聘的城市样本分布偏斜（西安为主），样本不足的城市显示「待扩充」；不同城市的样本量不同，样本少的城市统计值波动更大。
- 前程无忧（51job）没有技能标签字段，技术栈词频统计仅来自 BOSS 直聘岗位的技能标签。
- 城市在图表中按样本数降序排列；经验 / 学历 / 行业分桶按分桶本身的自然顺序排列。
- 「规则表」记录职类 × 领域的技术栈命中规则（cube_rules），趋势快照存放在 trends/ 目录。

## 学习路线与技能矩阵

- 学习路线分阶段：AI Agents → 后端 → DevOps → AI 编程 → 全栈。
- 策划技能 × 岗位矩阵的递进规则：第 N 阶段的技能 = 本阶段新增 + 前序所有阶段的技能（继承）。
- 「新增」表示该技能在本阶段首次引入，「继承」表示沿用前序阶段已学技能。
