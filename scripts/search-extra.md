# 岗位地图数据口径

站内「岗位地图」页（/jobs）的术语与口径说明（数据来源：BOSS 直聘 / 前程无忧 / 猎聘）。

## 薪资分位数与区间条

- P10 / P25 / P50 / P75 / P90 是分位数：P50 即中位数，表示一半样本的薪资低于该值，一半高于该值。
- 例：某城市 P50 为 18 表示该城市一半岗位的薪资中点不高于 18K/月。
- P10 是低分位（约一成样本低于它），P90 是高分位（约一成样本高于它）；P10-P90 区间可视为该城市岗位薪资的主流区间。
- 城市对比视图里，粗条 = P25–P75（中间一半岗位的落点），细条 = P10–P90，竖线 = 中位数。
- 所有薪资口径均为「K/月」。

## 样本与统计口径

- 每个城市样本不足 20 份时不给结论，折叠进「更多城市」。
- BOSS 直聘按城市轮换采集，不同城市样本量不同；样本少的城市统计值波动更大。
- 前程无忧（51job）没有技能标签字段，技能词频统计仅来自 BOSS 直聘岗位的技能标签。
- 「在招岗位」指当前池中的有效样本数，不等于全市场岗位总量；每个岗位取月薪区间中点再求分位数。

## 学习路线与技能矩阵

- 学习路线分阶段：AI Agents → 后端 → DevOps → AI 编程 → 全栈。
- 策划技能 × 岗位矩阵的递进规则：第 N 阶段的技能 = 本阶段新增 + 前序所有阶段的技能（继承）。
- 「新增」表示该技能在本阶段首次引入，「继承」表示沿用前序阶段已学技能。
