知识速览

先花几分钟把核心机制过一遍——细节都在《11.装饰器》里，测验和考核会考。

本质与语法糖

func ─ 传入 ─▶ decorator ─ 返回 ─▶ wrapper（替代原函数）

⚙️ @my_decorator 等价于 say_hello = my_decorator(say_hello)——装饰器在定义时就执行，wrapper 在调用时才执行。

三个要点

  1. wrapper 要接住参数并返回结果：用 def wrapper(*args, **kwargs) 接收任意参数，并 return func(*args, **kwargs) 把原函数的结果传出去——丢了 return，被装饰函数的返回值就变成 None。
  2. 叠加顺序：从下到上应用，从上到下包裹：@a @b 等价于 func = a(b(func))，调用时 a 的外层逻辑最先执行。官方文档：Function Definitions
  3. 装饰器会替换函数元信息：wrapper 的 __name__ 是 "wrapper"——用 functools.wraps(func)（或自己实现 wraps 装饰器）把 __name__/__doc__ 复制过来。官方文档：functools.wraps

基础测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。

1. 装饰器本质上是什么？
装饰器是一个可调用对象：接收一个可调用对象（函数），返回另一个可调用对象（wrapper）来替代它。详见「装饰器的本质」一节。
2. @my_decorator 写在函数上方，等价于？
@my_decorator 是语法糖：def f(): ... 之后自动执行 f = my_decorator(f)。详见「装饰器本质示例」。
3. @decorator_a @decorator_b 两个装饰器叠加，执行顺序是？
@a @b 等价于 func = a(b(func))：调用时 a 的外层先执行，然后是 b 的外层，再原函数，返回时逆序。详见「多个装饰器叠加」一节。
4. functools.wraps(func) 的作用是？
装饰后 f.__name__ 默认变成 "wrapper"；functools.wraps(func) 把 __name__、__doc__ 等元信息复制到 wrapper 上，保持函数身份。本课作业二就是手写实现它。
5. timer 装饰器的 wrapper 中忘了 return func(...)，被装饰函数调用返回什么？
wrapper 没有 return 时默认返回 None——slow_function() 就拿不到 "Done" 了。所以计时装饰器既要打印耗时，也要 return result。
6. 带参数的装饰器 @repeat(3) 的结构是？
三层结构：repeat(n) 先执行并返回真正的装饰器 decorator，再由它去包装函数——@repeat(3) 等价于 func = repeat(3)(func)。源课程答案 p3.py 即此模式。

最终考核

下面是《11.装饰器》源课程作业的两道实现题改编——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里选出正确实现，再点击核对。

考核一（作业一·timer 装饰器）：实现 @timer——调用函数后打印 函数名 执行时间: X.XXXX 秒，且调用结果必须保留（slow_function() 返回 "Done"）。下列实现中正确的是？
正确结构：wrapper 里 start = time.time() → result = func(*args, **kwargs) → 计算耗时并打印 → return result。第二个丢失返回值 ✗；第三个在定义时（import 阶段）就打印，且不返回新函数 ✗；第四个计的不是函数执行耗时 ✗。
查看源课程参考答案（作业一） 
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(f"{func.__name__} 执行时间: {elapsed:.4f} 秒")
        return result
    return wrapper

@timer
def slow_function():
    time.sleep(1)
    return "Done"

slow_function()
# 输出：slow_function 执行时间: 1.0012 秒
考核二（作业二·wraps 装饰器）：手写 wraps(func)，让被装饰函数保持原来的 __name__ 和 __doc__。下列实现中正确的是？
正确结构：wraps(func) 返回装饰器 decorator(wrapper)，其中把 wrapper.__name__ = func.__name__、wrapper.__doc__ = func.__doc__，再返回 wrapper。第二个只保留了一半 ✗；第三个方向反了 ✗；第四个等于没装饰 ✗。
查看源课程参考答案（作业二） 
def wraps(func):
    def decorator(wrapper):
        wrapper.__name__ = func.__name__
        wrapper.__doc__ = func.__doc__
        return wrapper
    return decorator

def my_decorator(func):
    @wraps(func)
    def wrapper():
        print("函数执行前")
        func()
        print("函数执行后")
    return wrapper

@my_decorator
def say_hello():
    """打招呼"""
    print("Hello!")

say_hello.__name__  # 'say_hello'（不包裹则是 'wrapper'）
say_hello.__doc__   # '打招呼'
考核三（叠加顺序预测）：以下代码的输出顺序是？ 
def a(func):
    def wrapper():
        print("A 前")
        func()
        print("A 后")
    return wrapper

def b(func):
    def wrapper():
        print("B 前")
        func()
        print("B 后")
    return wrapper

@a
@b
def hello():
    print("执行")

hello()
@a @b 即 hello = a(b(hello))：调用时先进入 a 的 wrapper（打印 A 前）→ 调用 b 的 wrapper（打印 B 前）→ 原函数（执行）→ 返回 b 的 wrapper（B 后）→ 返回 a 的 wrapper（A 后）。顺序：A 前 → B 前 → 执行 → B 后 → A 后。
考核四（返回值保留）：用正确的 timer 装饰 slow_function（内部 time.sleep(1); return "Done"），调用后程序的输出最后一行是？
wrapper 内先打印耗时行，然后 return result；调用方 print(slow_function()) 再打印返回值。所以最后一行是 "Done"——这验证了「返回值必须保留」。
