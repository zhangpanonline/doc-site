知识速览

本质与语法糖

func ─ 传入 ─▶ decorator ─ 返回 ─▶ wrapper（替代原函数）

⚙️ @my_decorator 等价于 say_hello = my_decorator(say_hello)——装饰器在定义时就执行，wrapper 在调用时才执行。

三个要点

  1. wrapper 要接住参数并返回结果：用 def wrapper(*args, **kwargs) 接收任意参数，并 return func(*args, **kwargs) 把原函数的结果传出去——丢了 return，被装饰函数的返回值就变成 None。
  2. 叠加顺序：从下到上应用，从上到下包裹：@a @b 等价于 func = a(b(func))，调用时 a 的外层逻辑最先执行。官方文档：Function Definitions
  3. 装饰器会替换函数元信息：wrapper 的 __name__ 是 "wrapper"——用 functools.wraps(func)（或自己实现 wraps 装饰器）把 __name__/__doc__ 复制过来。官方文档：functools.wraps

🌱 初级测验 · 概念

1. 装饰器本质上是什么？
装饰器是一个可调用对象：接收一个可调用对象（函数），返回另一个可调用对象（wrapper）来替代它。详见「装饰器的本质」一节。
2. @my_decorator 写在函数上方，等价于？
@my_decorator 是语法糖：def f(): ... 之后自动执行 f = my_decorator(f)。详见「装饰器本质示例」。
3. functools.wraps(func) 的作用是？
装饰后 f.__name__ 默认变成 "wrapper"；functools.wraps(func) 把 __name__、__doc__ 等元信息复制到 wrapper 上，保持函数身份。本课作业二就是手写实现它。

🌿 中级测验 · 应用

4. @decorator_a @decorator_b 两个装饰器叠加，执行顺序是？
@a @b 等价于 func = a(b(func))：调用时 a 的外层先执行，然后是 b 的外层，再原函数，返回时逆序。详见「多个装饰器叠加」一节。
5. 带参数的装饰器 @repeat(3) 的结构是？
三层结构：repeat(n) 先执行并返回真正的装饰器 decorator，再由它去包装函数——@repeat(3) 等价于 func = repeat(3)(func)。源课程答案 p3.py 即此模式。
6. timer 装饰器的 wrapper 中忘了 return func(...)，被装饰函数调用返回什么？
wrapper 没有 return 时默认返回 None——slow_function() 就拿不到 "Done" 了。所以计时装饰器既要打印耗时，也要 return result。

🎯 高级测验 · 综合

7. 装饰器本体（非 wrapper）里的代码什么时候执行？
装饰器本体在 @deco 一行（即定义函数时）就执行——所以注册类、收集函数等副作用逻辑要放在装饰器本体；「每次调用都执行」的逻辑必须放进 wrapper。放错位置是装饰器的经典 bug 源。
8. @repeat(3) 等价于下列哪个表达式？
repeat(3) 返回装饰器 decorator，再作用到 func 上——两步合成 func = repeat(3)(func)。这就是「带参数装饰器 = 三层函数」的等价形式。
9. 类装饰器 @Dec 装饰函数 f 之后，f 是什么？调用 f(1, 2) 会触发什么？
@Dec 等价于 f = Dec(f)——f 变成 Dec 的实例（原函数存进实例属性）。之后 f(1, 2) 触发的是 Dec.__call__(实例, 1, 2)——类装饰器的核心正是第 9 课的 __call__。

最终考核

下面是《11.装饰器》源课程作业的两道实现题改编——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里选出正确实现，再点击核对。

考核一（作业一·timer 装饰器）：实现 @timer——调用函数后打印 函数名 执行时间: X.XXXX 秒，且调用结果必须保留（slow_function() 返回 "Done"）。下列实现中正确的是？
正确结构：wrapper 里 start = time.time() → result = func(*args, **kwargs) → 计算耗时并打印 → return result。第二个丢失返回值 ✗；第三个在定义时（import 阶段）就打印，且不返回新函数 ✗；第四个计的不是函数执行耗时 ✗。
查看源课程参考答案（作业一） 
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(f"{func.__name__} 执行时间: {elapsed:.4f} 秒")
        return result
    return wrapper

@timer
def slow_function():
    time.sleep(1)
    return "Done"

slow_function()
# 输出：slow_function 执行时间: 1.0012 秒
考核二（作业二·wraps 装饰器）：手写 wraps(func)，让被装饰函数保持原来的 __name__ 和 __doc__。下列实现中正确的是？
正确结构：wraps(func) 返回装饰器 decorator(wrapper)，其中把 wrapper.__name__ = func.__name__、wrapper.__doc__ = func.__doc__，再返回 wrapper。第二个只保留了一半 ✗；第三个方向反了 ✗；第四个等于没装饰 ✗。
查看源课程参考答案（作业二） 
def wraps(func):
    def decorator(wrapper):
        wrapper.__name__ = func.__name__
        wrapper.__doc__ = func.__doc__
        return wrapper
    return decorator

def my_decorator(func):
    @wraps(func)
    def wrapper():
        print("函数执行前")
        func()
        print("函数执行后")
    return wrapper

@my_decorator
def say_hello():
    """打招呼"""
    print("Hello!")

say_hello.__name__  # 'say_hello'（不包裹则是 'wrapper'）
say_hello.__doc__   # '打招呼'
考核三（叠加顺序预测）：以下代码的输出顺序是？ 
def a(func):
    def wrapper():
        print("A 前")
        func()
        print("A 后")
    return wrapper

def b(func):
    def wrapper():
        print("B 前")
        func()
        print("B 后")
    return wrapper

@a
@b
def hello():
    print("执行")

hello()
@a @b 即 hello = a(b(hello))：调用时先进入 a 的 wrapper（打印 A 前）→ 调用 b 的 wrapper（打印 B 前）→ 原函数（执行）→ 返回 b 的 wrapper（B 后）→ 返回 a 的 wrapper（A 后）。顺序：A 前 → B 前 → 执行 → B 后 → A 后。
考核四（返回值保留）：用正确的 timer 装饰 slow_function（内部 time.sleep(1); return "Done"），调用后程序的输出最后一行是？
wrapper 内先打印耗时行，然后 return result；调用方 print(slow_function()) 再打印返回值。所以最后一行是 "Done"——这验证了「返回值必须保留」。

💼 面试实战

下面是真实面试官会问的问题，选自中文互联网面试题集（出处附后）。先自己回答，再点击核对。三级面试难度：中级考应用，高级考陷阱，专家考机制与设计。

⚡ 中级面试题

面试题一（装饰器原理·必问）：请解释装饰器的原理与作用。
装饰器本质是高阶函数 + 闭包：接收函数、返回 wrapper（前置操作 → 调用原函数 → 后置操作），@ 只是语法糖。作用：在不修改原函数代码的前提下动态增加功能（日志、计时、权限校验、缓存、事务），完美遵循开放封闭原则（对扩展开放、对修改封闭）。出处：博客园「Python 面试基础」
面试题二（wraps·高频追问）：不加 functools.wraps 的装饰器会丢失什么？
不加 wraps 时 f.__name__ 变成 "wrapper"、__doc__ 丢失——影响调试、文档生成、以及依赖 __name__ 的工具（如路由框架按函数名注册）。所以面试会说：wraps 不是可选项。出处：老男孩 IT 教育「Python 基础教程之最常见的面试题」

🔥 高级面试题

面试题三（通用装饰器·深水区）：写一个「生产级」装饰器，要求：任意参数透传、保留返回值、保留 __name__/__doc__。下列正确的是？
生产级装饰器三要素缺一不可：① def wrapper(*args, **kwargs) 透明透传任意签名；② return func(*args, **kwargs) 保留返回值；③ @functools.wraps(func) 保留 __name__/__doc__（调试与路由注册依赖它）。第二个固定签名会崩 ✗；第三个元信息丢失 ✗；第四个返回值丢失 ✗。出处：老男孩 IT 教育「Python 基础教程之最常见的面试题」
面试题四（调用计数·实现题）：用装饰器统计函数被调用的次数，下列正确的是？
正确结构：装饰器函数内 count = 0，wrapper 里 nonlocal count; count += 1 再调用原函数——闭包计数器每次调用累计，且计数状态对每个被装饰函数独立。第二个全局计数会串 ✗；第三个只在定义时执行一次 ✗；第四个默认参数可被外部传入污染 ✗。出处：老男孩 IT 教育「Python 基础教程之最常见的面试题」

🧠 专家面试题

专家题一（组合等价式·机制）：@a @b(3) 装饰函数 f，等价于？
从下往上应用：先执行 b(3) 得到带参装饰器返回的装饰器，再作用于 f → b(3)(f)；然后 a 再包装 → f = a(b(3)(f))。装饰器叠加与带参装饰器组合时的展开顺序是深水区必考。出处同面试题四
专家题二（缓存装饰器·机制）：functools.cache / lru_cache 的实现要点是？
functools.cache（3.9+）用参数作键缓存返回值：相同参数再次调用直接命中缓存（函数体不再执行）——递归斐波那契从指数级降到线性级的关键。要求参数可哈希；lru_cache 还可限制缓存大小并查看命中统计（cache_info）。出处同面试题四
