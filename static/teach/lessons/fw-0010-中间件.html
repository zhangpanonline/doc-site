知识速览

概念与中间件骨架

  • 横切关注点：跨越多个功能、可被横切的共同逻辑（响应格式/耗时/跨域/日志）
  • AOP：把共同逻辑分离出去，不侵入功能本身；FastAPI 中间件是 AOP 的一种实现手段
  • 骨架：async def mw(request, call_next): 前置 → response = await call_next(request) → 后置 → return
  • 响应信封统一：成功 {"code":"0","data":...,"message":"success"}；失败 code 取错误码、data 为 None

三个中间件（课件）

  • unified_response：仅处理 /api/ 路径；response.body_iterator 重拼 body；弹掉 content-length 防失真
  • process_time：perf_counter 计时，写入 X-Process-Time 响应头
  • cors：CORSMiddleware 类中间件——allow_origins 白名单、expose_headers 放行 X-Process-Time
  • register_middleware：inspect.isclass 分派——类是 add_middleware，函数是 app.middleware("http")

分级测验

🌱 初级测验 · 概念

1. 横切关注点（Cross-Cutting Concerns）指的是什么？
课件核心概念：横切关注点描述「跨越多个功能、可被横切的共同逻辑」——每个接口都要做的非业务逻辑就是它。
2. AOP 与 FastAPI 中间件的关系是？（课件原文）
课件原文：AOP——将跨域多个功能、可被横切的共同逻辑分离出去，不侵入功能本身；FastAPI 的中间件是 AOP 的一种实现手段（DI 也是其一）。
3. 中间件函数骨架里 call_next(request) 的作用是？
课件骨架：response = await call_next(request)——洋葱模型的核心，调用前的代码是前置（如计时开始），调用后的代码是后置（如写响应头）。

🌿 中级测验 · 应用

4. unified_response 为什么只处理 /api/ 开头的路径？
课件代码：if not request.url.path.startswith("/api/"): return response——文档页/静态资源等非业务路径不包信封，否则 Swagger UI 等会渲染失败。
5. 为什么要重拼 body_iterator 并弹掉 content-length？
课件代码：body = b"" + async for chunk in response.body_iterator；headers.pop("content-length", None)——body 被包进信封后长度变了，必须重算（FastAPI 会为 JSONResponse 重新计算），否则客户端按旧长度读会截断。
6. register_middleware 里 inspect.isclass 分派是怎么回事？
课件 __init__.py：for callable_obj, kwargs in MIDDLEWARES——inspect.isclass 为真走 app.add_middleware(callable_obj, **kwargs)（Starlette 类中间件）；否则 app.middleware("http")(callable_obj)（函数中间件）。一个注册表统一两种形态。

🎯 高级测验 · 综合

7. 失败响应（>=400）的信封里，code 和 message 从哪里来？
课件代码：err = json.loads(body) if body else {}；code=err.get("code", str(status_code))、message=err.get("message", "")——与 ch09 的响应 {"code","message"} 无缝衔接，信封只补 data=None。
8. setup_openapi 为什么要改造 OpenAPI 文档里的响应 schema？
课件 openapi.py：monkeypatch app.openapi——遍历 /api/ 路径的 200/201 响应，把原 schema 包进 ApiResponse_{Name} 信封（$ref 复用不重复生成）。中间件只改运行时，不改文档的话前端按文档生成的客户端拿不到 data 字段。
9. CORS 配置里 expose_headers 为什么要把 X-Process-Time 列进去？
课件 cors.py：expose_headers = 配置按逗号拆分——浏览器的 CORS 规则：跨域响应只有 CORS-safelisted 头（Content-Type 等少数）对 JS 可见，自定义头必须出现在 Access-Control-Expose-Headers 里。前端要显示接口耗时就必须把 X-Process-Time 放行。
