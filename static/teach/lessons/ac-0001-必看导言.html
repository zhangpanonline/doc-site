本课目标

完成本课后，你将能：

  1. 说清 AI 岗位的三大方向——应用开发、推理部署、模型研发——各自的定位与核心知识
  2. 用「岗位需求 / 学习难度 / 薪资水平」三列一起读懂岗位表，而不是只看薪资单列
  3. 复述《Agents底层逻辑》在整条课程路线中的位置，以及学完之后的主线走向
  4. 面对一个真实需求时，判断它落在哪个方向、自己还缺哪些能力

知识速览

先花几分钟把「岗位表 + 课程安排图」这两页骨架过一遍——细节都在《01.必看导言》里，测验和面试会考。

三类 AI 岗位画像

  • 应用开发：AI应用开发工程师 / Agent应用开发工程师 / 大模型应用开发工程师——岗位需求 ★★★★★、学习难度 ★★★☆☆、薪资水平 ★★★☆☆；核心知识是编程思维、AI 认知、应用框架、业务经验
  • 推理部署：大模型部署工程师 / LLM 推理优化工程师——岗位需求 ★★☆☆☆、学习难度 ★★★★★、薪资水平 ★★★★★；核心知识是CUDA 内核、GPU 架构、算子融合、分布式推理、推理引擎、模型量化、显存优化
  • 模型研发：大模型算法工程师 / LLM 微调工程师 / 大模型训练工程师——岗位需求 ★★☆☆☆、学习难度 ★★★★★、薪资水平 ★★★★★；核心知识是深度学习理论、算法创新、模型架构、分布式训练、数据处理、强化学习、论文复现、高等数学、线性代数、概率论、优化理论

课程位置：先打底座，再往上层走

  • 课程安排图的主线：Agents底层逻辑 → Agents应用框架 → Agents企业应用 → 就业
  • 《Agents底层逻辑》是最底下那一层：先把模型与 Agent 的底层机制弄懂，再学应用框架，最后落到企业应用
  • 支线：AI 效能工具（用 AI 提升开发效率）与「其他知识」，最终都汇入就业阶段
  • 所以本课程 01–34 章不是零散知识点，而是这条底座路线自上而下的完整展开

怎么用这张岗位表做决定

  • 三列要一起看：需求决定岗位数量，难度决定你多久能上手，薪资决定天花板；只看一列容易判断失真
  • 需求最大的是应用开发（★★★★★），难度却只有三星——这是多数人的「入口」，不是「低级岗位」
  • 推理部署与模型研发难度、薪资都是五星，但核心知识完全不同：一个偏推理引擎与显存，一个偏训练与算法数学
  • 官方工程实践给的判据同样是「够用就好」：能用简单方案解决，就不要先堆复杂框架

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与《01.必看导言》覆盖的内容。

🌱 初级测验 · 概念

1. 《01.必看导言》的岗位表里，岗位需求标到 ★★★★★ 的是哪一类方向？
岗位表原文：应用开发的「岗位需求」为 ★★★★★，推理部署与模型研发均为 ★★☆☆☆。需求差异是这张表的第一个关键信号。
2. 「大模型算法工程师 / LLM 微调工程师 / 大模型训练工程师」属于哪一类方向？
岗位表原文：模型研发方向包含大模型算法工程师、LLM 微调工程师、大模型训练工程师；核心知识是深度学习理论、算法创新、模型架构、分布式训练、数据处理、强化学习、论文复现与数学基础。
3. 应用开发方向列出的核心知识是？
岗位表原文：应用开发的核心知识是编程思维、AI 认知、应用框架、业务经验——不含 CUDA 与数学训练类知识，那些属于另外两个方向。

🌿 中级测验 · 应用

4. 团队要「把线上大模型服务的推理延迟降下来、单卡吞吐提上去」，按岗位表最对口的方向与核心知识是？
岗位表把「分布式推理、推理引擎、模型量化、显存优化」列在推理部署方向，正是延迟与吞吐问题的对口知识；应用开发管的是模型之上的编排与业务，模型研发管的是训练与算法。
5. 岗位表里「应用开发」需求五星、难度三星，下面哪种解读最合理？
三列要一起读：需求五星说明市场上这类岗位最多，难度三星说明学习曲线相对平缓，薪资三星说明天花板与稀缺度相关。由此推不出「没技术含量」「薪资最高」「不需要编程」中的任何一条。
6. 按《01.必看导言》的课程安排，学完《Agents底层逻辑》之后的主线走向是？
课程安排图的主线：Agents底层逻辑 → Agents应用框架 → Agents企业应用 → 就业；「AI 效能工具」与「其他知识」是并入就业阶段的支线，不是主线前置。

🎯 高级测验 · 综合

7. 一位同学会 Python、懂业务，但没学过 CUDA 与高等数学，想在 3 个月内进入 AI 岗位。按岗位表，最匹配的方向与理由是？
选方向的依据是「岗位表三列 + 核心知识」的匹配度，而不是单看薪资。应用开发的四类核心知识与该同学现有能力重合度最高、难度三星可在短期内补齐；推理部署与模型研发难度五星，CUDA、数学与训练类知识不是三个月能速成的。
8. 有人说「推理部署和模型研发在表里需求、难度、薪资三列完全一样，所以是同一类岗位」。这个推论错在哪？
三列是「市场画像」，核心知识列才是「能力画像」。两行星级相同只说明市场稀缺度与难度接近，核心知识列的差异（推理引擎、模型量化、显存优化 对 深度学习理论、分布式训练、强化学习、数学基础）决定了它们是两条不同的能力路线。
9. 产品团队要在两周内上线一个内部知识问答助手，团队里没人懂 CUDA 与模型训练。AI 给出的方案是「自建推理集群 + 微调一个专属模型」。最合理的判断是？
岗位表给的成本账：应用开发需求五星、难度三星，能立刻组队开工；推理部署与模型研发需求两星、难度五星，属于按需引入的稀缺能力。两周的窗口只够走应用开发路线把链路跑通，等出现明确的成本或效果瓶颈，再立项推理优化或微调。
