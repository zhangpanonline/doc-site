知识速览

先花几分钟把核心机制过一遍——细节都在《1.基础语法》里，测验和考核会考。

语言的三个特征

源码 .py 文件 ─ 逐行执行 ─▶ 解释型：无需编译
a = 10，随后 a = "hello" ─ 运行时定类型 ─▶ 动态类型：变量可换类型
10 + "5" ─ 类型不匹配 ─▶ 强类型：直接报错

⚙️ 三种特征叠加：写起来自由（不用声明类型），运行时严格（类型错了立刻 TypeError）。

三个要点

  1. and / or 返回操作数本身，而不是布尔值：0 and 5 → 0、3 or 5 → 3、"" and "hello" → ""。官方文档：Boolean Operations
  2. 除法三兄弟与截断：/ 总是返回 float（5 / 2 → 2.5）；// 整除（5 // 2 → 2）；% 取余；int(3.9) → 3 是截断，不是四舍五入。官方文档：数值类型
  3. 链式比较与循环 else：a < b < c 等价于 a < b and b < c，且中间的 b 只计算一次；循环的 else 只在正常结束（未被 break 打断）时执行。官方文档：Comparisons

分级测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。三级难度：初级考概念，中级考应用，高级考综合与陷阱。

🌱 初级测验 · 概念

1. print(type(42) == int) 的输出是？
type 函数返回的不是字符串，而是类型对象：type(42) 得到 <class 'int'>，它 == int 成立，所以输出 True。详见《1.基础语法》「type 函数」一节。
2. print(int(3.9)) 的输出是？
int() 把浮点数转整数时是截断小数，不是四舍五入：int(3.9) → 3。想四舍五入要用 round()。详见「变量类型转换」一节。
3. print(bool("")) 的输出是？
空字符串是假值：bool("") → False。假值清单：0、0.0、""、None、False，其余都是真值。详见「逻辑运算符」的真假值表。

🌿 中级测验 · 应用

4. print(5 / 2) 的输出是？
/ 是「真除法」，总是返回 float：5 / 2 → 2.5。想要整数部分用 //（整除）：5 // 2 → 2。详见「算术运算符」一节。
5. print(3 or 5) 的输出是？
or 的规则：第一个为真就返回第一个，否则返回第二个。3 为真，所以 3 or 5 → 3。注意 0 or 5 才是 5。详见「逻辑运算符」一节。
6. print("A" < "a") 的输出是？
字符串比较按字典序（ASCII 码）：'A' 的码值 65 小于 'a' 的 97，所以 "A" < "a" → True。详见「比较运算符」一节。

🎯 高级测验 · 综合

7. print(1 < 5 < 3) 的输出是？
链式比较等价于 1 < 5 and 5 < 3：前半成立但 5 < 3 为假 → 整体 False。别被「1 < 5」迷惑，链式比较要求每一环都成立。详见「链式比较」一节。
8. print(bool("hello") and int(3.9)) 的输出是？
跨知识点综合：bool("hello") 为 True（真值），and 第一个为真则返回第二个操作数——而 int(3.9) 是截断后的 3。所以整体输出 3，不是 True。两个坑叠一个。
9. 执行以下代码，最后的输出是？ 
x = 10
x -= 3
x *= 2
x /= 4
print(x)
逐步推演：10 - 3 = 7 → 7 × 2 = 14 → 14 / 4 = 3.5（/= 让结果变 float）。连续赋值运算符按书写顺序逐个生效。

最终考核

下面是《1.基础语法》源课程作业的四道改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里（或纸上）算出答案，再点击核对。全部答对且能讲清理由，才算过关。

考核一（作业一·逻辑运算符陷阱）：print("" and "hello") 的输出是？
空字符串 "" 是「假值」，and 第一个为假就返回第一个——所以输出空字符串（屏幕上是一行空白，看不到任何字符）。对比："hi" and "hello" → "hello"。
考核二（作业二·循环累加）：以下代码最终输出的 result 是？ 
n = 1
result = 0
while n <= 5:
    if n % 2 == 0:
        result += n
    else:
        result -= n
    n += 1
print(result)
逐轮推演：n=1（奇）result=-1 → n=2（偶）+2 → 1 → n=3（奇）-3 → -2 → n=4（偶）+4 → 2 → n=5（奇）-5 → -3。奇数减、偶数加，1..5 的交替和是 -3。
考核三（作业三·BMI 计算器）：标准为 18.5/24/28 三档边界。下列分类判断中，边界处理正确的是？
标准是 18.5 ≤ BMI < 24 为正常，所以 bmi == 18.5 必须落在「正常」档：第一个选项用 < 18.5 判断偏瘦，18.5 落进下一档「正常」✓；第二个用 <= 18.5，18.5 被误判为偏瘦 ✗；第三个 18.5 落进 else 偏瘦 ✗；第四个 17 会先命中 < 24 被误判为正常 ✗。
查看源课程参考答案（作业三） 
height = float(input("请输入您的身高（米）："))
weight = float(input("请输入您的体重（千克）："))

bmi = weight / (height**2)

if bmi < 18.5:
    category = "偏瘦"
    advice = "建议适当增加营养摄入，多吃富含蛋白质的食物，进行适量力量训练。"
elif bmi < 24:
    category = "正常"
    advice = "保持良好的生活习惯，均衡饮食，适量运动，继续保持！"
elif bmi < 28:
    category = "超重"
    advice = "建议控制饮食，减少高热量食物摄入，增加有氧运动，如慢跑、游泳等。"
else:
    category = "肥胖"
    advice = "建议咨询专业医生或营养师，制定科学的减重计划，注意饮食控制和规律运动。"

print(f"\n您的 BMI 值为：{bmi:.2f}")
print(f"身体状况：{category}")
print(f"建议：{advice}")
考核四（作业四·素数筛选器）：素数 = 大于 1 且只能被 1 和自己整除的数。下列 is_prime(n) 实现中，正确的是？
验证关键样例：n=2 是素数 → 必须 True；n=1 不是 → 必须 False；n=9 不是 → 必须 False。只有第一个全对（n=2 时 range 为空直接返回 True；9 在 i=3 时被整除返回 False）。第二个把 9 判成素数 ✗；第三个把 1 判成素数 ✗；第四个把 2 判成非素数 ✗。

# 判断 num 是否为素数（i*i <= num 等价于 i <= num**0.5）
is_prime = True
i = 2
while i * i <= num:
    if num % i == 0:
        is_prime = False
        break
    i += 1

💼 面试实战

下面是真实面试官会问的问题，选自中文互联网面试题集（出处附后）。先自己回答，再点击核对。三级面试难度：中级考应用，高级考陷阱，专家考机制与设计。

⚡ 中级面试题

面试题一（牛客·最强 Python 面试题系列）：关于「变量、对象、引用」的关系，下列说法正确的是？
经典三问：变量是到内存空间的指针；对象是存值的内存块；引用是自动形成的从变量到对象的指针。a = 1 的过程：创建值 1 的对象 → 创建变量 a → 把 a 连到对象。类型概念存在于对象中而非变量中（动态类型）。出处：牛客网「最强 Python 面试题之 Python 基础题」
面试题二（牛客 NP 系列·进制转换）：把十六进制字符串 "FF" 转成十进制，正确写法与结果是？
int(x, base) 的 base 参数（2~36）指定进制：int("FF", 16) → 255；不带 base 的 int("FF") 会抛 ValueError（无法按十进制解析）。这是牛客 Python 入门题库（NP 系列）的常考题。还可自测：int("101", 2) → 5。出处：牛客刷题——Python 篇（2）类型转换

🔥 高级面试题

面试题三（浮点精度·高频陷阱）：print(0.1 + 0.2 == 0.3) 的输出是？
0.1 + 0.2 实际是 0.30000000000000004 ≠ 0.3 → False。Python 浮点是 IEEE 754 双精度，十进制小数在二进制下无法精确表示。工程实践：金额等精确场景用 Decimal 或按「分」存整数；浮点比较用容差 abs(a - b) < 1e-9。出处：腾讯云「分享 10 个高频 Python 面试题」
面试题四（字符串驻留·陷阱）：a = "hello"; b = "hello"; print(a is b) 的输出是？
类似小整数缓存，Python 对简短、只含字母数字下划线的字符串做驻留（interning）：a is b → True。但这是实现细节——判断字符串内容仍用 ==，不要依赖 is 的结果。出处：腾讯云「分享 10 个高频 Python 面试题」

🧠 专家面试题

专家题一（链式比较机制·深水区）：a < b < c 与 a < b and b < c 的区别是？
语义上等价，但求值次数不同：a < b < c 中 b 只计算一次；a < b and b < c 中 b 计算两次。当 b 是带副作用的表达式（如函数调用）时，两者行为可观察地不同——这是面试官追问「区别」时的标准答案。出处：老男孩 IT 教育「Python 基础教程之最常见的面试题」
专家题二（内存管理·机制）：del a 对变量 a 做了什么？
del a 解除变量与对象的引用（名字从命名空间移除）；对象何时释放由引用计数决定——计数归零才回收（CPython 主机制，辅以标记清除/分代回收处理循环引用）。若还有别的引用，对象不会释放。出处：老男孩 IT 教育「Python 基础教程之最常见的面试题」
面试追问参考：变量使用前必须赋值吗？del 有什么用？

① 变量无须事先声明，但使用前必须先赋值（赋值的同时创建变量）；② del 释放变量（解除引用），对象会在引用计数归零后被回收；③ 标识符规则：字母/数字/下划线组成、不能数字开头、区分大小写。出处同面试题一
