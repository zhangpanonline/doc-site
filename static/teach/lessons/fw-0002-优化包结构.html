优化包结构

本课目标

完成本课后，你将能：

  1. 说出 app 包的四层职责（main 入口 / core 基础设施 / api 路由层 / schema 模型层）
  2. 用 pydantic-settings 的 env_file 与 env_prefix 管理环境变量配置
  3. 把路由拆分到 APIRouter 并用 include_router 挂载，把 DTO 独立到 schema/
  4. 用 debugpy + VSCode attach 模式断点调试 FastAPI

知识速览

先花几分钟把核心机制过一遍——细节都在《02.优化包结构》里，测验和面试会考。

四层结构

  • main.py：FastAPI 应用入口（创建 app、挂载路由）
  • core/：核心基础设施（配置 config.py）
  • api/：路由层（welcome.py / items.py，各自一个 APIRouter）
  • schema/：Pydantic 请求/响应模型（DTO，如 item.py）

配置与路由要点

  • pydantic-settings：model_config = {"env_file": ".env", "env_prefix": "WEB_"}——app_name 字段实际读取 WEB_APP_NAME
  • 路由拆分：APIRouter(prefix="/items") + app.include_router(...)——前缀在路由器上声明
  • debugpy：--listen 0.0.0.0:5678 --wait-for-client 起调试服务器，VSCode 用 attach 模式连 5678

🌱 初级测验 · 概念

1. 分层结构中 core/ 的职责是？
课件结构注释：core/ 是核心基础设施，本课的 config.py 就放这里。
2. schema/ 层放什么？
课件结构注释：schema/ 是 Pydantic 请求/响应模型层。
3. WebSettings 里 app_name 字段实际读取的环境变量是？
课件注释：model_config 的 env_prefix 为 WEB_——app_name 字段对应环境变量 WEB_APP_NAME。

🌿 中级测验 · 应用

4. env_file 配置项的作用是？
课件注释：env_file 是 env 文件的位置——配置从这里读取。
5. APIRouter(prefix="/items") 的作用是？
课件代码：router = APIRouter(prefix="/items")——该路由器内所有路径自动带 /items 前缀。
6. debugpy 的 --wait-for-client 含义是？
课件命令：--listen 0.0.0.0:5678 --wait-for-client——起监听后等 VSCode attach 上来再继续。

🎯 高级测验 · 综合

7. CommonSettings 的 environment 字段（默认 development）与 WebSettings 分开的理由是？
课件把 environment 放 CommonSettings（通用）、app_name 放 WebSettings（应用专属）——分层配置的基础。
8. main.py 里 include_router 的调用时机与位置？
课件代码：先创建 app，再 import 两个 router 并 include_router 挂载——顺序是定义后挂载。
9. 把 Item 模型挪到 schema/item.py 的意义？
分层意义：schema 层独立后，路由、服务、测试都能 import 同一份模型——避免定义散落与重复。
