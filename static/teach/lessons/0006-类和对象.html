三个要点

  1. 类属性共享，实例属性独立：类属性要用 类名.属性 修改（Dog.species = ...），实例上赋值只会新建实例属性。计数器 Dog.count += 1 写在 __init__ 里就是典型用法。官方教程：Class and Instance Variables
  2. 多继承的 super() 沿 MRO 找「下一个」：不是固定调父类，而是按 __mro__ 顺序找下一个类。C(A, B) 里 A 的 super() 调到的是 B——考核一考的正是这一点。
  3. 反射工具各有分工：type() 不看继承、isinstance() 看继承；__bases__ 是全部直接父类元组、__base__ 是第一个；vars(obj) 只看对象自己的属性字典。官方文档：isinstance

分级测验

🌱 初级测验 · 概念

1. 想让所有实例都看到类属性的修改，应该怎么做？
类属性存于类字典，要通过类名修改才能让所有实例共享变化。实例上赋值 dog1.species = ... 只会给 dog1 新建一个同名实例属性，别的实例不受影响。详见「实例属性与类属性」一节。
2. isinstance() 与 type() 的区别是？
isinstance(dog, Animal) 为 True（Dog 继承 Animal）；type(dog) == Animal 为 False（type 返回精确类型 Dog）。详见「isinstance()」一节。
3. vars(dog) 返回的是什么？
vars(dog) 等价于 dog.__dict__，只包含实例自己的属性（如 {'name': 'Buddy'}），类属性和方法在类字典里。详见「vars()」一节。

🌿 中级测验 · 应用

4. Dog.__base__ 返回的是什么？
__bases__ 是所有直接父类元组（如 (B, C)），__base__ 是其中的第一个（B）。详见「内置属性」一节。
5. 类中定义 self.__password，它实际存进对象字典的键是？
双下划线开头触发名称改写：__password 被改写为 _BankAccount__password（前加类名和下划线），外部直接访问 obj.__password 会 AttributeError。这是约定式防护，不是真正的私有。详见「访问控制」一节。
6. 在 __init__ 中写 Dog.count += 1（count 是类属性），效果是？
Dog.count += 1 通过类名修改类属性，每创建一个实例计数 +1，所有实例共享——这是统计实例数的标准写法。详见「类方法」一节。

🎯 高级测验 · 综合

7. class D(B, C)，B、C 都继承 A。D 的 MRO 顺序是？
菱形继承的 MRO 是 D → B → C → A → object（C3 线性化，近似广度优先）——不是直觉上的「B 走完再到 C」。A 只出现一次且在最后。详见「方法解析顺序（MRO）」一节。
8. MRO 为 D → B → C → A 时，B 的方法里写 super().method()，实际调用的是？
super() 沿当前对象实例的 MRO 找当前类的下一个——B 的下一个是 C，不是直接父类 A！这是多继承 super 与直觉最大的差异点。详见「super() 在多继承中的行为」一节。
9. 以下代码的输出是？ 
class Animal:
    kingdom = "Animalia"

    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, age):
        super().__init__(name)
        self.age = age

dog = Dog("Buddy", 3)
print(getattr(dog, "color", "brown"))
setattr(dog, "color", "golden")
delattr(dog, "color")
print(hasattr(dog, "color"))
反射四连：getattr 键不存在返回默认值 brown；setattr 动态加属性 golden；delattr 删掉它；hasattr 再查 → False。输出：brown → False。

最终考核

下面是《6.类和对象》源课程作业的四道改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里算出答案，再点击核对。全部答对且能讲清理由，才算过关。

考核一（作业一·腾讯面试题）：以下代码的输出顺序是？ 
class Base(object):
    def __init__(self):
        print("enter Base"); print("leave Base")

class A(Base):
    def __init__(self):
        print("enter A"); super().__init__(); print("leave A")

class B(Base):
    def __init__(self):
        print("enter B"); super().__init__(); print("leave B")

class C(A, B):
    def __init__(self):
        print("enter C"); super().__init__(); print("leave C")

c = C()
C(A, B) 的 MRO 是 C → A → B → Base。C.__init__ 打印 enter C 后 super() 调到 A；A 打印 enter A 后 super() 沿 MRO 调到B（不是 Base！）；B 的 super() 才到 Base。返回时按后进先出打印 leave。完整顺序：enter C → enter A → enter B → enter Base → leave Base → leave B → leave A → leave C。
考核二（作业二·反射）：print(type(dog1), type(Dog)) 的输出是？
type(dog1) 是创建实例的类 → Dog；type(Dog) 是创建类的类（元类）→ type。输出：<class 'Dog'> <class 'type'>。所有类的类型都是 type。
考核三（作业二·属性字典）：dog2 = Dog("Max", 5) 后，vars(dog2) 的结果是？
vars(dog2) 只看实例自己的字典：name 和 age。类属性 kingdom（继承来的）、count、方法 bark 都在类字典里，不会出现在 vars 结果中。→ {'name': 'Max', 'age': 5}。
考核四（作业三·链表实现）：实现 LinkedList.append(value)——在链表尾部添加新节点（head 为 None 时为首节点）。下列实现中正确的是？
正确的 append：链表为空时 head = new_node；否则从 head 出发，while current.next is not None 走到最后一个节点，再 current.next = new_node。第二个是 prepend 的行为 ✗；第三个只保留最后一个 ✗；第四个是死循环 ✗。
查看源课程参考答案（作业三·核心方法） 
class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

class LinkedList:
    def __init__(self, data=None):
        self.head = None
        self._length = 0
        if data is not None:
            for value in data:
                self.append(value)

    def append(self, value):
        new_node = Node(value)
        if self.head is None:
            self.head = new_node
        else:
            current = self.head
            while current.next is not None:
                current = current.next
            current.next = new_node
        self._length += 1

    def traverse(self, callback):
        current = self.head
        index = 0
        while current is not None:
            callback(index, current.value)
            current = current.next
            index += 1

    def get_length(self):
        return self._length

💼 面试实战

下面是真实面试官会问的问题，选自中文互联网面试题集（出处附后）。先自己回答，再点击核对。

面试题一（菱形继承·高频）：class D(B, C)，B、C 都继承 A，且四个类都有 who()。调用 D().who() 走哪个？
MRO（C3 线性化）顺序为 D → B → C → A → object，方法查找从左到右取第一个命中——所以是 B.who。而 B 里的 super().who() 会继续走到 C——这就是「super 指向 MRO 下一个」的完整体现。出处：千锋教育「Python 面试题：阅读下面的代码说出运行结果」
面试题二（类属性陷阱·高频）：class A: items = []，创建两个实例 a1、a2，执行 a1.items.append(1) 后 a2.items 是什么？
items = [] 是类属性：a1.items 沿查找链找到类字典里那个唯一的列表，append 改的是它——a2.items 同样指向它 → [1]。这就是「可变类属性的幽灵共享」，与可变默认参数陷阱同源。需要实例独立时应在 __init__ 里 self.items = []。出处：CSDN 文库「Python 面试核心考点解析：面向对象」
