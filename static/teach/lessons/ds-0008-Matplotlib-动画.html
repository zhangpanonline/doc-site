知识速览

先花几分钟把动画的骨架过一遍——细节都在《08.Matplotlib - 动画》里，测验和面试会考。

FuncAnimation：先有静态图，再让函数改数据

  • 三要素：fig（画布）、func（每帧调用的更新函数）、frames（帧总数或可迭代对象）
  • 写法套路是「先画静态图并保存 Artist 引用 → 更新函数里调用 set_data / set_ydata 改数据 → 用 FuncAnimation 串起来」
  • frames 的四种形态：可迭代对象（直接用）、整数（等价于 range(frames)）、生成器函数、None
  • interval 是显示时的每帧间隔毫秒数、默认 200；repeat 默认 True

Blit 模式：只重绘变化的部分

  • blit=True 时只重绘被动过的那些 Artist，而不是整张 Axes，性能提升明显
  • 代价：更新函数（以及 blit 下的 init_func）必须返回 Artist 序列，blitting 算法靠它判断 Figure 上哪块区域要更新——忘了返回就报错
  • init_func 用来「画一个干净的初始帧」，在第一帧之前调用一次；不传时就用 frames 第一项的画法结果
  • 课件里的清理函数会先 ani.event_source.stop() 再 plt.close("all")：动画对象持有事件源，重跑单元格前要主动停掉

两种方案与保存：按内存和场景选

  • FuncAnimation：画一次、之后只改数据，省内存、适合长动画与实时数据流（滚动窗口用 deque(maxlen=100) + 无限生成器）
  • ArtistAnimation：接收一个「每帧要显示的 Artist 列表」的列表，所有帧都要事先存下来，内存随帧数增长；换来的好处是能精确控制每一帧的内容（比如柱状图竞赛）
  • 保存：ani.save('sine_wave.gif', writer='pillow', fps=20)；GIF 用 pillow，MP4 用 ffmpeg（需另装），嵌入 Notebook 用 HTML(ani.to_jshtml())
  • fps 管的是保存后文件的帧率，interval 管的是显示时的帧率——两者互不覆盖

🌱 初级测验 · 概念

1. 用 FuncAnimation 做动画，你提供的那个函数（课件里的 update(frame)）的职责是？
课件原文：FuncAnimation 是「你提供一个更新函数，动画循环每次调用它来更新图表」，核心三要素是 fig / update(frame) / frames。保存交给 ani.save()，帧数交给 frames。
2. 课件参数表里，interval 的含义与默认值是？
课件参数表：interval 是「每帧间隔（毫秒），默认 200」；repeat 才是「是否循环播放，默认 True」。课件示例里的 16、30、50 都是把默认值调小让动画更流畅。
3. 更新函数里想把正弦曲线的形状换掉，课件用的写法是？
课件写法：先用 line, = ax.plot(x, np.sin(x)) 画一次并保存引用，更新函数里 line.set_ydata(np.sin(x + phase))。动画的全部意义就是「画一次、之后只改数据」——重复建图或重复 plot 会不断堆叠新 Artist。

🌿 中级测验 · 应用

4. 同事按课件写了 FuncAnimation(fig, update, frames=100, blit=True, interval=50)，但运行报错 RuntimeError: When blit=True, the animation function must return a sequence of Artist objects.。最可能的原因是？
官方文档：blit == True 时「func must return an iterable of all artists that were modified or created」，这份信息被 blitting 算法用来判断图上哪块区域要更新。报错点名的是动画函数，不是 repeat / frames / ffmpeg。对应课件「Blit 模式」小节。
5. 关于 init_func 的调用时机与必要性，下面哪种说法符合课件与官方文档？
课件：init_func 是「初始化函数，配合 blit 使用」，「先初始化所有 Artist，然后每帧只更新特定部分」；官方文档补充：不提供时「the results of drawing from the first item in the frames sequence will be used」，并且该函数「will be called once before the first frame」。对应课件「Blit 模式」小节。
6. 把 frames 写成 data_stream()（一个 while True: yield ... 的无限生成器）时，课件为什么同时传了 cache_frame_data=False？
官方文档对 cache_frame_data 的说明：「Whether frame data is cached. Disabling cache might be helpful when frames contain large objects.」无限生成器没有终点，帧数据会一帧帧缓存下去。对应课件「使用可迭代对象作为 frames」那段实时数据流示例。

🎯 高级测验 · 综合

7. 下面四种说法，哪一个是错的？
错在第二句的「完全不会被用到」。官方文档：init_func 确实「will be called once before the first frame」，但「If blit == True, init_func must return an iterable of artists to be re-drawn」——它的返回值参与确定重绘区域，返回缺失会直接报 When blit=True, the init_func must return a sequence of Artist objects.。「调用一次」和「返回无用」是两件事。对应课件「Blit 模式」小节。
8. 要做一个「不断接收传感器数据、无限滚动」的实时监控动画，为什么 FuncAnimation 通常比 ArtistAnimation 更合适？
课件：FuncAnimation「你提供一个更新函数，动画循环每次调用它」；ArtistAnimation「适合你已经准备好每一帧所有 Artist 的情况」「接受一个列表，每个元素是这一帧要显示的所有 Artist」。官方教程也给了同样判据：FuncAnimation「is more efficient in terms of speed and memory as it draws an artist once and then modifies it」，ArtistAnimation 的优势在灵活。ArtistAnimation 同样接受 blit 参数，也能保存成各种格式，A/C/D 都不成立。对应课件第 2 节。
9. 同事要把动画交付出去，写下 ani.save('sine_wave.mp4', writer='ffmpeg')，但机器上只装了 pillow、没有 ffmpeg。最符合课件说明的判断是？
课件：GIF 用 pillow writer，MP4 用 ffmpeg writer（需安装 ffmpeg）。官方教程同样强调「ffmpeg and imagemagick need to be separately installed」。pillow 写不了 mp4，改 writer 而保留 .mp4 扩展名只会得到格式不匹配的错误。对应课件第 3 节「保存动画」。
