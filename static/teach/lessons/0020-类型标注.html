三个要点

  1. 标注是「提示」不是「约束」：x: int = "hello" 运行不报错——标注给 IDE 和类型检查器（mypy/pyright）看，帮助在编码期发现问题。官方文档：typing
  2. 裸容器标注等于没说：List、Dict 不带类型参数时检查器无法推断元素类型——应写 list[dict[str, int]] 这类完整形式（考核四）。
  3. Python 3.10+ 内置小写写法：list[int]、int | None 比 typing.List、Optional 更现代，标注放在变量后、函数返回值用 ->。

分级测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。三级难度：初级考概念，中级考应用，高级考综合与陷阱。

🌱 初级测验 · 概念

1. x: int = "hello" 运行时会发生什么？
Python 是动态语言，运行时不强制类型标注；类型检查工具（如 IDE 的 typeCheckingMode）会在编码期提示。详见「变量类型标注」一节。
2. 返回值可能是 str 也可能是 None，正确的标注是？
Optional[str] 即 Union[str, None]，3.10+ 可直接写 str | None。详见「Optional 和 Union」一节。
3. 回调参数「接收两个 int 返回 int」的标注是？
Callable[[参数类型列表], 返回类型]——Callable[[int, int], int] 表示接收两个 int 返回 int 的可调用对象。详见「Callable 和回调函数」一节。

🌿 中级测验 · 应用

4. 泛型类 Stack[T] 中，T 的定义方式是？
泛型三步：T = TypeVar("T") 声明类型变量；class Stack(Generic[T]) 参数化；使用时 Stack[int]。详见「泛型」一节。
5. 方法返回「本类的新实例」，返回值标注用？
typing.Self（3.11+）表示返回本类实例；旧写法是字符串前向引用 -> "Point"。两者都正确，Self 更通用（子类也成立）。详见「类与自定义类型」一节。
6. TypedDict 适合标注什么？
TypedDict 描述键结构固定的字典（每个键的类型分别声明），用于 API 响应等结构化数据。详见「TypedDict API 接口定义」一节。

🎯 高级测验 · 综合

7. def f(items: List) -> Dict 的问题是什么？
裸 List/Dict 没带类型参数，等于「不知道里面是什么」——应写 list[dict[str, Any]] 等完整形式。这就是考核四思考题的考点。
8. 泛型 Cache[K, V] 的 get 返回 Optional[V]，实现中用 self._data.get(key) 是因为？
dict.get(key) 键不存在返回 None——恰好满足 Optional[V]（V 或 None）的语义；用 self._data[key] 会 KeyError，与标注不符。类型标注与实现要互相印证。
9. TypedDict 嵌套：AppConfig 里 db: DatabaseConfig（另一个 TypedDict），检查器能验证嵌套结构吗？
TypedDict 可以嵌套：先定义 DatabaseConfig(TypedDict)，再在 AppConfig 里引用它——检查器会逐层校验键的类型，多层级 API 结构也能完整建模。

最终考核

下面是《20.类型标注》源课程作业的改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里选出正确标注，再点击核对。

考核一（作业一·函数标注）：calculate_bmi(weight, height) 与 get_grade(score) -> "A"/"B"/.../，下列标注中正确的是？
BMI 计算输入是浮点（体重/身高），返回 weight / height**2 也是 float → (weight: float, height: float) -> float；get_grade 接收分数（int）返回等级字符串（str）→ (score: int) -> str。第二个把身高体重当 int 会丢精度 ✗；第三个返回值错 ✗。
考核二（作业二·泛型缓存）：Cache[K, V] 的 set 存值、get 返回 Optional[V]、clear 清空。下列实现中正确的是？
正确实现：class Cache(Generic[K, V])，self._data: dict[K, V] = {}；get 用 self._data.get(key)（键不存在返回 None，正好匹配 Optional[V]）。第二个键不存在会 KeyError ✗；第三个类型参数失效 ✗；第四个检查器推断不了 ✗。
查看源课程参考答案（作业二） 
from typing import TypeVar, Generic, Optional

K = TypeVar("K")
V = TypeVar("V")

class Cache(Generic[K, V]):
    def __init__(self) -> None:
        self._data: dict[K, V] = {}

    def set(self, key: K, value: V) -> None:
        self._data[key] = value

    def get(self, key: K) -> Optional[V]:
        return self._data.get(key)

    def clear(self) -> None:
        self._data.clear()
考核三（作业三·TypedDict）：AppConfig 含 app_name(str)、debug(bool)、db(DatabaseConfig)——db 又含 host/port/username/password/database。下列标注中正确的是？
TypedDict 可以嵌套：先定义 class DatabaseConfig(TypedDict)（host: str, port: int, username: str, password: str, database: str），再 class AppConfig(TypedDict) 里写 db: DatabaseConfig。第二个丢失结构信息 ✗；第三个 Any 等于放弃检查 ✗；第四个说法错误 ✗。
查看源课程参考答案（作业三） 
from typing import TypedDict

class DatabaseConfig(TypedDict):
    host: str
    port: int
    username: str
    password: str
    database: str

class AppConfig(TypedDict):
    app_name: str
    debug: bool
    db: DatabaseConfig
考核四（作业四·思考题）：def process_data(items: List) -> Dict 与 def find_max(a: int, b: int) -> int | None（相等时返回 None），哪项标注需要修改？
List/Dict 裸用时检查器不知道元素类型——应写 items: list[dict[str, Any]]、返回 dict[Any, Any]（或更精确的 TypedDict）。find_max 相等时返回 None，标注 int | None 完全正确——返回值本来就可能是 None。

四道考核全部答对，说明你已经掌握类型标注——可以继续学习《19.模块化》了。
