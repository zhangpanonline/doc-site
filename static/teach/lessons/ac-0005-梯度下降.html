梯度下降

配合《05.梯度下降》使用预计 15–20 分钟9 道分级测验 + 面试实战

本课目标

完成本课后，你将能：

  1. 用自己的话说清梯度下降在做什么——为什么沿「负梯度方向」走
  2. 逐符号读懂损失函数 $L=\frac{1}{m}\sum_{i=1}^{m}(y_i-\hat y_i)^2$，说清平方与除以 $m$ 各自的作用
  3. 解释学习率如何决定每一步的幅度，过大、过小分别会发生什么
  4. 把「前向传播 → 算损失 → 反向传播求梯度 → 按学习率更新参数」串成一次完整的训练迭代

知识速览

先花几分钟把三个术语和一条公式过一遍——细节都在《05.梯度下降》里，测验和面试会考。

梯度下降：朝「下坡最快」的方向走

  • 损失函数把「当前这组参数好不好」变成一个数字：数字越小，预测越接近真实值
  • 梯度指向函数值上升最快的方向，所以负梯度方向才是当前点的最速下降方向
  • 课件术语原文：梯度下降是「沿着函数在当前点处最速下降方向（即负梯度方向）移动，使得函数的值逐步减少」
  • 写成一行：$\theta \leftarrow \theta - \eta \nabla L(\theta)$——$\nabla L(\theta)$ 是梯度，$\eta$ 是学习率

损失函数：一个数字背后的四个符号

  • 公式：$$L = \frac{1}{m}\sum_{i=1}^{m}(y_i-\hat y_i)^2$$
  • $m$：这一批参与计算的样本个数；$i$ 从 1 遍历到 $m$
  • $y_i$：第 $i$ 个样本的真实值；$\hat y_i$：模型前向传播算出的预测值（上一章的内容）
  • 平方：让每一项非负，避免「一半偏高、一半偏低」互相抵消，同时放大了偏差大的样本
  • 除以 $m$：取平均，让损失不随这一批的样本数膨胀，不同 batch 之间才可比——这就是「均方误差」里的 mean
  • 损失函数只负责量差距；参数往哪改、改多少，要靠对它求梯度

学习率与「一次训练迭代」

  • 学习率 $\eta$ 是梯度下降的幅度：梯度给方向，学习率给步长
  • 过大：一步迈过谷底，损失来回震荡甚至越来越大（发散）；过小：每步都很小，收敛极慢
  • 一次迭代的四步：前向传播得到 $\hat y_i$ → 与真实的 $y_i$ 算出损失 $L$ → 反向传播求出 $L$ 对每个参数的梯度 → 按 $\theta \leftarrow \theta - \eta \nabla L$ 更新参数
  • 课件术语原文：学习/训练是「一个过程，在这个过程中，通过梯度下降的手段，让神经网络的参数逐步调整到最佳状态」——它是反复迭代的过程，不是一次动作

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与《05.梯度下降》覆盖的内容。

🌱 初级测验 · 概念

1. 「梯度下降」中，参数每一步朝哪个方向移动？
课件术语原文：沿着函数在当前点处最速下降方向（即负梯度方向）移动，使得函数的值逐步减少。梯度是上升最快的方向，因此更新时要减去它——朝它的反方向走。
2. 学习率决定的是什么？
课件术语原文：学习率是「梯度下降的幅度」。它不改变方向，只决定沿着这个方向一次走多远；方向由负梯度给出。
3. 课件术语里的「学习 / 训练」指的是？
课件术语原文：学习/训练是「一个过程，在这个过程中，通过梯度下降的手段，让神经网络的参数逐步调整到最佳状态」。关键词是「过程」——它由很多次迭代组成，而不是某一次更新。

🌿 中级测验 · 应用

4. 损失函数 $L=\frac{1}{m}\sum_{i=1}^{m}(y_i-\hat y_i)^2$ 里，$m$ 和前面的 $\frac{1}{m}$ 分别是什么？
求和号下的 i 从 1 遍历到 m，m 就是这一批参与计算的样本数。只求和的话，batch 越大损失越大，既不能和别的 batch 比较，也看不出「平均每个样本错多少」；除以 m 之后得到的才是均方误差（mean squared error）。
5. 如果把平方去掉，把损失写成 $\frac{1}{m}\sum_{i=1}^{m}(y_i-\hat y_i)$，最直接的隐患是什么？
平方保证每一项非负，既避免正负抵消，又放大了偏差大的样本；去掉平方后，误差 +5 和 −5 的两个样本会加出 0，指标就骗人了。
6. 学习率设得过大的典型表现是？
学习率是梯度下降的幅度：太大 → 越过最低点来回震荡、甚至发散；太小 → 收敛极慢。梯度给方向、学习率给步长，两者缺一不可。

🎯 高级测验 · 综合

7. 按本课术语，一次训练迭代的正确顺序是？
前向传播负责「猜」，损失负责「量差距」，反向传播负责把误差摊到每个参数上（求梯度），梯度下降负责按学习率更新。顺序错一步，算出的梯度就对不上当前参数——训练循环里的 zero_grad / backward / step 也是这个顺序。
8. 有同事说：「梯度下降就是让损失函数每一轮都变小，所以只要盯着 loss 往下掉，就说明训练是对的。」按本章对「学习/训练」的定义，最准确的评价是？
课件术语：学习/训练是「一个过程」，通过梯度下降让参数逐步调整到最佳状态。loss 是衡量差距的指标，下降说明过程在起作用；但梯度下降本身只是「沿当前点最速下降方向移动」的动作，学习率（幅度）过大就会越过谷底，损失反而上升。
9. 有人为了让 loss 的显示数字更小，把损失从 $\frac{1}{m}\sum(y_i-\hat y_i)^2$ 改成了 $\frac{1}{m^2}\sum(y_i-\hat y_i)^2$。关于这次改动，判断正确的是？
对预测值求导得 ∂L/∂ŷᵢ = −(2/m)(yᵢ − ŷᵢ)。把 1/m 换成 1/m²，梯度整体乘了 1/m，等价于把学习率调小 m 倍——方向没变，步子却小了。所以判断一个改动是否安全，看的不是 loss 的数字，而是它对梯度（也就是更新幅度）做了什么。
