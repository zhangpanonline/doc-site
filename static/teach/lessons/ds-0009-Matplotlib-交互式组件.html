知识速览

先把握「五个组件 + 一条套路 + 一个后端前提」，细节都在《09.Matplotlib - 交互式组件》里，测验和面试会考。

五个组件与选型

  • Slider（滑块）：拖动调整连续数值，参数有 valmin / valmax / valinit / valstep，用 on_changed 绑定回调，回调参数是当前值；多值就是建多个滑块、共用一个回调
  • Button（按钮）：触发一次性动作（重新生成数据、重置），用 on_clicked 绑回调，回调参数是事件对象 event
  • CheckButtons（复选框）：多个独立开关，常用于控制多条曲线显隐，用 on_clicked，回调参数是被切换的 label
  • RadioButtons（单选）：一组互斥选项，适合切换函数类型或图表类型，回调参数也是 label
  • TextBox（文本框）：需要精确数值或自定义表达式时用，on_submit 在回车或离开输入框时触发，回调参数是字符串

组件通用四步套路（本章每个 demo 都是这个结构）

  • ① 建 ax：fig.add_axes((left, bottom, width, height)) 给组件单独一块 Axes，并配 fig.subplots_adjust(bottom=…) 给组件腾地方
  • ② 建组件：slider = Slider(slider_ax, '频率', 0.1, 5.0, valinit=1.0, valstep=0.1) —— 结果必须赋值给变量，否则组件失去引用就不响应了
  • ③ 写回调：回调里改数据（line.set_ydata(...) / line.set_visible(...)）；数据范围变了还要 ax.relim() + ax.autoscale_view()（Button 重新生成数据那段就是这么做的）
  • ④ 重绘：回调末尾 fig.canvas.draw_idle()，把重绘请求交给 GUI 事件循环

后端前提与常见故障

  • 本章第一段代码是 %matplotlib widget：Notebook 里要交互必须切到交互后端（ipympl，需单独安装）；默认的 inline 后端只渲染一次静态图
  • 组件画出来了但拖不动：先查后端是不是 inline；再查 ipympl 是否装了；最后查组件对象有没有被垃圾回收（裸调用 Slider(...) 不赋值就是典型）
  • 拖了但曲线不变：回调末尾少了 draw_idle()——set_ydata 只改数据，画布不会自己知道
  • 组件压在图上：忘了 fig.subplots_adjust，组件 Axes 与主图坐标区重叠了

🌱 初级测验 · 概念

1. 要让用户拖拽调整一个连续数值（例如正弦波的频率），应该用哪个组件？
本章第 1 节：Slider 是最常用的交互组件，适合让用户通过拖动来调整连续数值，用 on_changed 绑定回调，回调收到的就是当前值。
2. Button 用什么方法把「点击」和回调函数连起来？
本章第 2 节：Button 用 on_clicked(回调) 连接点击事件，回调收到的是事件对象；on_changed 是 Slider 的方法，on_submit 是 TextBox 的方法。
3. 五个组件在构造时都要传的第一个参数是什么？
本章五个示例都是先用 fig.add_axes((left, bottom, width, height)) 建一块 Axes，再把它作为第一个参数传给组件；官方 widgets 文档也写明所有组件都要求预先定义 Axes 并作为第一个参数传入。

🌿 中级测验 · 应用

4. Slider(..., valinit=1.0, valstep=0.1) 里的 valstep=0.1 是什么语义？
本章第 1 节 demo_slider_single.py：valinit 是滑块的初始位置，valstep 是步长吸附——官方 Slider 文档原文说若为浮点数，滑块会 snap to multiples of valstep（吸附到 valstep 的整数倍）；若传数组则吸附到数组里的值。
5. 回调里已经 line.set_ydata(...) 改好了数据，但末尾忘了 fig.canvas.draw_idle()，会看到什么？
本章五个示例的回调末尾都有 fig.canvas.draw_idle()。set_ydata 只修改 Artist 的数据，屏幕不会自己更新；draw_idle 的语义是「请求 GUI 事件循环回来时重绘一次」。
6. CheckButtons 与 RadioButtons 的关键区别是？
本章第 3、4 节：CheckButtons 的回调收到被切换的 label，用来切换多条曲线的显隐；RadioButtons 用于从一组互斥选项中选择一个，适合切换函数或图表类型。

🎯 高级测验 · 综合

7. 为什么每个组件都要单独传一个 ax，而不能像 plt.plot(x, y) 那样直接用「当前 Axes」？
本章每个示例都用 fig.add_axes((left, bottom, width, height)) 指定组件的位置与大小，再用 fig.subplots_adjust 给它腾地方；官方 widgets 文档明确说 Matplotlib 不会替你决定组件该多宽多高，要自己算。
8. 在 Jupyter 里跑本章代码，图出来了但滑块拖不动、完全是静态的。最该先排查的是？
本章开头第一段代码就是 %matplotlib widget。官方交互文档说明：Notebook 默认的 inline 后端是「渲染一次并插入静态图片」，不能平移缩放、不能接收用户输入、也不能被其他单元格更新；要交互必须装 ipympl 并切到 widget 后端。
9. 要给一张分析图做调参面板：连续调节一个系数、按需显隐 3 条曲线、偶尔精确输入一个阈值、还要一个恢复默认的按钮。最合适的组合是？
选型看交互语义：连续数值用 Slider；多个独立开关用 CheckButtons；精确输入用 TextBox；一次性动作用 Button；RadioButtons 是互斥单选，用来显隐多条曲线会出现「只能显示一条」的语义错误。
