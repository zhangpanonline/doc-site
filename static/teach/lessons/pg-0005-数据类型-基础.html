本课目标

完成本课后，你将能：

  1. 分清 varchar(n) / char(n) / text 的语义与 n 的单位（字符不是字节），说出 text 是 PG 原生字符串类型
  2. 解释 timestamp 与 timestamptz 的时区差异（内部存 UTC），为跨时区应用正确选型
  3. 说出钱的类型标准答案（numeric）与浮点的陷阱
  4. 识别超长字符串截断、DateStyle 解析歧义等官方细节陷阱

知识速览

先花几分钟把核心机制过一遍——细节与测验依据都来自官方文档 §8.3 与 §8.5。

字符类型三兄弟（官方要点）

  • varchar(n) 有限变长 · char(n) 定长补空格 · text 无限变长
  • n 是字符数不是字节数（官方原文：characters, not bytes）
  • 超长行为：直接存超长报错（多余全空格则截断）；显式转换则静默截断
  • text 是 PG 原生字符串类型（官方：内置函数多接受/返回 text）；varchar 不带长度 = 任意长度

日期时间与时区

  • timestamp（不带时区）存字面时间；timestamptz（带时区）内部存 UTC、按会话时区展示
  • 精度 p 控制秒的小数位（0~6）；interval 可限字段集合（YEAR TO MONTH 等）
  • DateStyle：模糊日期 01/02/03 按 MDY/DMY/YMD 解析——跨客户端格式不一致的坑

数值选型速记

  • 整数 smallint(2B)/integer(4B)/bigint(8B)，默认 integer
  • 钱 = numeric(precision, scale)（精确十进制）；float 是近似值，钱不能用浮点

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与官方文档覆盖的内容。

🌱 初级测验 · 概念

1. varchar(10) 里的 10 是指？
官方原文：这两种类型都可以存储长度最多为 n 个字符（不是字节）的字符串——10 个汉字也能存。
2. 官方说 PostgreSQL 的「原生」字符串类型是？
官方原文：text 是 PostgreSQL 的原生字符串数据类型——大多数内置字符串函数都声明为接受或返回 text。
3. 存金额（钱）的官方推荐类型是？
numeric 做精确十进制运算；浮点（real/double）是近似值，金额用浮点会出现 0.1+0.2 类误差。

🌿 中级测验 · 应用

4. timestamptz 内部存的是什么？
带时区的 timestamp 内部存 UTC，读取时按会话时区转换展示——跨时区应用的默认选择。
5. 往 varchar(5) 直接存储 6 个字符的字符串，会怎样？
官方原文：超长存储导致错误，除非多余的字符全是空格则截断；但显式转换时超长值被静默截断——两种路径行为不同。
6. 跨时区团队存「事件发生的当地时间」，该用？
「当地时间」语义不随查看者时区改变——用不带时区的 timestamp；「绝对时刻」用 timestamptz。

🎯 高级测验 · 综合

7. AI 建表给「备注」列用了 char(255)。审查：有什么问题？
char(n) 固定长度、填充空格——短值比较时空格差异是经典坑；现代实践用 text（无长度限制）或 varchar(n)（要限制）。
8. 客户端上报的日期字符串「01/02/03」被解析错乱，最可能的原因？
官方原文：模糊的日/月/年顺序用 DateStyle 控制（MDY=月日年、DMY=日月年、YMD=年月日）——前后端格式约定不一致的经典坑。
9. varchar 不写长度（n 缺省）会怎样？
官方原文：如果 character varying 未指定长度，则该类型接受任意长度的字符串。

最终考核

四道题覆盖本课全部要点——答完它们，数据类型基础就过关了。

考核一：订单表字段选型——订单号（定长 20 位字符）、备注（不限长）、金额、创建时刻（绝对时间）。最佳组合是？
定长业务编号用 varchar(20) 限长；不限长备注用 text（原生）；金额用 numeric；绝对时刻用 timestamptz。
考核二：char(3) 存 'ab'，查询 WHERE c = 'ab' 却查不到，为什么？
char(n) 固定长度填充空格——'ab' 实际存为 'ab '，比较时的空格语义就是 char 类型被现代实践抛弃的原因。
考核三：想把「秒」精确到毫秒（3 位小数）的 timestamp，怎么写？
官方原文：time/timestamp/interval 接受可选精度 p，指定秒域小数点后的位数（0~6）。
考核四：varchar(5) 列里 CAST('abcdef' AS varchar(5)) 会怎样？
官方原文：显式转换为 varchar(n)/char(n) 时，超长值被截断为 n 个字符而不报错——与直接存储的行为不同。

四道考核全部答对，说明你掌握了数据类型基础——继续学习 pg-06 · 数据类型 · 数组与 jsonb。
