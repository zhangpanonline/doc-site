知识速览

神经网络是目前机器学习领域最常见、最重要的实现智能的手段，而学习神经网络，一切要从神经元开始。先用几分钟把本章的骨架过一遍——细节都在《03.神经元》里，测验和面试会考。

神经元的数学模型

  • 起点：1943 年，Warren McCulloch（神经科学家）与 Walter Pitts（逻辑学家）为神经元建立了数学模型；经过几十年发展，今天每个神经元的数学模型是 $y = \sigma(\sum_{i=1}^n w_i x_i + b) = \sigma(w_1 x_1 + w_2 x_2 + ... + w_n x_n + b)$
  • 输入值：$[x_1, x_2, ... x_n]$——输入值中的每一个分量表示某一个维度的信息
  • 输出值 / 激活值：一个标量——单个神经元接受一个向量、输出一个标量
  • 公式是逐分量配对的：$w_i$ 只和第 $i$ 个输入分量 $x_i$ 相乘；求和的顺序不影响结果，但权重与维度的对应关系不能打乱

权重、偏置与参数

  • 权重 $[w_1, w_2, ... w_n]$：每个权重表示该维度信息的重要程度（它是带符号的——负权重表示该维度与输出负相关，不是「不重要」）
  • 偏置 $b$：改变被激活的阈值——加上 $b$ 之后，加权和要越过 $-b$ 这个门槛，神经元才输出有效值
  • 参数：权重和偏置的统称。参数（权重和偏置）唯一决定了该神经元的输出是否正确
  • 易错：偏置必须加在加权和里面再送进激活函数，也就是 $\sigma(\sum w_i x_i + b)$；写成 $\sigma(\sum w_i x_i) + b$ 是另一回事（见第 9 题）

激活函数与三条总结

  • $\sigma$ 是激活函数，决定了是否输出有效值；经典激活函数 $ReLU(z)=max(0, z)$
  • 激活函数是固定的——它不是参数，不参与训练；能与梯度一起被更新的只有权重和偏置
  • 本章「总结」三条：① 单个神经元，接受一个向量，输出一个标量；② 激活函数是固定的；③ 参数（权重和偏置）唯一决定了该神经元的输出是否正确
  • 换个说法记住分工：σ 决定「怎么判断」，参数决定「判断得对不对」

分级测验

🌱 初级测验 · 概念

1. 在公式 $y = \sigma(\sum_{i=1}^n w_i x_i + b)$ 中，$b$ 是什么？
课件「神经元」小节的定义：偏置 b 的作用是「改变被激活的阈值」。输入值是 $[x_1, ..., x_n]$，σ 是激活函数，y 是输出值/激活值。
2. 「单个神经元」接收什么、输出什么？
课件「总结」第一条：单个神经元，接受一个向量，输出一个标量。输入 $[x_1, ..., x_n]$ 是 n 个分量，输出 y 是标量——第 8、9 题都建立在这条上。
3. 课件里说的「参数」指的是什么？
课件原文：参数——权重和偏置的统称。激活函数 σ 是固定的，输入与输出更不是参数。

🌿 中级测验 · 应用

4. 某神经元先用 ReLU 做激活，加权和记为 $z = \sum_{i=1}^n w_i x_i + b$。把 $b$ 从 0 调到 $-3$，同一个输入 x 的输出会怎样变化？
ReLU 只在输入为正时才有非零输出（$max(0, z)$），所以输出非零的条件是 $\sum w_i x_i + b > 0$，即 $\sum w_i x_i > -b$——门槛是 $-b$。$b=0$ 时门槛是 0；$b=-3$ 时门槛变成 3，同一个输入更难被「激活」。这正是课件说的「偏置改变被激活的阈值」。
5. 同事引用「每个权重表示该维度信息的重要程度」，接着说：「所以权重为负的维度就是不重要的维度，等于被忽略了」。这个推论哪里错了？
在 $z = \sum w_i x_i + b$ 里，$w_i$ 是带符号的系数：$w_i$ 为负意味着 $x_i$ 越大 z 越小，这是方向，不是「不重要」。激活函数作用在整个加权和上（ReLU 把 z 为负的样本整体压成 0），不会去单独处理某一个维度。
6. 一个训练好的神经元，权重 $w = [0.5, -1, 2]$ 依次对应输入维度 $[年龄, 收入, 点击次数]$。现在只把权重顺序改成 $[2, -1, 0.5]$（把「年龄」和「点击次数」的权重对调），输入不变，输出会怎样？
公式 $y = \sigma(\sum_{i=1}^n w_i x_i + b)$ 是逐分量配对求和：$w_i$ 只与 $x_i$ 相乘。加法本身有交换律，但「哪个权重配哪个维度」不对应，加权和就换了含义、数值也随之改变。这也是课件「参数唯一决定了该神经元的输出是否正确」的具体体现。

🎯 高级测验 · 综合

7. 某神经元 σ 取 ReLU，$w = [1, 1]$、$b = -1$。输入 $x = [0.4, 0.4]$ 与 $x = [2, 2]$ 时，输出分别是？
先算加权和、再加偏置、最后整体过激活函数：$x=[0.4,0.4]$ 时 $z = 0.4+0.4-1 = -0.2$，ReLU 把负值压成 0；$x=[2,2]$ 时 $z = 2+2-1 = 3$，ReLU 原样输出 3。选 0.8/4 是漏了偏置，选 -0.2 是漏了激活函数。
8. 一个神经元的输入 x 有 768 维，业务上只希望「年龄」这一维影响输出。应当怎么设置参数？
$z = \sum w_i x_i + b$：$w_i = 0$ 意味着该维度贡献恒为 $0 \times x_i = 0$，与 $x_i$ 的取值无关，于是只有非零权重的维度真正进入加权和。剩下的由偏置决定被激活的阈值（见第 4 题）。这也说明权重不是「装饰性」的重要程度——它直接决定哪个维度参与计算。
9. AI 写了一个神经元，代码是 return np.maximum(0, w @ x) + b（先激活再加偏置）。判断这段代码。
课件的公式是 $y = \sigma(\sum w_i x_i + b)$：σ 作用在「加权和 + 偏置」这个整体上。写成 $\sigma(\sum w_i x_i) + b$ 时，本该输出 0 的负样本会输出 b（偏置被放到了截断之外），神经元失去「不激活就不输出有效值」的语义。另外 w @ x 与 np.dot(w, x) 对 1-D 数组是等价的，不是 bug。
