对象的类型

本课目标

完成本课后，你将能：

  1. 说出「object 是万物之根、type 是万物之源」的含义
  2. 预测 type() / isinstance() 在类、实例、函数、type、object 上的结果

知识速览

先花几分钟把核心机制过一遍——细节都在《7.对象的类型》里，测验和考核会考。

类型世界的两条链

继承链：object 是万物之根 ───▶ 所有类最终都继承 object
创建链：type 是万物之源 ───▶ 所有类都由 type 创建（含 type 自己）

⚙️ 一条线索记忆：type(type) → type（type 是自己的实例）；type.__base__ → object（type 继承自 object）。

三个要点

  1. 类的类型是 type，实例的类型是类：type(A) → type；type(a) → A。创建类的类叫元类，默认就是 type。官方文档：Metaclasses
  2. 类成员的查找顺序：① 自身的 MRO 链条 → ② 元类的 MRO 链条；实例成员：① 自身 → ② 类型的 MRO 链条。
  3. 私有成员的三种下划线：_a 约定私有（外部可访问）；__a 名称改写（外部访问报错）；__a__ 系统内置成员。官方教程：Private Variables

基础测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。

1. 所有类的类型（即创建类的类）是？
创建类的类称为元类，默认是 type：type(Dog) → <class 'type'>。详见「类型与元类」一节。
2. type(type) 的结果是？
type 是自己的元类：type(type) → type（自指）。同时 type.__base__ → object——type 继承自 object。详见「验证 type 与 isinstance 的关系」一节。
3. isinstance(type, object) 的结果是？
Python 3 中所有类都继承 object，type 也不例外——isinstance(type, object) → True。等价判断：issubclass(type, object) 也是 True。
4. 类 A 中定义 __a = 2，外部执行 A.__a 会发生什么？
双下划线开头（且不以双下划线结尾）的 __a 会被改写为 _A__a，外部访问 A.__a 抛 AttributeError；访问 A._A__a 才能拿到 2。详见「类中的私有成员」一节。
5. class D(B, C) 且 B、C 都继承 A，D.__base__ 是？
__bases__ 是全部直接父类 (B, C)；__base__ 取其中的第一个——B。详见「MRO」一节。
6. 类成员（如类属性）的查找顺序是？
类成员先沿自身 MRO（父类链）查找，找不到再沿元类 MRO查找。实例成员则是：自身 → 类型的 MRO 链条。详见「成员的查找顺序」一节。

最终考核

下面是《7.对象的类型》源课程作业（demo1.py 逐行预测）的四道改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里算出答案，再点击核对。

📣 源作业还要求费曼复述：用你自己的话讲清楚「object 是万物之根，type 是万物之源」和「实例/类成员的查找顺序」，讲不通的地方回到对话里让 AI 老师给你反馈。

考核一（demo1.py·object 段）：print(type(object)) 的输出是？
object 也是一个类，而所有类都由 type 创建：type(object) → <class 'type'>。object 是继承链终点，但创建它的仍是 type。
考核二（demo1.py·type 段）：print(isinstance(type, function)) 的输出是？（function = type(lambda: None)）
type 是一个类，不是函数对象——isinstance(type, function) → False。虽然 type 可以像函数一样调用（type("Dog", (), {})），但它的类型是 type 而不是 function。
考核三（demo1.py·类与实例段）：print(isinstance(A, A))（A 是一个类）的输出是？
isinstance(A, A) 问「A 这个对象是 A 的实例吗」——A 是类，它的实例是 a（isinstance(a, A) → True）；A 本身是 type 的实例，不是 A 的实例 → False。对比：issubclass(A, A) 恒为 True。
考核四（demo1.py·function 段）：print(isinstance(function, function)) 的输出是？
function 类本身的类型是 type（所有类都由 type 创建），不是 function——isinstance(function, function) → False。而普通函数对象 func 才是 function 的实例：isinstance(func, function) → True。
