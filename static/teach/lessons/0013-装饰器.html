本质与语法糖

func ─ 传入 ─▶ decorator ─ 返回 ─▶ wrapper（替代原函数）

⚙️ @my_decorator 等价于 say_hello = my_decorator(say_hello)——装饰器在定义时就执行，wrapper 在调用时才执行。

三个要点

  1. wrapper 要接住参数并返回结果：用 def wrapper(*args, **kwargs) 接收任意参数，并 return func(*args, **kwargs) 把原函数的结果传出去——丢了 return，被装饰函数的返回值就变成 None。
  2. 叠加顺序：从下到上应用，从上到下包裹：@a @b 等价于 func = a(b(func))，调用时 a 的外层逻辑最先执行。官方文档：Function Definitions
  3. 装饰器会替换函数元信息：wrapper 的 __name__ 是 "wrapper"——用 functools.wraps(func)（或自己实现 wraps 装饰器）把 __name__/__doc__ 复制过来。官方文档：functools.wraps

🌱 初级测验 · 概念

1. 装饰器本质上是什么？
装饰器是一个可调用对象：接收一个可调用对象（函数），返回另一个可调用对象（wrapper）来替代它。详见「装饰器的本质」一节。
2. @my_decorator 写在函数上方，等价于？
@my_decorator 是语法糖：def f(): ... 之后自动执行 f = my_decorator(f)。详见「装饰器本质示例」。
3. functools.wraps(func) 的作用是？
装饰后 f.__name__ 默认变成 "wrapper"；functools.wraps(func) 把 __name__、__doc__ 等元信息复制到 wrapper 上，保持函数身份。本课作业二就是手写实现它。

🌿 中级测验 · 应用

4. @decorator_a @decorator_b 两个装饰器叠加，执行顺序是？
@a @b 等价于 func = a(b(func))：调用时 a 的外层先执行，然后是 b 的外层，再原函数，返回时逆序。详见「多个装饰器叠加」一节。
5. 带参数的装饰器 @repeat(3) 的结构是？
三层结构：repeat(n) 先执行并返回真正的装饰器 decorator，再由它去包装函数——@repeat(3) 等价于 func = repeat(3)(func)。源课程答案 p3.py 即此模式。
6. timer 装饰器的 wrapper 中忘了 return func(...)，被装饰函数调用返回什么？
wrapper 没有 return 时默认返回 None——slow_function() 就拿不到 "Done" 了。所以计时装饰器既要打印耗时，也要 return result。

🎯 高级测验 · 综合

7. 装饰器本体（非 wrapper）里的代码什么时候执行？
装饰器本体在 @deco 一行（即定义函数时）就执行——所以注册类、收集函数等副作用逻辑要放在装饰器本体；「每次调用都执行」的逻辑必须放进 wrapper。放错位置是装饰器的经典 bug 源。
8. @repeat(3) 等价于下列哪个表达式？
repeat(3) 返回装饰器 decorator，再作用到 func 上——两步合成 func = repeat(3)(func)。这就是「带参数装饰器 = 三层函数」的等价形式。
9. 类装饰器 @Dec 装饰函数 f 之后，f 是什么？调用 f(1, 2) 会触发什么？
@Dec 等价于 f = Dec(f)——f 变成 Dec 的实例（原函数存进实例属性）。之后 f(1, 2) 触发的是 Dec.__call__(实例, 1, 2)——类装饰器的核心正是第 9 课的 __call__。
