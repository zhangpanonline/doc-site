Transformer的完整训练流程

配合《12.Transformer的完整训练流程》使用预计 15–20 分钟9 道分级测验 + 面试实战

本课目标

完成本课后，你将能：

  1. 按顺序说清单个 Transformer Block 的六个阶段：多头注意力（含 RoPE）→ 残差（Add）→ 归一化（Norm）→ FFN → 残差（Add）→ 归一化（Norm）
  2. 解释两次残差连接与 RMSNorm 各自解决什么问题，以及为什么 Block 的输入输出都是 $4×6$
  3. 算出线性变换层把 $4×6$ 变成 $4×120000$ 时权重矩阵的形状与参数量，并说清 Softmax 之后得到的是什么
  4. 复述「原始语料 → 下一个 token 作标签 → 反向传播更新全部参数」这条自监督训练闭环

知识速览

先花几分钟把一个 Block 的六步、形状契约与训练闭环过一遍——细节都在《12.Transformer的完整训练流程》里，测验和面试会考。

一个 Transformer Block 的六个阶段（顺序不能乱）

  • ① 多头注意力：现代大模型还会在这一步注入 token 位置信息，算法是旋转位置编码（RoPE），针对的矩阵是 Q 和 K，时机是多头切分之后、注意力得分计算之前
  • ② 残差连接（Add）：把注意力阶段得到的「残差」和它的输入相加，得到 $4×6$ 的矩阵
  • ③ 归一化（Norm）：用 RMSNorm（均方根归一化）把大部分数据归一化到 $[-3,3]$ 之间，主要是为了防止梯度爆炸和梯度消失，得到 $4×6$ 的矩阵
  • ④ 前馈网络 FFN：为了提升模型复杂度、引入非线性激活函数。FFN 权重矩阵里不同行（神经元）相当于存了不同的「知识片段」或「模式模板」，上下文命中就激活对应输出；不同大模型在这一层设计不同，比如 DeepSeek V4 Pro 在这里用了 MoE（混合专家模型）。输出 $4×6$ 的矩阵（它仍然表达一个残差）
  • ⑤ 残差连接（Add）：把 FFN 阶段的残差和它的输入相加，得到 $4×6$ 的矩阵
  • ⑥ 归一化（Norm）：再一次 RMSNorm，把大部分数据归到 $[-3,3]$，得到 $4×6$ 的矩阵 —— ✅ 单个 Transformer Block 全部完成

形状契约与「上下文」是怎么攒出来的

  • 进出一致：单个 block 接收 $4×6$ 的矩阵、输出 $4×6$ 的矩阵。中间经过大量运算，可以让输出的每一行都包含大量上下文信息
  • 逐层堆叠：把输出再传给下一个 block，循环往复。DeepSeek v4 pro 拥有 61 个 Transformer Block
  • 最后一行信息最全：最终最后一个 block 的输出，它的每一行都表达了一个完整的上下文
  • 契约稳定：注意力负责把别的位置的信息混进来，残差负责把原信息原样带下去——所以 block 内部怎么改（例如把 FFN 换成 MoE），对外仍是 $4×6$ 进、$4×6$ 出，61 层才串得起来

从隐藏状态到「下一个 token 的概率」，再到反向传播

  • 线性变换层：大多数模型的这一层就是一个单层全连接神经网络，它把一个 $4 × 6$ 的矩阵变成 $4 × 120000$ 的矩阵（120000 就是词表大小）
  • 权重矩阵形状：按 $y = xW$ 的写法，$x$ 是 $4×6$、输出是 $4×120000$，所以 $W$ 是 $6×120000$（参数量 720000，不含偏置）；PyTorch 的 nn.Linear(6, 120000) 算的是 $y = xA^T + b$，内部存的是转置后的 $A$，形状 $120000×6$——同一组参数的两种写法
  • 每一行的含义：该层输出的每一行表达了「对于当前上下文，下一个 token 的可能性」，数值越大、可能性越高；线性变换之后再经过 Softmax 归一化，就得到下一个 token 的概率分布
  • 自监督 + 反向传播：程序读取原始语料，拿到每一个上下文对应的下一个 token 作为标签，进行反向传播，从而调整整个 Transformer 架构里边的所有参数——标签由语料自己错开一位产生，不需要人工标注

分级测验

🌱 初级测验 · 概念

1. Transformer Block 里，「多头注意力」之后紧接着的两步，顺序是？
课件「Transformer Block」的六步顺序：① 多头注意力 → ② 残差连接（Add）→ ③ 归一化（Norm）→ ④ FFN → ⑤ 残差连接（Add）→ ⑥ 归一化（Norm）。注意每一步都得到 $4×6$ 的矩阵，残差加的是子层的输入，归一化跟在残差之后。
2. 单个 Transformer Block 接收一个 $4×6$ 的矩阵，它输出的矩阵形状是？
课件原文：对于单个 Transformer block，它接收一个 4×6 的矩阵，输出一个 4×6 的矩阵；经过中间的大量运算，它可以让输出结果的矩阵每一行都包含大量的上下文信息。变成 $4×120000$ 是最后线性变换层干的事，不是 block 内部的事。
3. 课件说 RMSNorm（均方根归一化）把「大部分」数据归一化到哪个区间？
课件两步归一化的原文都是「将大部分数据归一化到 $[-3,3]$ 之间」——注意是「大部分」而不是「保证全部落在区间内」，这是数值量级的经验观察，不是硬约束；它的目的是防止梯度爆炸和梯度消失。

🌿 中级测验 · 应用

4. 线性变换层把 $4×6$ 的矩阵变成 $4×120000$ 的矩阵。按 $y = xW$ 的写法，这一层权重矩阵 $W$ 的形状应该是？
形状必须能乘起来：$x$ 是 $4×6$，要得到 $4×120000$，$W$ 只能是 $6×120000$（参数量 720000，不含偏置）。写成 PyTorch 的 nn.Linear(6, 120000) 时，官方文档定义它算的是 $y = xA^T + b$，所以内部存的是 $A$、形状 $120000×6$——这与 $6×120000$ 是同一组参数的转置写法，别把两者当成两组参数。
5. 现代大模型在多头注意力阶段注入位置信息，用的是 RoPE（旋转位置编码）。按课件口径，它作用在哪些矩阵、在什么时机？
课件原文：使用的算法是旋转位置编码（RoPE），针对的矩阵是 Q 和 K，时机是多头切分之后、注意力得分计算之前。因为注意力得分由 Q 与 K 的点积决定，位置信息写进 Q、K 才能影响「谁该关注谁」；V 负责被加权汇总，不参与打分。
6. 输出层得到 $4×120000$ 的矩阵，其中第 3 行数值最大的那一列是「猫」。对整张矩阵做 Softmax（在词表维上归一化）之后，关于第 3 行的说法正确的是？
课件：线性变换后，再经过 Softmax 进行归一化，就可以得到下一个 Token 的概率分布。Softmax 是单调的指数归一化——它保持大小排序（最大值仍是最大值），把整行压成非负且求和为 1 的概率。它不会把其他列清零，也不是按列归一化，更不会改变排序。

🎯 高级测验 · 综合

7. 把 61 个结构相同的 block 串起来，为什么「最后一个 block 的输出，每一行都表达了一个完整的上下文」？
课件：单个 block 经过大量运算可以让输出的每一行都包含大量上下文信息，然后传给下一个 block，循环往复。机理是「注意力混合信息 + 残差保留信息」逐层叠加：注意力让每个位置看到别的位置，残差让原始信息不被冲掉，61 层下来每一行就攒满了上下文。这与参数量、复制、Softmax 位置都无关。
8. 课件说不同大模型在第 ④ 步 FFN 上设计不一样，比如 DeepSeek V4 Pro 用了 MoE。从「形状契约」看，下面哪句最准确？
课件把 FFN 描述为「提升模型复杂度」的子层，并明确「不同的大模型在这一层设计的不一样」，MoE 是其中一种设计。因为 FFN 的输出要拿去做残差相加（⑤ 步），它必须输出和输入同形状的 $4×6$；专家数量只影响这一层内部的参数与计算方式，不影响 block 对外的形状契约，也不影响残差与归一化的存在。
9. 训练代码在构造标签时写错了：把「当前 token」当成标签，而不是「下一个 token」。最可能的后果是？
课件的训练闭环是「拿到每一个上下文对应的下一个 token 作为标签」。标签与输入同一个位置时，正确答案就摆在了输入里，模型只要学会复制当前 token 就能把 loss 压下去，于是学不到「根据上下文预测下一个」的能力；形状完全合法，所以不会报错——这正是它危险的地方。
