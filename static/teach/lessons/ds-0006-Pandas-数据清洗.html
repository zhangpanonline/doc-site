Pandas - 数据清洗

配合《06.Pandas - 数据清洗》使用预计 15–20 分钟9 道分级测验 + 面试实战

本课目标

完成本课后，你将能：

  1. 用 info() / head() / dtypes / isna().sum() / value_counts() 在一分钟内说清一份数据「脏在哪」
  2. 把「26应届」这类混入的错误信息识别出来，提取成独立的「毕业年份」列
  3. 用 map() 归类学历、用 str 系列方法统一城市口径
  4. 用自定义函数 + apply() 把「3个月」「10+年」「15-30K·13薪」解析成可统计的数值
  5. 清洗完做前后对比与口径校验，说得清每一处 NaN 是「本来没有」还是「解析失败」

知识速览

先花几分钟把清洗的骨架过一遍——细节都在《06.Pandas - 数据清洗》里，测验和面试会考。

先观察，再动手：四个探针

  • df.info()：一次看全数据量、列名、非空计数、dtype——本课数据 679 行 6 列，备注列只有 222 个非空，一眼就知道它大半是空的
  • df.isna().sum()：按列数缺失。本课：昵称 3 / 学历 2 / 城市 21 / 经验 17 / 薪资 101 / 备注 457
  • df.dtypes 与 df.describe()：前者暴露类型错位（数值字段被读成字符串），后者给出数值列的 mean / std / 四分位，是发现异常值的入口
  • df[col].value_counts(dropna=False)：分类列清洗前的必做动作——不加 dropna=False 会丢掉 NaN 这一类的计数，看不到「缺了多少」
  • 核心判断：本课 6 列全是 object / str——经验和薪资这两个数值字段被读成了字符串，这就是整节课要解决的主问题

逐列清洗：五条主线

  • 应届信息提取：26应届 不是经验、也不是城市，而是毕业年份。用 str.contains(r'应届', na=False) 造掩码 → str.extract(r'(\d+)\s*应届') 取数字 → 加 2000 写进新列「毕业年份」；经验列置 0，城市等错位列置空
  • 学历归类：「本 / 本科 / 本211 / 985本」都是本科，「专 / 专科 / 大专」都是大专。用 map(edu_map) 做字典映射，映射表里没有的值自动变 NaN——「招人」「留美」这类异常值正是靠这一条被清掉；清洗后可 astype('category') 明确它是分类数据
  • 城市统一：先 str.strip() 去空格，再 str.split('/').str[-1] 把「湖南/株洲」统一成「株洲」，最后用 isin(not_cities) 剔掉「焦虑型人格」「在读」「-」，「广西柳州」归一成「柳州」
  • 经验转数值：区间文本规则多，「3个月」要 ÷12、「<1年」取下限减 0.5、「10+年」取下限、「3年前端\n2年转行」两段相加——逐条 if 的规则用自定义函数 + apply() 最好读；解析不出来的（「转行」「读研」「上海」）返回 NaN
  • 薪资转数值：先做文本消歧（多行取最后一行、-> 取最新值、去掉括号里的地点说明），再换算口径：w/年 先 ×10 得千元/年、再 ÷12 得千元/月；k*15 取基本月薪；50k~60k 这类区间只取第一个数。清洗后的单位必须写进列名（薪资(k) / 经验(年)），否则下游必踩单位坑

清洗完必须验证的三件事

  • 前后对比：再跑一次 df.info()——行数应保持不变（679），变的应该是 dtype（薪资/经验变成 float64）与非空计数。行数变了，说明某一步把行吃掉或造出来了
  • 口径检查：df.describe() 看量级是否合理。薪资 max 166.7 来自「200w/年」的换算（200×10÷12），是正确换算出的极端值，处理它属于业务判断（后续单独裁剪），不属于解析错误
  • 缺失与异常分流：清洗后的 NaN 要能逐个说清来源——「备注」457 个是本来就没有，「转行/读研」变成的 NaN 是无法解析，两者不能混为一谈。这也决定了 dropna() 不能无脑用：薪资只缺 101 个，但备注缺 457 个，按行 dropna 会把 679 行砍到只剩两百多行
  • 落盘前收尾：用列表选择固定列顺序、astype('Int32') 把毕业年份转成可空整数、CSV 用 encoding='utf-8-sig' 写出（Excel 打开不乱码）

🌱 初级测验 · 概念

1. 拿到一份陌生的表格数据，课件要求的第一件事是什么？
对应《06.Pandas - 数据清洗》第 1 节「数据初探」：拿到一份新数据，先别急着动手——先「观察」。直接 dropna 会先丢掉信息（本课备注列只有 222 个非空），后面想验证都没得验。
2. 本课数据 679 行，想快速知道每一列「缺了多少个值」，最直接的一句是？
对应第 1 节：df.isna().sum() 按列统计缺失个数（昵称 3 / 学历 2 / 城市 21 / 经验 17 / 薪资 101 / 备注 457）。count() 给的是非空个数，describe() 只看数值列，duplicated() 是重复行。
3. 本课 df.info() 输出显示 6 列全部是 object / str，课件由此得出的核心结论是？
对应第 1 节原文：类型全是 object/str——数值型的字段（经验、薪资）被读成了字符串，这是我们今天要解决的核心问题。

🌿 中级测验 · 应用

4. 想把列名「薪资」「经验」改成带单位的「薪资(k)」「经验(年)」，正确写法是？
对应第 6 节结尾：df = df.rename(columns={'薪资': '薪资(k)', '经验': '经验(年)'})。选项 2 会把 7 列的名字整体覆盖成 2 个，列名个数与列数不匹配会直接报错；选项 4 是新建列，旧列还在。
5. 要取出「城市」列为北京的全部行，课件示范的写法是？
对应课件开头的 loc / iloc 说明：loc 按索引标签名定位，配合布尔条件筛选所有列写 df.loc[df["城市"] == "北京"]；iloc 只接受整数位置，所以传布尔 Series 是错的。
6. 学历列里有「本」「本科」「本211」「985本」「专」「专科」等写法，课件用什么方式归类，不认识的写法会怎样？
对应第 3 节：用 map() 做分类映射，不认识的统一设为 NaN——「招人」「留美」就是这样被清掉的。pandas 官方文档也写明：当参数是字典时，Series 中不在字典键里的值会被转换成 NaN。选项 3 是错的：category 只压缩存储，「本」和「本科」仍是两个类别。

🎯 高级测验 · 综合

7. 经验列里混进了「26应届」。课件为什么要把这列值提取成独立的「毕业年份」列，而不是直接删掉或当成 0 年经验？
对应第 2 节：它其实是「毕业年份」信息，不是该列的正常数据。统一做法是把「X应届」提取为独立的一列「毕业年份」，原列留空（经验列写 0）。清洗的原则是区分「这一列口径内的值」和「放错列的值」——放错的要搬家，不是删除；经验列写 0 也是业务约定（应届即 0 年工作经验）。
8. 薪资列出现「15-30K·13薪」时，直接套用课件里那段 parse_salary（先找 w、再找 k/k、最后找第一个 k）会发生什么？
对应第 6 节的薪资规则清单：`50k~60k` → 薪资范围，函数最终只取第一个 k 值。所以「15-30K」会被解析成 15.0（下界），「15-30K·13薪」同理——清洗口径必须先定再写代码：是取中值、取上界，还是拆成「薪资下限/薪资上限」两列外加一列「13 薪」。取第一个数是最省事的默认，但会让薪资系统性偏低，且丢掉年终奖信息。注意 parse_salary 开头的异常值判断是整串精确匹配，所以「15-30K·13薪」不会命中 '-' 分支。
9. 同事让 AI 写「把备注列里的「前端」替换成「FE」」，AI 给出的方案是在薪资清洗函数后面追加一行：df['备注'] = df['备注'].str.replace('前端', 'FE')。这次替换能跑通吗？要注意什么？
对应第 4 / 6 节的文本处理，以及 pandas 官方「Working with text data」：字符串方法「exclude missing/NA values automatically」，所以 457 个 NaN 会原样保留、不会报错；同时官方提示「Single character pattern with regex=True will also be treated as regular expressions」，所以「.」「*」这类字符做字面替换时要写 regex=False。
