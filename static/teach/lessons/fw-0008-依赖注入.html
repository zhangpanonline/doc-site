本课目标

完成本课后，你将能：

  1. 说清 IoC（思想）、DI（手段）、IoC 容器（工具）三者的关系
  2. 手写 Depends 容器并演示 override/clear_override 切换依赖

知识速览

先花几分钟把核心机制过一遍——细节都在《08.依赖注入》里，测验和面试会考。

三个概念（课件原文）

  • IoC：一种设计思想，旨在将某种选择权移交出去，从而避免与其耦合
  • DI：将 IoC 思想落地的一种手段（课件演示：把 oss_upload 作为参数传进去）
  • IoC 容器：优化 DI 的工具，它负责交付依赖项（课件 Depends 类：_overrides 表 + __call__ 查表）

FastAPI 原生 DI 三件套

  • APIRouter：prefix + tags 组织一组路径操作（products/categories/skus 三个 router）
  • Depends(get_db)：get_db 是 dependable，FastAPI 自动调用并注入返回值
  • Annotated[AsyncSession, Depends(get_db)]：类型标注 + 依赖声明合一，写入函数签名
  • 接口层分工：ProductService(db).create_product(data)；查不到 → raise HTTPException(404)

🌱 初级测验 · 概念

1. IoC、DI、IoC 容器三者是什么关系？（课件原文）
课件原文：IoC——一种设计思想，把选择权移交出去避免耦合；DI——将 IoC 落地的一种手段；IoC 容器——优化 DI 的工具，负责交付依赖项。
2. 课件第一个问题「希望切换为腾讯云怎么办」的解法是？
课件第二段代码：upload_file(user, file, oss_upload, has_permission)——依赖作为参数传入，正常/腾讯云/测试假实现三种场景只换传入的函数，upload_file 本身零改动。
3. 课件 Depends 类的 override 是做什么的？
Depends.override(original, replacement) 写入 _overrides 表；__call__ 时查表，命中就执行替代实现。clear_override 清空。演示：override(ali_oss_upload, fake_upload) 后 upload_file 自动走模拟上传。

🌿 中级测验 · 应用

4. FastAPI 里 get_db 是什么角色？
课件 api/ 三文件：db: Annotated[AsyncSession, Depends(get_db)]——FastAPI 调用 get_db() 拿到 AsyncSession 注入。get_db 在课件最终版是 async def 生成器（begin 上下文里 yield session，结束自动提交）。
5. Annotated[AsyncSession, Depends(get_db)] 拆开看，两部分各自干什么？
课件代码：Annotated 把「这个参数是什么类型」和「FastAPI 从哪拿这个参数」声明在一起——IDE 知道 db 是 AsyncSession，FastAPI 知道要先调 get_db。
6. 课件 main.py 里 docs_url/openapi_url 的写法实现了什么？
docs_url=None if common_settings.environment == "production" else "/docs"——按环境变量 conditionally 控制 OpenAPI 文档（对应 ch01 面试题「按环境开关」的正确姿势）。

🎯 高级测验 · 综合

7. APIRouter 的三个 router 是怎么注册进应用的？
课件 main.py：import 三个 router 后 app.include_router(...) 三次——main.py 只做组装，路由定义分散在各 api/ 文件。
8. API 层查到 None 时怎么处理？为什么不在 service 层抛 HTTPException？
课件 api/ 三文件统一模式：if result is None: raise HTTPException(404, detail="...")。service 保持与 HTTP 解耦（ch07 边界关注点），404/201/204 这些 HTTP 语义由接口层翻译。
9. skus.py 里挂在商品下的 SKU 路由和独立 SKU 路由怎么区分？
课件 skus.py：router = APIRouter(tags=["SKU"]) 不设 prefix，路径操作里写完整路径——商品下的 SKU 操作（POST/GET /api/products/{product_id}/skus）与独立 SKU 操作（/api/skus/{sku_id}）在同一个 router 里分组注释区分。
