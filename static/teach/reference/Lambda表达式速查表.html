lambda表达式速查表

配合《Lambda 表达式互动教学课程》与《7.lambda表达式》使用。建议打印一份放在手边。

术语表

匿名函数
没有名字的临时函数：lambda x, y: x + y。
高阶函数
接收函数作为参数的函数：map / filter / sorted / max / min / reduce。
key 参数
指定「按什么排序/比较」的取值函数，不影响返回的元素本身。
迭代器
惰性求值的对象；map/filter 返回迭代器，需 list() 展开且只能消费一次。

五个高阶函数

函数作用返回示例
map(f, xs)逐元素转换迭代器list(map(lambda x: x**2, [1,2,3])) → [1,4,9]
filter(f, xs)按条件筛选迭代器list(filter(lambda x: x>0, [-1,0,2])) → [2]
sorted(xs, key=f, reverse=?)按 key 排序新列表sorted(ws, key=lambda s: len(s))
max/min(xs, key=f)按 key 取极值元素本身max(students, key=lambda s: s["score"])
reduce(f, xs)两两累积单个值reduce(lambda x, y: x+y, [1,2,3]) → 6

组合套路（字典列表数据集）

products = [{"name": "A", "inc": "X", "price": 10, "stock": 5}, ...]

# 排序：按价格升序 / 降序 / 按库存总额
sorted(products, key=lambda p: p["price"])
sorted(products, key=lambda p: p["price"], reverse=True)
sorted(products, key=lambda p: p["price"] * p["stock"])

# 筛选 + 取字段：某公司所有产品名
list(map(lambda p: p["name"],
         filter(lambda p: p["inc"] == "X", products)))

# 极值：最贵产品
max(products, key=lambda p: p["price"])

# 聚合：某公司平均价格
xs = list(map(lambda p: p["price"],
              filter(lambda p: p["inc"] == "X", products)))
sum(xs) / len(xs)

常见误区

  • lambda 只能写一个表达式：赋值、if 语句块、多条语句都写不进去——复杂逻辑用 def。
  • map/filter 要 list() 展开：直接 print 看到的是迭代器对象。
  • 迭代器只能消费一次：同一个 map 对象转两次 list，第二次是空的。
  • max/min 返回元素本身：max(xs, key=len) 返回最长的字符串，不是长度值。
  • reduce 需要导入：from functools import reduce。
  • sorted 不修改原列表：返回新列表；原地排序用 xs.sort(key=...)。
