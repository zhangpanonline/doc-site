    items: list[T]; total: int; page: int; page_size: int

    def __init__(self, db: AsyncSession):

class ProductService(BaseService):

分页：count 总数 → offset/limit 取当页 → PageResult；更新：model_dump(exclude_unset=True) 只更新传入字段。

异常体系与边界

BusinessException
业务异常基类：message 对外 / detail 对内 / original_exception 追溯。
DatabaseException
捕获 IntegrityError 翻译成业务语言（如「关联的分类不存在」「SKU编码重复」）。
DTO 转换
from_attributes + model_validate 把 ORM 对象转 DTO。
边界规则
对外只暴露 DTO；ORM 对象只在 service 内部（_get_*_orm 私有方法）。
接口层解耦
service 不 import FastAPI 的 Request/Response/HTTPException。
