高频操作

# 列表增删改查
nums.append(4)      # 末尾添加      nums.insert(0, 0)  # 指定位置插入
nums.extend([5, 6]) # 批量添加      nums.remove(0)      # 删第一个匹配值
nums.pop()          # 删并返回末尾  nums.pop(0)         # 删并返回指定位置
nums.index(2)       # 第一个匹配位置 nums.count(2)       # 出现次数
nums.sort()         # 原地排序，返回 None！  sorted(nums)  # 返回新列表

# 元组解包
first, *rest = (1, 2, 3, 4)   # first=1, rest=[2, 3, 4]
*rest, last = (1, 2, 3, 4)    # rest=[1, 2, 3], last=4

# 字典安全访问
d.get("k")            # 键不存在返回 None（不报错）
d.get("k", "默认")     # 键不存在返回默认值
d.update({"k": 1})    # 批量更新      d.pop("k")        # 删并返回值
d.popitem()           # 删并返回最后插入的键值对

# 集合运算（方法与运算符等价）
s1 & s2     # 交集  s1.intersection(s2)
s1 | s2     # 并集  s1.union(s2)
s1 - s2     # 差集  s1.difference(s2)
s1 ^ s2     # 对称差 s1.symmetric_difference(s2)

常见误区

  • 单元素元组要加逗号：(1) 是数字 1，(1,) 才是元组。
  • 空集合是 set()：{} 创建的是空字典。
  • 字典键必须可哈希：str/int/tuple 可以，list 不行（报 TypeError）。
  • sort() 原地排序返回 None：要接返回值用 sorted()。
  • == 不是 is：== 比内容（[1,2]==[1,2] → True），is 比身份（两个独立列表 is → False）；判 None 用 is。
  • 类型不同不相等：[1, 2] == (1, 2) → False。
  • zip 以最短为准：长度不同的容器配对到最短的结束。
  • 集合无序：遍历/打印顺序不固定，别依赖顺序。
