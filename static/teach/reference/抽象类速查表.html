抽象类速查表

配合《抽象类互动教学课程》与《17.抽象类》使用。建议打印一份放在手边。

模板

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        """子类必须实现"""
        pass

    @property
    @abstractmethod          # 抽象属性：@property 在上
    def name(self):
        pass

    def describe(self):      # 普通方法：子类直接继承
        print(f"面积: {self.area()}")

class Circle(Shape):
    def __init__(self, r):
        self._r = r
        self._name = "圆"

    def area(self):          # 抽象方法必须全部实现
        return 3.14159 * self._r ** 2

    @property
    def name(self):
        return self._name

c = Circle(5)                # ✅ 全部实现，可实例化
# Shape()                    # ❌ TypeError: Can't instantiate abstract class

规则速查

场景结果
实例化抽象类TypeError
子类漏实现抽象方法子类仍是抽象类，实例化 TypeError
子类实现全部抽象方法可正常实例化
孙类继承已实现的子类可实例化（抽象方法已在父类实现）
抽象类里的普通方法子类直接继承使用
抽象属性装饰器顺序@property 在上、@abstractmethod 在下

常见误区

  • 不继承 ABC 就不是抽象类：@abstractmethod 必须配合 ABC（或其元类）才生效。
  • 抽象方法在子类里写 pass 不算实现：那只是又一个空方法（虽能实例化但丢接口意义——其实写了方法体就算实现；真正的坑是漏写）。
  • 抽象类可以有 __init__：子类用 super().__init__ 复用。
  • 类型检查配合：开启 IDE 的 typeCheckingMode，抽象接口会在编辑期提示漏实现。
