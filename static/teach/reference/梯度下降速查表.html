梯度下降速查表

配合《梯度下降互动教学课程》使用。

三个核心术语

梯度下降
沿着函数在当前点处最速下降方向（即负梯度方向）移动，使函数的值逐步减少。更新式：$\theta \leftarrow \theta - \eta \nabla L(\theta)$。
学习率
梯度下降的幅度——梯度给方向，学习率给步长。过大震荡发散，过小收敛极慢。
学习 / 训练
一个过程：在这个过程中，通过梯度下降的手段，让神经网络的参数逐步调整到最佳状态。

损失函数逐符号拆解

$$L = \frac{1}{m}\sum_{i=1}^{m}(y_i-\hat y_i)^2$$

符号名称含义与作用
$m$样本个数这一批参与计算的样本数，$i$ 从 1 遍历到 $m$
$y_i$真实值第 $i$ 个样本的标签
$\hat y_i$预测值前向传播算出的输出（上一章的内容）
$(\cdot)^2$平方保证非负、避免正负偏差互相抵消，并放大大偏差的样本
$\frac{1}{m}$取平均让损失不随批大小膨胀，batch 之间可比（均方误差里的 mean）

对预测值求导：$\frac{\partial L}{\partial \hat y_i} = -\frac{2}{m}(y_i - \hat y_i)$——误差越大，回传的梯度越大；实际步长 = 梯度 × 学习率。

一次训练迭代与学习率调参

# 一次训练迭代（顺序不能乱）
pred = model(X)           # 1. 前向传播：算出 ŷ
loss = loss_fn(pred, y)   # 2. 损失：L = (1/m) · Σ(yᵢ - ŷᵢ)²  → 一个数字
loss.backward()           # 3. 反向传播：把梯度填进每个参数的 .grad
optimizer.step()          # 4. 梯度下降：θ ← θ - η·∇L
optimizer.zero_grad()     # 5. 清零梯度，准备下一轮（否则梯度累加）
学习率过大
一步迈过谷底：损失来回震荡、甚至越来越大（发散）。
学习率过小
每步都很小：损失下降极慢，迭代很多轮也到不了最优点。
随训练衰减
前期大步、后期小步：ExponentialLR（每轮乘 gamma）、ReduceLROnPlateau（按验证指标动态降）；调度要在 optimizer.step() 之后调用。

易错点速查

现象根因处理
loss 先猛降、随后乱跳或越来越大学习率过大，步子迈过了谷底回到 1e-3 量级重新观察，再考虑加衰减调度
loss 几乎不动、下降极慢学习率过小适当调大；SGD 对特征尺度敏感，先做标准化
loss 数字突然变好看把损失整体除以了更大的常数（如 1/m → 1/m²）看梯度与更新幅度，别只看 loss 的数字
损失显示「很好」但预测很差去掉平方后正负偏差互相抵消保留平方（或绝对值），保证每一项非负
更新幅度越滚越大、方向失真循环里没有 optimizer.zero_grad()，梯度在累加backward 之前清零；测试阶段用 torch.no_grad()
