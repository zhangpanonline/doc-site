索引进阶速查表

配合《索引进阶互动教学课程》使用。来源：官方文档 §11.8 + §11.3（postgres.cn），非渡一课程内容。

部分索引

CREATE INDEX idx ON t(url, ip)
WHERE NOT (ip > '192.168.100.0' AND ip < '192.168.100.255');
要点说明
动机避免索引常见值（官方原文）
收益索引更小 + 表更新更快（不必每次都维护）
陷阱查询条件必须与谓词一致，否则走不上索引
前提常见值可预知、数据分布稳定；变化要重建

多列索引

要点官方原文
效率最高场景对前导（最左侧）列有约束时
列数上限32 列（含 INCLUDE 列）
支持类型B-tree / GiST / GIN / BRIN
INCLUDE 列非关键列随索引存储 → Index Only Scan 免回表
