RETURNING 与 UPSERT 速查表

配合《RETURNING 与 UPSERT 互动教学课程》使用。来源：官方文档 §6.4 + INSERT 命令参考（postgres.cn），非渡一课程内容。

RETURNING 三场景

场景写法返回
拿自增 idINSERT INTO users(...) VALUES (...) RETURNING id;新分配行的 id
拿更新后新值UPDATE t SET x=x+1 WHERE ... RETURNING *;修改后的新内容
批量插入拿 idINSERT INTO t SELECT ... RETURNING id;全部新行 id

UPSERT 语法骨架

INSERT INTO 表 (列...) VALUES (...)
ON CONFLICT (冲突列 | ON CONSTRAINT 约束名 | 缺省)
DO NOTHING | DO UPDATE SET 列 = EXCLUDED.列 [, ...]
[WHERE 条件]
[RETURNING ...]

术语速记

RETURNING
改完直接拿回行，避免额外查询；内容规则同 SELECT 输出列表，RETURNING * 简写。
conflict_target
冲突检测目标：列/表达式列表、ON CONSTRAINT 约束名、部分索引 WHERE 谓词、或完全缺省（任意唯一冲突）。
DO NOTHING
冲突跳过、不报错——幂等批量导入。
DO UPDATE
冲突更新；SET 支持表达式/DEFAULT/子查询/ROW；可加 WHERE 精细控制。
EXCLUDED
引用「本应插入的那行」的列值——取新来的值，区别于表中现有值。
TOCTOU 竞态
「先查后写」在并发下的时间窗口问题——UPSERT 原子化解。
