神经元速查表

配合《神经元互动教学课程》使用。

数学模型

$y = \sigma(\sum_{i=1}^n w_i x_i + b) = \sigma(w_1 x_1 + w_2 x_2 + ... + w_n x_n + b)$

1943 年，Warren McCulloch（神经科学家）与 Walter Pitts（逻辑学家）为神经元建立了数学模型；经过几十年发展，定型为上面这个式子。

符号名称含义形态
$[x_1, x_2, ... x_n]$输入值每一个分量表示某一个维度的信息向量
$y$输出值 / 激活值神经元判断的结果一个标量
$[w_1, w_2, ... w_n]$权重每个权重表示该维度信息的重要程度（带符号：负号表示负相关）向量，与输入逐分量配对
$b$偏置改变被激活的阈值标量
$\sigma$激活函数决定了是否输出有效值；经典激活函数 $ReLU(z)=max(0, z)$固定，不参与训练
$w$ 与 $b$参数权重和偏置的统称；唯一决定了该神经元的输出是否正确可训练

核心结论（本章「总结」）

输入输出
单个神经元，接受一个向量，输出一个标量。
激活函数
固定的——它决定「是否输出有效值」，但不是参数，不参与训练。
参数
权重和偏置的统称，唯一的决定了该神经元的输出是否正确。
偏置与阈值
输出非零的条件是 $\sum w_i x_i + b > 0$，即加权和越过门槛 $-b$：$b$ 变动即阈值平移（$b=0$ 门槛 0，$b=-3$ 门槛 3）。

参考实现（NumPy）与官方对照

import numpy as np

w = np.array([0.5, -1.0, 2.0])   # 权重向量 (n,)
x = np.array([1.0, 1.0, 2.0])    # 输入向量 (n,)
b = -0.5                         # 标量偏置

z = w @ x + b                    # 加权和 + 偏置（np.dot(w, x) 等价）
y = np.maximum(0, z)             # 激活函数 ReLU：max(0, z)

assert np.ndim(z) == 0           # 形状自检：单个神经元的加权和必须是标量
print(z, y)                      # 3.0 3.0

换任意激活函数（恒等、sigmoid 等）只改最后一步；σ 作用在「加权和 + 偏置」的整体上。

来源原文定义对应本章
PyTorch torch.nn.Linear"Applies an affine linear transformation to the incoming data: y = xA^T + b."加权和 + 偏置（仿射变换）；Variables 只有 weight 与 bias 两个可学量
Keras Dense"Dense implements the operation: output = activation(dot(input, kernel) + bias)"点积 + 偏置后整体过 activation；kernel/bias 是 layer 创建的可训练量
PyTorch torch.nn.ReLU"Applies the rectified linear unit function element-wise. ReLU(x) = (x)^+ = max(0, x)"经典激活函数 $ReLU(z)=max(0, z)$；逐元素作用，负值截断为 0
NumPy numpy.dot"If both a and b are 1-D arrays, it is inner product of vectors (without complex conjugation)."$\sum w_i x_i$ 用点积（np.dot / @），不是逐元素 *

易错点

  • 把激活函数当参数：σ 是固定的映射，能与梯度一起更新的只有权重和偏置；换 σ 之后参数必须重新确定。
  • 加权和写成逐元素乘：w * x + b 得到的是向量，w @ x + b 才是标量——单神经元必须输出标量。
  • 偏置加在激活函数外面：正确是 $\sigma(\sum w_i x_i + b)$；写成 $\sigma(\sum w_i x_i) + b$ 时，负样本会输出 $b$ 而不是 0。
  • 用权重符号判断重要性：负权重表示负相关（方向），绝对值大小才是影响力强度。
  • 打乱权重顺序：$w_i$ 与 $x_i$ 逐分量对应，顺序一换，加权和的含义与数值都变了。
