元类速查表

配合《元类互动教学课程》与《10.元类》使用。建议打印一份放在手边。

术语表

元类
创建类的类，默认是 type；class MyMeta(type) 自定义。
mcs
元类 __new__ 的第一参数，元类自身（类似 cls 之于类）。
namespace
类体收集到的属性字典：{'__module__': ..., '__qualname__': ..., 'bark': <function>}。
调用协议
x() 永远查找 type(x).__call__(x)。

两条时间线

事件入口元类方法
创建类（class 语句）type.__call__(MyMeta, ...)MyMeta.__new__ 执行一次
实例化（Dog()）MyMeta.__call__(Dog)MyMeta.__call__ 每次执行

三条模板

# 1. 单例元类（拦截实例化 → 重写 __call__）
class SingletonMeta(type):
    _instance = {}
    def __call__(cls, *args, **kwds):
        if cls not in cls._instance:
            cls._instance[cls] = super().__call__(*args, **kwds)
        return cls._instance[cls]

# 2. 自动注册（拦截类创建 → 重写 __new__）
class PluginMeta(type):
    registry = {}
    def __new__(mcs, name, bases, namespace):
        cls = super().__new__(mcs, name, bases, namespace)
        if name != "Plugin":
            mcs.registry[name] = cls
        return cls

# 3. 方法日志（创建前替换 namespace 中的函数）
class LogMeta(type):
    def __new__(mcs, name, bases, namespace):
        for key, value in namespace.items():
            if not key.startswith("_") and callable(value):
                namespace[key] = mcs.wrap(value)
        return super().__new__(mcs, name, bases, namespace)

常见误区

  • 元类 __new__ 必须 return：return super().__new__(mcs, name, bases, namespace)，忘了 return 类创建失败。
  • 单例要改 __call__ 不是 __new__：元类的 __new__ 只在创建类时跑一次，拦不住实例化。
  • 注册在 __new__ 里做：定义子类即触发；放在 __call__ 里则必须实例化才注册。
  • 替换要在 super().__new__ 之前：创建类前改好 namespace，新类才带上被包裹的方法。
  • 子类自动继承元类：class Child(Base) 且 Base 用 MyMeta，Child 也用 MyMeta。
  • 元类冲突：多继承两个不同元类的父类会 TypeError；解法是 class CommonMeta(MetaA, MetaB)。
