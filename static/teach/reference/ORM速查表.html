映射骨架

class Base(DeclarativeBase):
    @declared_attr.directive
    def __tablename__(cls) -> str:
        return cls.__name__.lower()

class IDMixin:
    id: Mapped[int] = mapped_column(Identity(), primary_key=True)

class TimestampMixin:
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(
        DateTime, server_default=func.now(), onupdate=func.now())

关系速查

关系机制要点
一对多ForeignKey + relationshipondelete="CASCADE" 按领域语义选
多对多Table 关系表 + secondary=纯关联用 Table；有关联字段才升级模型类

relationship 只声明关系、不影响建表；建表只认 mapped_column（课件原文）。

建表与概念

create_all
异步引擎下 conn.run_sync(Base.metadata.create_all)。
模型注册
模型被 import 才进 metadata——建表入口要 import 全部模型（noqa: F401）。
dialect
数据库方言层：连接串的 postgresql 部分；跨数据库的根源。
