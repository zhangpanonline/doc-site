装饰器速查表

配合《装饰器互动教学课程》与《11.装饰器》使用。建议打印一份放在手边。

术语表

装饰器
接收函数、返回新函数的高阶函数；@deco 即 f = deco(f)。
wrapper
装饰器返回的包装函数，替代原函数；用 *args, **kwargs 接住任意参数。
functools.wraps
把原函数的 __name__/__doc__ 等元信息复制给 wrapper。
带参装饰器
三层结构：外层收参数 → 返回装饰器 → 装饰器返回 wrapper。

三大模板

# 1. 基本装饰器（计时）
import time
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 执行时间: {time.time() - start:.4f} 秒")
        return result          # 必须 return，否则返回值丢失
    return wrapper

# 2. 元信息保留（等价于 functools.wraps）
def wraps(func):
    def decorator(wrapper):
        wrapper.__name__ = func.__name__
        wrapper.__doc__ = func.__doc__
        return wrapper
    return decorator

# 3. 带参数装饰器（重复 n 次）
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                func(*args, **kwargs)
        return wrapper
    return decorator

叠加顺序

@a
@b
def f(): ...

# 等价于 f = a(b(f))
# 调用顺序：a 外层 → b 外层 → f → b 内层 → a 内层

常见误区

  • wrapper 忘 return：被装饰函数的返回值变成 None。
  • 装饰器在定义时执行、wrapper 在调用时执行：装饰器本体里别放「每次调用都要做」的逻辑。
  • 不保留元信息：f.__name__ 变成 "wrapper"，影响调试与工具识别——用 wraps。
  • 叠加顺序记反：@a @b 是 a 包 b，不是 b 包 a。
