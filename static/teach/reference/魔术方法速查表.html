关键规则

  • 类型不符返回 NotImplemented（不是抛错）：让 Python 尝试 __rxxx__ 逆运算。
  • __setattr__/__getattribute__ 内用 object 版本：object.__setattr__(self, name, value) 绕过拦截，防无限递归。
  • __getattr__ 只兜底：常规查找失败（属性不存在）才触发。
  • 实现 __eq__ 后 __hash__ 失效：自定义 __eq__ 的类默认不可哈希，放入集合需显式处理。
  • 比较用 total_ordering：只写 __eq__ + __lt__，其余自动推导。

Fraction 模板（本课考核）

@total_ordering
class Fraction:
    def __init__(self, n, d):
        if d == 0: raise ValueError("分母不能为0")
        if d < 0: n, d = -n, -d
        g = math.gcd(abs(n), abs(d))
        self.numerator, self.denominator = n // g, d // g

    def __str__(self):  return f"{self.numerator}/{self.denominator}"
    def __repr__(self): return f"Fraction({self.numerator}, {self.denominator})"

    def __eq__(self, o):
        if not isinstance(o, Fraction): return NotImplemented
        return self.numerator == o.numerator and self.denominator == o.denominator

    def __lt__(self, o):
        if not isinstance(o, Fraction): return NotImplemented
        return self.numerator * o.denominator < o.numerator * self.denominator

    def __add__(self, o):
        if not isinstance(o, Fraction): return NotImplemented
        return Fraction(self.numerator * o.denominator + o.numerator * self.denominator,
                        self.denominator * o.denominator)

    def __float__(self): return self.numerator / self.denominator
