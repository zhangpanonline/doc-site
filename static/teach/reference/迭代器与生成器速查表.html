迭代器与生成器速查表

配合《迭代器与生成器互动教学课程》与《17.迭代器与生成器》使用。建议打印一份放在手边。

三者关系

概念协议一次性？例子
可迭代对象__iter__ 返回迭代器不一定list、range（可反复遍历）
迭代器__iter__ + __next__是list_iterator
生成器含 yield 的函数返回的对象是generator

迭代器一定是可迭代对象；生成器一定是迭代器。三者都惰性计算。

关键语法

# 生成器函数：调用不执行函数体，next() 驱动到下一个 yield
def gen():
    yield 1          # 暂停点，返回 1
    yield 2

g = gen()
next(g)              # 1；再次 next(g) → 2；再 next → StopIteration

# yield from：委托子生成器（递归扁平化）
def flatten(nested):
    for item in nested:
        if isinstance(item, list):
            yield from flatten(item)
        else:
            yield item

# send：给暂停的 yield 送值并继续
def calc():
    total = 0
    while True:
        x = yield total    # send 的值赋给 x
        if x is None: break
        total += x

c = calc()
next(c)              # 启动，yield 0
c.send(10)           # yield 10；c.send(20) → yield 30

# close：终止生成器，之后 next 抛 StopIteration
g.close()

# 生成器表达式：惰性的列表推导式
squares = (x**2 for x in range(1000000))

推导式速查

[x**2 for x in range(5)]                    # 列表推导式
{x: x**2 for x in range(5)}                 # 字典推导式
{x**2 for x in range(5)}                    # 集合推导式
(x**2 for x in range(5))                    # 生成器表达式（惰性）
[x for row in matrix for x in row]          # 嵌套：展平二维
[x for x in range(10) if x % 2 == 0]        # 带过滤
["偶" if x % 2 == 0 else "奇" for x in ...]  # 带 if-else
# 没有元组推导式！(x for x in ...) 是生成器表达式

常见误区

  • 迭代器只能遍历一次：第二次 for 循环是空的。
  • 调用生成器函数不执行函数体：先得到 generator，next 才驱动。
  • range 不是迭代器：是可迭代对象，支持索引、切片、重复遍历。
  • close 之后 next 抛 StopIteration：不是重新开始，也不是 None。
  • 元组没有推导式：(x for x in ...) 是生成器表达式。
