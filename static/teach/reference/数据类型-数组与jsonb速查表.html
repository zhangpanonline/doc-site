数组速查

操作写法
定义tags text[]（类型名加 []；尺寸声明被忽略）
字面量'{10000, 10000, 10000}'（下标从 1 开始）
元素查询'admin' = ANY(tags)
包含查询tags @> ARRAY['admin']
追加元素array_append(tags, 'new')

json vs jsonb（官方对比）

维度jsonjsonb
存储文本精准拷贝分解好的二进制格式
处理每次重新解析快很多，无需解析
索引基本不可支持（GIN）
空格/键序/重复键全部保留不保留，重复键留最后

官方结论：大多数应用应该把 JSON 存为 jsonb。

jsonb 标准姿势

CREATE INDEX ON t USING gin (meta);
-- 包含查询（走 GIN）
SELECT * FROM t WHERE meta @> '{"role": "admin"}';
-- 提取（不走 GIN，避免在过滤里用）
SELECT meta->>'role' FROM t;
