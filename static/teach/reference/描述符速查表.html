描述符速查表

配合《描述符互动教学课程》与《13.描述符》使用。建议打印一份放在手边。

术语表

描述符类
实现了 __get__ / __set__ / __delete__ 任意一个的类。
数据型描述符
实现了 __set__ 或 __delete__；优先级高于实例字典。
非数据型描述符
只实现了 __get__；实例字典可覆盖它。
__set_name__
钩子（3.6+）：类体赋值完成后调用，告诉描述符自己被赋给了哪个类的哪个属性名。

查找顺序（实例成员）

① 数据型描述符（类属性）   ← 优先级最高，压过实例字典
② 实例属性（instance.__dict__）
③ 普通类属性
④ 父类…

通过类访问描述符时，__get__ 的 instance 参数为 None。

三大模板

# 1. 只读属性（@property 无 setter）
class ImmutablePoint:
    def __init__(self, x, y):
        self._x, self._y = x, y
    @property
    def x(self):
        return self._x
    # p.x = 10 → AttributeError

# 2. 范围验证（property + setter）
class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius
    @property
    def celsius(self):
        return self._celsius
    @celsius.setter
    def celsius(self, value):
        if value < -273.15 or value > 1000:
            raise ValueError("温度超出范围")
        self._celsius = value
    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32

# 3. 访问计数器（数据型描述符）
class AccessCounter:
    _access_count = 0
    _modify_count = 0
    def __init__(self, init_value):
        self._value = init_value
    def __get__(self, instance, owner):
        AccessCounter._access_count += 1
        return self._value
    def __set__(self, instance, value):
        AccessCounter._modify_count += 1
        self._value = value

常见误区

  • 描述符必须做类属性：实例属性不会触发协议。
  • 数据描述符压过实例字典：a.__dict__["x"] = v 后读 a.x 仍走 __get__。
  • 通过类覆盖描述符：MyClass.my_attr = 20 直接把类属性换成普通值，描述符失效。
  • 惰性计算缓存要写回实例：非数据描述符 __get__ 里 setattr(instance, name, value) 缓存结果，第二次直接走实例字典。
  • property 就是数据描述符：getter/setter/deleter 语法糖背后仍是描述符协议。
