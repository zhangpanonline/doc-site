部署-k8s速查表

配合《部署-k8s互动教学课程》使用。源课程：gitee.com/dev-edu/python-framework。

工具链

ACS
托管 k8s 集群（duyi-cluster，已有 VPC + 2 个带 pod 的交换机）。
kubectl
命令行入口；get nodes 验证连通。
Helm
包管理器；upgrade --install + --set 注入配置。
版本纪律
镜像不用 latest，用版本号 tag。

关键命令

# 镜像拉取凭证
kubectl create secret docker-registry acr-registry-secret \
  --docker-server=<acr内网地址> --docker-username=<用户名> \
  --docker-password="$ACR_PASSWORD"

# 带密钥部署
helm upgrade --install duyi-service ./k8s \
  --set secret.dbPassword="$DB_PASSWORD" \
  --set secret.jwtSecretKey="$JWT_SECRET_KEY"

# 验证
kubectl get pods

流量链路

  1. 域名 CNAME → ALB DNS（公网入口）
  2. ALB：443 证书终结 TLS；80 重定向 443
  3. ALB Ingress Controller → Ingress 规则（服务 duyi-service、端口 8080）
  4. Service（稳定入口+负载均衡）→ Pod（IP 漂移无感）

交换机分工：2 个带 pod 的给集群，2 个不带 pod 的给 ALB。
