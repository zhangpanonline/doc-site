第三方库速查表

配合《第三方库互动教学课程》与《23.第三方库》使用。建议打印一份放在手边。

pip 命令速查

pip install 包名                    # 装最新
pip install 包名==2.31.0           # 固定版本
pip install "包名>=2.20,<3.0"      # 版本范围
pip install -U 包名                # 升级
pip uninstall -y 包名              # 卸载（-y 免确认）
pip list / pip list --outdated    # 已装列表 / 可升级列表
pip show 包名                      # 包详情（版本/依赖/被谁依赖）
pip freeze > requirements.txt      # 冻结依赖
pip install -r requirements.txt   # 按清单安装
python -m pip ...                  # 用当前解释器对应的 pip（多版本共存时更稳）

版本约束符号

符号含义示例
==固定版本requests==2.31.0
>= / <=最低 / 最高限制numpy>=1.24.0
~=同系列小版本更新~=2.31.0 即 >=2.31,<3
,组合多条件>=2.20,<3.0

venv 工作流

# 1. 创建
python -m venv .venv
# 2. 激活（macOS/Linux）
source .venv/bin/activate
# 3. 装依赖
pip install -r requirements.txt
# 4. 开发完冻结
pip freeze > requirements.txt
# 5. 退出
deactivate

常见误区

  • dotenv 不是标准库：读 .env 需要 pip install python-dotenv。
  • 流式打印要 flush：print(x, end="", flush=True) 才能边到边显示。
  • .env 不进版本库：API 密钥放 .env 并加进 .gitignore。
  • 激活 venv 后再装包：未激活时 pip 装进的是全局环境。
