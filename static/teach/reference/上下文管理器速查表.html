上下文管理器速查表

配合《上下文管理器互动教学课程》与《18.上下文管理器》使用。建议打印一份放在手边。

with 的等效形式

with 表达式 as 变量名:
    代码块

# 等效于
变量名 = 表达式.__enter__()
try:
    代码块
except Exception as e:
    stopPropagation = 变量名.__exit__(type(e), e, e.__traceback__)
    if not stopPropagation:
        raise
else:
    变量名.__exit__(None, None, None)
__enter__
进入 with 时调用，返回值赋给 as 变量。
__exit__
退出时调用，收 (exc_type, exc_val, exc_tb)；返回 True = 吞异常，返回 False/None = 异常继续传播。

两种写法

# 1. 类实现（资源管理）
class TempDirectory:
    def __enter__(self):
        self.path = tempfile.mkdtemp()
        return self.path
    def __exit__(self, exc_type, exc_val, exc_tb):
        shutil.rmtree(self.path)
        return False            # 不吞异常

# 2. @contextmanager 生成器（简单场景）
from contextlib import contextmanager

@contextmanager
def timer(name):
    start = time.time()
    try:
        yield                    # 之前 = __enter__，之后 = __exit__
    finally:
        print(f"{name} 耗时: {time.time() - start:.4f} 秒")

常见误区

  • 两个方法缺一不可：只有 __enter__ 或只有 __exit__，with 会报错。
  • @contextmanager 的清理要放 finally：yield 后不在 finally 的代码，块内抛异常时会跳过。
  • 返回 True 会吞异常：SuppressError 靠这个实现「忽略指定异常」；不想吞就返回 False。
  • 多管理器一行写：with A() as a, B() as b:，按顺序进入、逆序退出。
