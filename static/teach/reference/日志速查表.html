三类日志

类型位置字段
请求中间件method / path / status_code / client_ip
数据库SQLAlchemy 事件sql / params（慢查询 warning）
业务service_logger 装饰器action / entity / entity_id

共同：message + duration_ms（自动计时）；request_id 由 ContextVar 注入全链路。

定级：请求 500→error、其余 warning；业务 BusinessException→warning、未知→error(exc) 带栈。
