Matplotlib-核心概念速查表

配合《Matplotlib-核心概念互动教学课程》使用。

三层架构对照

层是什么负责典型 API / 对象
Figure最顶层容器，一张画布整体大小、样式、布局；可含一个或多个 Axesplt.subplots(figsize=…)、fig.suptitle()、fig.add_subplot()
AxesFigure 内部的绘图区（数据画在这里）数据与坐标：画什么、范围、标题、标签、图例、脊线、注解ax.plot/bar/scatter/hist、ax.set_title/xlabel/xlim、ax.legend()、ax.spines、ax.annotate
Artist一切可见之物（连 Figure/Axes/Axis 本身都是）视觉表现：颜色、线型、透明度、大小Line2D、Patch / Rectangle、Text、Legend、Collection

关系：Figure → Axes → Artist；一个 Axes 通常含 2 个 Axis（x、y；3D 为 3 个），Axes ≠ Axis。

Figure（画布）
  ├── Axes（绘图区1）
  │     ├── Axis（X轴）  ├── Axis（Y轴）
  │     ├── Line2D（折线）├── Rectangle（柱体）
  │     ├── Text（文字）  ├── Legend（图例）└── ...
  ├── Axes（绘图区2）
  └── ...

查 API 的判据：容器/全局配置 → Figure；数据、坐标、标签、脊线 → Axes；颜色/线宽/大小 → 某个 Artist。

常用配置速记

import numpy as np
import matplotlib.pyplot as plt

# 中文字体 + 负号显示 + DPI（全局 rcParams）
plt.rcParams.update({
    "font.sans-serif": ["PingFang SC"],
    "axes.unicode_minus": False,
    "figure.dpi": 100,
})

plt.style.available          # 查看所有可选风格
plt.style.use('ggplot')      # 切换整体视觉风格
plt.style.use('default')     # 恢复默认

fig, ax = plt.subplots(figsize=(8, 4))              # 一张画布 + 一个绘图区
fig, axes = plt.subplots(2, 2, figsize=(8, 6))      # 2x2 网格 → 2D 数组
fig, (ax1, ax2) = plt.subplots(1, 2)                # 一维 → 可解包
axes[0, 1].bar([1, 2, 3], [3, 5, 2])                # 下标 [行, 列]，从 0 开始

ax.spines['top'].set_visible(False)                 # 干净风格：隐藏上、右脊线
ax.spines['right'].set_visible(False)
ax.spines[['top', 'right']].set_visible(False)      # 列表索引 = 广播代理，一次设两条
ax.spines['left'].set_color('gray')                 # 脊线也是 Artist，可改颜色/线宽
ax.spines['bottom'].set_linewidth(1.5)

ax.plot(x, np.sin(x), label='sin')                  # 有 label 才有图例条目
ax.legend()                                         # 图例来自各 Artist 的 label

ax.annotate('最大值',                                # 带箭头的注解
            xy=(5, 25),                             # 被标注的点（箭头指向）
            xytext=(4, 23),                         # 文字摆放位置
            arrowprops={"arrowstyle": "->", "color": "red"},
            fontsize=12)
ax.text(1, 20, '二次函数', fontsize=14, style='italic',
        bbox={"boxstyle": "round", "facecolor": "wheat", "alpha": 0.5})
plt.subplots(m, n)
一次拿到 Figure + m×n 个 Axes；不带参数时 ax 是单个对象，带 m,n 时 axes 是数组，取用方式不同。
ax.legend()
条目来自各 Artist 的 label=；图例不出来，先检查有没有写 label。
annotate 的 xy / xytext
xy = 箭头指向的数据点；xytext = 文字落点。两者默认都在 data 坐标系（xycoords='data'）。
spines
属于 Axes，共 4 条：top / right / left / bottom。fig.spines 不存在。
rcParams 的作用域
对整个 matplotlib 包全局生效；运行时 rc 设置优先于样式表，样式表优先于 matplotlibrc 文件。
3D 子图
plt.subplots(subplot_kw={"projection": "3d"}) 或 fig.add_subplot(111, projection='3d')。

pyplot 隐式接口 vs 面向对象（Axes）接口

维度隐式 pyplot 接口显式 Axes 接口
写法plt.plot(...)、plt.title(...)fig, ax = plt.subplots() 后 ax.plot(...)、ax.set_title(...)
状态内部维护「最后创建的 Figure / Axes」，Artist 加到它认为你要的对象上对象显式引用，没有隐藏的「当前对象」
多 Axes退回 plt.subplot(2,2,1) 或 plt.sca() 来回切换，脆弱axes[i, j] 直接定位，与调用顺序无关
细调能改，但难以稳定地改「某一个」绘图区创建后、显示前都可继续定制：脊线、注解、范围、图例位置
适用交互式试画、一次性简单脚本多子图、要复用/封装成函数、要交付给人看的图

官方口径：Axes 接口是 Matplotlib 的实现层，大量定制与微调最终都落在这层；两版混用时最容易踩的坑就是「plt.figure() 新建了画布，后一句 plt.plot 画到别处去了」。

常见坑与自查

  • 只看得到一条线 / 一张图：中途调了 plt.figure() 或 plt.subplot()，切换了「当前 Axes」。改用显式 fig, ax 并与同一个 ax 复用来画。
  • 把单个 Axes 当数组、或把 2D 数组当 Axes：plt.subplots() 返回单对象；plt.subplots(2,2) 返回 2D 数组。按网格维度判断取用方式。
  • AttributeError: 'Figure' object has no attribute 'spines'：脊线在 Axes 上，写成 ax.spines[...]。
  • 箭头指错地方：annotate 的 xy（指向）与 xytext（文字）写反了。
  • 图例是空的：绘图时漏了 label=。
  • 中文变方框 / 负号变方块：走 plt.rcParams.update({"font.sans-serif": [...], "axes.unicode_minus": False})。
  • 改了风格影响别的图：style.use() 与 rcParams 都是全局的，函数内改动会外溢；要局部生效用 plt.rc_context({...})。
