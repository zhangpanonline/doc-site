作用域速查表

配合《作用域互动教学课程》与《6.作用域》使用。建议打印一份放在手边。

术语表

作用域
变量名的可见范围，决定名字在哪里能读到、能修改。
LEGB
查找顺序：Local 局部 → Enclosing 外层函数 → Global 全局 → Built-in 内置。
全局变量
模块最外层定义的变量；函数内读取没问题，修改要 global。
闭包
内层函数捕获外层函数的变量，随外层函数返回后仍能访问。
UnboundLocalError
编译期把名字判为局部变量，但读取时还没赋值——经典作用域报错。

global 与 nonlocal

关键字指向适用场景
global x模块级全局变量函数内修改全局变量（如计数器）
nonlocal x外层函数的变量嵌套函数修改外层状态（闭包计数器、账户余额）
count = 0                # 全局

def outer():
    count = 10            # 外层函数的局部
    def inner():
        global count      # 改全局：count 0→1
        count += 1
    inner()
    print(count)          # 10 —— outer 的局部未被 inner 修改

outer()
print(count)              # 1 —— 全局被 inner 修改

闭包模板

def make_counter():
    count = 0                      # 外层状态

    def increment():
        nonlocal count             # 修改外层状态
        count += 1
        return count

    return increment               # 返回内层函数

counter = make_counter()
print(counter())   # 1
print(counter())   # 2 —— 状态保留

常见误区

  • 「先读后写」全局变量报错：函数内只要对某名字赋值，该名字就是局部变量；print(x) 后 x = 20 会抛 UnboundLocalError。
  • 读取全局不需要 global：只有修改才需要声明。
  • global 与 nonlocal 不可互换：模块级没有外层函数，nonlocal 会报错；闭包里误用 global 会改错变量。
  • 闭包状态各自独立：每次调用外层函数都创建新的变量环境，两个计数器互不影响。
  • 默认参数在定义时求值：def f(items=[]) 的列表只创建一次，多次调用共享（第 3 章陷阱的根因）。
