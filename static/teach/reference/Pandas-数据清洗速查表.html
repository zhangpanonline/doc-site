清洗六步流程

步骤动作本课（679 行招聘数据）实例
1 数据初探info() head() dtypes isna().sum() describe()6 列全是 object/str；缺失：昵称 3 / 学历 2 / 城市 21 / 经验 17 / 薪资 101 / 备注 457
2 错位信息提取str.contains() 造掩码 → str.extract() 取值 → df.loc[mask, 新列] 赋值「26应届」→ 毕业年份 2026，经验列记 0、城市列置空
3 分类映射map(映射表)；未收录值自动成 NaN；可 astype('category')本/本科/本211/985本 → 本科；招人/留美 → NaN
4 文本统一str.strip() str.split(x).str[-1] isin() 布尔索引「湖南/株洲」→ 株洲；焦虑型人格/在读/- → 空；广西柳州 → 柳州
5 数值解析自定义函数 + apply()（规则多、要读得懂时首选）3个月 → 0.3 年；10+年 → 10；200w/年 → 166.7k/月
6 结果验证前后 info()/dtypes/describe() 对比 + value_counts(dropna=False) 抽查行数仍 679，经验(年)/薪资(k) 变 float64；列名带单位后落盘

一条铁律：先定口径，再写代码——「区间薪资取中值还是下限」这类决定必须写在解析函数之前。

常见脏数据形态 → 对应方法

形态信号方法 / 判据
缺失值isna().sum() 有数；value_counts() 看不到 NaN先用 dropna=False 看见它；dropna() 默认丢「任意一个 NA 的行」，本课会把 679 行砍到两百多；fillna(0) 会伪造事实。判据：「本来没有」保留，「解析失败」回头修函数
重复值duplicated().sum() > 0；或同一昵称多条drop_duplicates(subset=[...])；先想清「哪几列相同才算同一条」——本课是招聘意愿登记，同昵称不同薪资不算重复
类型错位dtypes 里数值列是 object/str（本课经验、薪资）apply(解析函数) → astype(float)；毕业年份先转 Int32（可空整数）再落盘，否则 2026.0 会带小数点
文本格式不一首尾空格、「湖南/株洲」、全角括号、-> 多段值str.strip() → str.split() → str.replace()；.str 方法自动跳过 NaN，无需先 fillna；做字面替换时留意单字符模式会被当正则
异常值 / 假类别value_counts() 尾部出现「焦虑型人格」「招人」「留美」「？？」白名单 isin(not_cities) 剔值，或反选 ~isin(known_values)；白名单要写进代码注释，新数据来了需复查
信息错位「26应届」出现在城市/经验列搬家而不是删除：str.extract(r'(\d+)\s*应届') 提到新列，原列置 0 或空
量级 / 单位混杂同列既有 9k 又有 20w/年、k*15统一换算到同一单位（本课：千元/月，w/年 → ×10÷12），并把单位写进列名 薪资(k) / 经验(年)

import pandas as pd, numpy as np, re

df.info()                       # 行数 / 列名 / 非空计数 / dtype 一屏看全
df.head(); df.dtypes            # 前 5 行；每列类型
df.isna().sum()                 # 每列缺失个数
df.describe()                   # 数值列 count/mean/std/min/四分位/max
df[c].value_counts(dropna=False)  # 分类列清点（含 NaN 这一类）

pd.isna(x) / df.notna()         # 判定缺失：np.nan / None / NaT / pd.NA 都算
                                # 注意 s == np.nan 永远是 False，NaN 只能用 isna 判定

df.dropna(how='any'|'all', thresh=n, subset=[...])   # 默认 any：任一 NA 即丢行
df.fillna(0) / df.ffill() / df.bfill()               # 填充；（求和时 NA 视为 0）

df['经验(年)'] = df['经验'].apply(parse_experience)   # 逐值自定义函数
df['学历'] = df['学历'].map(edu_map)                  # 字典映射；未命中 → NaN
df['学历'] = df['学历'].astype('category')            # 明确分类数据，省内存
df['毕业年份'] = df['毕业年份'].astype('Int32')        # 可空整数，避免 2026.0

df[c].str.strip()/str.lower()   # 文本规整；.str 方法自动跳过 NA
df[c].str.contains('应届', na=False)                  # 造掩码，na=False 必写
df[c].str.extract(r'(\d+)\s*应届')                    # 正则提取，返回 DataFrame → [0]
df[c].str.split('/').str[-1]                          # 取最后一段（省/市 → 市）
df[c].str.replace('k', '', regex=False)               # 字面替换；正则要用 regex=True

df.loc[df['城市'] == '北京']     # 条件筛选（布尔索引，取全列）
df.iloc[0:5, 0:3]               # 纯整数位置切片
df = df.rename(columns={'薪资': '薪资(k)'})
df = df[['昵称','学历','城市','经验(年)','薪资(k)','毕业年份','备注']]   # 固定列序
df.to_csv('../linking_clean.csv', index=False, encoding='utf-8-sig')  # Excel 不乱码
df.to_excel('../linking_clean.xlsx', index=False)
解析函数骨架
if pd.isna(val): return np.nan → 精确匹配的异常值整串返回 NaN → 按规则优先级 re.search / re.findall → 都不命中返回 np.nan。
规则优先级
经验列：应届/毕业 → 0；N+年 取下限 N；<N年 取 N-0.5；N年 求和；N个月 ÷12。顺序换了结果就变，先写清单再落代码。
验证三件套
行数是否变化 → 目标列 dtype 是否 float64/category → describe() 的量级是否符合业务（薪资 25%/50%/75% ≈ 10/15/20）。
NaN 记账
每个 NaN 都要能回答「本来没有」还是「解析失败」；城市缺失从 21 涨到 41（+15 个「X应届」提走、+3 个「焦虑型人格/在读/-」、其余为拆分与空格归并）属于预期，但要逐笔记账。
