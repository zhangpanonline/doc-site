五层选型

层级目录场景
单元unit/复杂重要的函数、类（屏蔽外部）
集成integration/核心；覆盖率主力
系统e2e/system真实启动 happy path（必做）
e2ee2e主要业务功能链（必做）
冒烟不限红线五条满足任一即必做

冒烟五条红线

  1. 挂了用户立刻无法完成核心任务
  2. 90% 以上用户每天使用
  3. 其他功能的前置依赖
  4. 出错造成严重数据损失或资损
  5. 历史上经常出问题（痛点回归）

冒烟往往针对已上线、稳定运行的旧功能；未通过 = 灾难性事故。

Mock 七大能力

次数 / 参数 / 顺序
assert_called_once / assert_called_with / assert_called_before
动态返回 / 异常
side_effect = [1,2,3] / side_effect = ValueError(...)
记录 / 重置
call_args_list / reset_mock()

覆盖率 = 执行到的代码 / 全量代码；门禁例：--cov=app --cov-fail-under=80。TLD 开发先行，TDD 测试先行。
