Matplotlib-动画速查表

配合《Matplotlib-动画互动教学课程》使用。

FuncAnimation 参数表

ani = FuncAnimation(fig, update, frames=100,
                    init_func=init, blit=True, interval=50)
参数含义默认
fig要动画的 Figure必填
func每帧调用一次：func(frame, *fargs) -> iterable_of_artists，里面用 set_* 方法改数据必填
frames帧来源。可迭代对象直接用；整数等价于 range(frames)；可传无参生成器函数；None 等价于 itertools.countNone
init_func画一个干净的初始帧，第一帧之前调用一次；不传就用 frames 第一项的画法结果None
fargs传给 func 的额外位置参数（官方更推荐 functools.partial）None
save_count缓存帧数的兜底值，仅在无法从 frames 推断长度时使用（迭代器 / 生成器）None
interval显示时每帧间隔（毫秒）200
repeat播放完是否重新开始True
repeat_delay两次播放之间的等待（毫秒）0
blit只重绘变化的部分——此时 func / init_func 必须返回 Artist 序列False
cache_frame_data是否缓存每帧数据；帧对象很大或用无限生成器时设 FalseTrue
必须持有引用
返回值要赋给一个活得够久的变量（如 ani），否则 Animation 被垃圾回收、动画直接停住。
滚动窗口套式
deque(maxlen=100) 存最近 100 个点 + 无限生成器做 frames + cache_frame_data=False。
收尾清理
重跑单元格前先 ani.event_source.stop()，再 plt.close("all")。

两种动画方案对照

FuncAnimationArtistAnimation
驱动方式函数驱动：每帧调用 update(frame)数据驱动：预先准备「每帧要显示的 Artist 列表」的列表
内存画一次、之后只改数据，省内存所有帧的 Artist 都要留着，内存随帧数增长
适合长动画、实时数据流、滚动窗口；帧数多每帧内容彼此独立、需要精确控制某一帧显示什么（柱状图竞赛、条形图动画）
关键写法先 (line,) = ax.plot(...) 拿引用 → update 里 line.set_ydata(...) → return line,frames.append([line]) 逐帧收集 → ArtistAnimation(fig, frames, interval=50)
擅长更新set_data / set_ydata / set_offsets / set_text直接换一组 Artist，不用逐个改属性

一句话：省内存选 FuncAnimation，要精确控制每帧选 ArtistAnimation。

Blit 模式要点

def init():
    ax.set_xlim(0, 2 * np.pi + 5); ax.set_ylim(-1.5, 1.5)
    return line, point          # blit=True 时必须返回 Artist 序列

def update(frame):
    y = np.sin(x + frame * 0.1)
    line.set_data(x, y)
    point.set_data([x[-1]], [y[-1]])
    return line, point          # 漏了这句 → RuntimeError

ani = FuncAnimation(fig, update, frames=100, init_func=init, blit=True, interval=50)
好处
只重新绘制被动过的 Artist，而不是整个 Axes，帧率明显更高。
代价
回调必须返回所有被修改 / 新建的 Artist（返回值的用途是让 blitting 算法知道图 Figure 上哪块区域要更新）。
常见报错
update 漏返回 → When blit=True, the animation function must return a sequence of Artist objects.；init_func 漏返回 → When blit=True, the init_func must return a sequence of Artist objects.
注意
blit 下 Artist 按 zorder 绘制，但会盖在此前所有 Artist 之上——需要叠层顺序时别开 blit 或改用 ArtistAnimation。

保存动画命令速记

ani.save('sine_wave.gif', writer='pillow', fps=20, dpi=100)   # GIF：需要 pillow
ani.save('sine_wave.mp4', writer='ffmpeg', fps=30, dpi=150)   # MP4：需要另外安装 ffmpeg
ani.save('sine_wave.html', writer='html')                     # HTML：HTMLWriter
HTML(ani.to_jshtml())                                         # Notebook 里嵌 JS 动画
HTML(ani.to_html5_video())                                    # 嵌 HTML5 video（需要 ffmpeg）
writer支持格式依赖
'pillow'.gif / .apng / .webpPillow（全部帧留在内存里）
'ffmpeg'ffmpeg 支持的全部格式（.mp4 / .mkv / .mjpeg …）需另行安装 ffmpeg；管道式，性能较好
'imagemagick'imagemagick 支持的全部格式需另行安装 imagemagick
'html'.html / .htm / .png无（生成 JS 动画）
fps ≠ interval
fps 决定保存出来文件的帧率，interval 决定显示时的帧率（默认 200 ms）；save() 不传 fps 时才从 interval 推算。
dpi
保存时的每英寸点数，默认取 savefig.dpi（'figure'）；与图尺寸（英寸）共同决定成片分辨率。
writer 怎么给
可传字符串（上表五个）或一个 writer 对象；不传则取 rcParams["animation.writer"]（默认 'ffmpeg'）。
没装 ffmpeg 时
跨平台装法：pip install imageio_ffmpeg，再设 rcParams["animation.ffmpeg_path"] = imageio_ffmpeg.get_ffmpeg_exe()。
