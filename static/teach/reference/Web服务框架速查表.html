三大框架选型

框架哲学场景
Django开箱即用大型复杂应用、自带后台管理、统一方案
Flask微内核可扩展小型应用、快速原型、高度定制
FastAPI高性能现代化API 服务、微服务、AI 模型封装成 API

ASGI 协作

app(scope, receive, send) -> CoroutineType

scope   : 连接上下文字典（type/path/method/headers…）
receive : 异步函数，接收消息（请求体/客户端消息）
send    : 异步函数，发送消息（响应头体/服务端消息）

服务器：socket 通信、报文解析、事件循环、进程线程（Uvicorn 首选）。应用程序：业务逻辑。

端点与校验速记

/docs
Swagger UI——交互式测试（Try it out），开发调试用。
/redoc
ReDoc——纯阅读、惰性加载，对外发布用。
/openapi.json
FastAPI 自动生成并暴露，遵循 OpenAPI 规范。
Pydantic
数据校验与转换（'123'→123），失败抛 ValidationError；模型进 openapi.json。
async def 原则
await 只在 async def 里合法；同步阻塞库配 def（官方：跑线程池）。
