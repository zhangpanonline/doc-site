Numpy-数据操作速查表

配合《Numpy-数据操作互动教学课程》使用。

一、创建：把形状与分布一次说清

方法作用示例 → 结果
np.array从列表/嵌套列表创建np.array([[1,2],[3,4]]) → 形状 (2,2)
np.zeros / np.ones全 0 / 全 1（默认 float64）np.zeros((2,3))；np.ones((2,3), dtype=np.float32)
np.eye单位矩阵np.eye(3) → 对角线为 1 的 3×3
np.arange按步长生成，不含终点np.arange(0,10,2) → [0 2 4 6 8]
np.linspace按个数等分，默认含终点np.linspace(0,1,5) → [0. 0.25 0.5 0.75 1.]；加 endpoint=False → [0. 0.2 0.4 0.6 0.8]
np.resize改形状，元素不够时循环重复填充np.resize(np.array([1,2,3,4]), (2,3)) → [[1,2,3],[4,1,2]]

随机数：先拿生成器，再调分布

rng = np.random.default_rng(41)      # 固定种子 ⇒ 结果可复现
rng.uniform(0, 1, (2, 3))            # 均匀分布，可指定形状
rng.normal(0, 1, (2, 3))             # 正态分布
rng.integers(0, 10, (2, 3))          # 随机整数（左闭右开）

# 场景：造模拟数据测排序/筛选
prices = np.random.default_rng(42).uniform(10, 100, 10).round(2)

形状永远要写成元组：np.zeros((2, 3)) ✅ / np.zeros(2, 3) ❌（会把 3 当成 dtype）。

二、索引与切片：视图还是拷贝？

写法名称返回适用场景
arr[i] / arr[1:, 2:] / arr[:, 1]基本索引与切片视图（改它 → 改原数组）连续区间、按维度取子块
arr[[0, 2]]花式索引（整数数组）拷贝挑不连续的行/列
arr[[0,1,3], [2,1,0]]成对花式索引拷贝（长度为 3 的一维）每行各取一个指定列
arr[arr > 15]布尔索引（掩码）拷贝（拍平成一维）按条件筛选元素
切片语法
arr[start:stop:step]，stop 不包含，step 默认 1；多维用逗号分隔，:: 等价于 :。
组合条件
用 & / | / ~，每项都要加括号：arr[(arr > 10) & (arr < 30)]。
怎么判断视图/拷贝
看 arr[...].base：视图返回原数组，拷贝返回 None。强制拷贝用 .copy()。
内存提醒
从大数组里切一小块会让整块内存跟着存活（视图持有引用）——确定不再需要大数组时显式 .copy()。

三、变形、运算与统计

操作写法要点
重塑arr.reshape(3, 4) / arr.reshape(2, -1)只改形状不改数据；总元素数必须一致；-1 自动推断该维（只能出现一个）
拍平arr.ravel() / arr.flatten() / arr.reshape(-1)ravel 尽量返回视图，flatten 一定返回拷贝
转置arr.T / arr.transpose(1, 0, 2)换轴顺序；多维可指定任意轴排列
向量化运算arr + 10 · arr * 2 · arr ** 2 · arr > 2一次作用于整个数组，不要写 for 循环
数组间运算a + b · a - b · a * b · a / b逐元素；形状需广播兼容
条件替换np.where(cond, x, y)向量化 if-else；只传 cond 时返回满足条件的下标

聚合统计：axis 与 ddof

arr = np.arange(12).reshape(3, 4).astype(float)

arr.sum(), arr.mean(), arr.min(), arr.max()   # 整数组聚合
arr.sum(axis=0)   # 沿行方向压扁 → 按「列」求和 [12. 15. 18. 21.]
arr.sum(axis=1)   # 按「行」求和 [ 6. 22. 38.]
arr.argmin(), arr.argmax()                    # 最值所在的索引

# 标准差：分母是 N - ddof
arr.std()            # ddof=0 → 总体标准差 3.452052529534663
arr.std(ddof=1)      # ddof=1 → 样本标准差 3.605551275463989（Bessel 校正，值更大）
arr.std() ** 2 == arr.var()          # True：std 是 var 的平方根
arr.std(ddof=1) / arr.mean()         # 变异系数 CV：0.6276
CV 范围离散程度直观感受典型场景
< 10%非常小数据极度集中，几乎一模一样精密仪器读数、自动化零件尺寸
10% ~ 20%较小有波动但很稳定，平均值可靠成年人身高体重、日常气温
20% ~ 30%中等正常波动范围，尚可接受考试成绩、绩效评分
30% ~ 50%较大数据分散，平均值代表性下降城市房价、地区薪资水平
> 50%非常大极度分散，平均值几乎没意义股票日收益率、创业公司估值

CV 为什么有用：标准差带量纲，跨列/跨指标比较不了；CV = std/mean 无量纲，先看 CV 再决定平均值能不能代表这批数据。

四、筛选、拼接、排序与广播

操作写法要点
条件筛选np.where(scores >= 60, '通过', '不通过')x / y / condition 三者需可互相广播
取下标np.where(arr > 25)返回元组 (array([2,3,4]),)，可再 arr[indices] 取值
通用拼接np.concatenate([a, b], axis=0)axis=0 接行、axis=1 接列；其余维度必须一致
垂直/水平堆叠np.vstack([a, b]) / np.hstack([a, b])vstack 按行叠；hstack 按列接（等价 concatenate 的常用快捷键）
按切点分割np.split(arr, [1, 3])得到 [:1]、[1:3]、[3:] 三段
按列均分np.hsplit(arr, 2)横向切成左右两半
排序np.sort(arr)返回排好序的值（不改原数组）
排序下标np.argsort(arr)返回「能把它排好序的下标」，arr[np.argsort(arr)] == np.sort(arr)
原地排序arr.sort()无返回值，直接改 arr
去重np.unique(arr)返回排好序的唯一值
# 场景：销量前 3 名（argsort 才拿得到"谁"）
sales = np.array([230, 150, 890, 340, 560, 120, 670])
top3 = np.argsort(sales)[::-1][:3]     # [2 6 4]
sales[top3]                            # [890 670 560]

广播规则（Broadcasting）

# 规则：从尾部维度开始逐个比 —— 相等，或其中一个是 1 ⇒ 兼容
(3, 4) + (4,)      → (3, 4)     # 尾维 4 == 4，向量加到每一行
(3, 1) + (4,)      → (3, 4)     # 1 与 4 都含 1，两侧都可拉伸
(3, 4) + (3,)      → ValueError: operands could not be broadcast together with shapes (3,4) (3,)
                                # 尾维 4 vs 3：既不相等也没有 1
(2, 3) + (3,)      → (2, 3)     # 二维与一维：缺的维度按 1 补齐后尾维相等
matrix + col[:, None]           # 把 (3,) 变 (3,1) → 按列广播
报错怎么读
could not be broadcast together with shapes (3,4) (3,)：右对齐后第一个不兼容的那一维就是病灶，改形状（[:, None] / reshape）或改语义。
什么时候别广播
广播会把小数组概念上"拉伸"，若中间结果形状远大于输入（如 10×3 与 5×1×3 得到 5×10×3），内存会爆——此时把外层循环写回 Python 更稳。
axis 记忆法
axis=0 沿行方向压扁（结果长度 = 列数，按列统计）；axis=1 按行统计。
NaN 的存在感
数组里只要有 np.nan，sum / mean / std 全部返回 nan；先 np.isnan(x).sum() 数条数，再决定用 np.nanmean / np.nanstd 还是 np.where 填充。
