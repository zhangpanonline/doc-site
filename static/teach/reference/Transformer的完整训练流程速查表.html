Transformer的完整训练流程速查表

配合《Transformer的完整训练流程互动教学课程》使用。

单个 Transformer Block 的六个阶段（顺序不能乱）

#阶段作用 / 要点输出形状
①多头注意力（含 RoPE）让每个位置吸收别的位置的信息；现代模型在此注入位置信息，算法是旋转位置编码 RoPE，作用于 Q、K，时机在多头切分之后、注意力得分计算之前$4×6$
②残差连接 Add把注意力阶段的残差与其输入相加，原信息原样带下去$4×6$
③归一化 Norm用 RMSNorm（均方根归一化）把大部分数据归到 $[-3,3]$，防梯度爆炸/消失$4×6$
④前馈网络 FFN提升复杂度、引入非线性；FFN 权重矩阵的不同行（神经元）相当于存了不同「知识片段」，上下文命中即激活（如 DeepSeek 用 MoE 替换/扩展这一层）$4×6$
⑤残差连接 Add把 FFN 阶段的残差与其输入相加$4×6$
⑥归一化 Norm再一次 RMSNorm，单个 Block 全部完成$4×6$

形状契约：一个 block 进 $4×6$、出 $4×6$。所以内部怎么改（例如把 FFN 换成 MoE）对外都成立，才能把几十层串起来（例：DeepSeek v4 pro 有 61 个 Block）。

从隐藏状态到「下一个 token 的概率」

隐藏状态 H (4×6)
   ↓ 线性变换层（单层全连接，y = xW）
logits (4×120000)     ← 120000 = 词表大小
   ↓ Softmax
下一个 token 的概率分布

权重矩阵形状：x(4×6) · W(6×120000) = 4×120000
参数量：6 × 120000 = 720000（不含偏置）
PyTorch 等价写法：nn.Linear(6, 120000)
每一行的含义
该行表达「对于当前上下文，下一个 token 的可能性」——数值越大越可能。
Softmax 之后
得到归一化的概率分布（和为 1），才是可采样的那一张分布。

自监督训练闭环

原始语料
  → 切出上下文
  → 标签 = 同一序列错开一位的下一个 token（无需人工标注）
  → 前向传播得到预测分布
  → 与标签比较算损失
  → 反向传播，更新 Transformer 里所有参数

「上下文」是怎么攒出来的：把 block 输出再传给下一个 block，循环堆叠；注意力把别的位置的信息混进来、残差把原信息带下去，于是越靠后的层，每一行包含的上下文信息越全。

易错点

  • 把残差与归一化的顺序记反（本课件的顺序是 注意力 → Add → Norm → FFN → Add → Norm）
  • 以为 RoPE 作用在注意力计算之后（实际是切分多头之后、算得分之前，作用于 Q/K）
  • 把「形状不变」理解成「内容不变」——形状是契约，内容每层都在被改写
  • 算权重参数量时忘了它是 $6×120000$ 而不是 $4×120000$（用 $y=xW$ 的写法，$W$ 的左边是输入维度）
