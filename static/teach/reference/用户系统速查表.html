密码学四类

类别有密钥可逆代表
对称加密同一密钥可逆AES
非对称加密公钥+私钥可逆RSA、ECC
哈希算法无密钥不可逆SHA256、MD5
消息认证码同一密钥不可逆HMAC-SHA256

密码保存：bcrypt 加盐 + 多轮（hashpw/gensalt/checkpw）；JWT 签名 = 带密钥的哈希，不需加盐，payload 不加密别放敏感数据。

凭证与认证链

签发
create_token({"sub": user.id}, secret, expires_delta)；payload 含 jti/iat/exp。
过期时间
设置表 jwt_expire_minutes（默认 120）；密钥 WEB_JWT_SECRET_KEY。
认证依赖
HTTPBearer 取 token → decode（锁 HS256）→ sub 查库 → 注入 User。
业务异常
AuthException；登录失败统一话术防枚举；注册双保险（查重 + IntegrityError）。
改密
先 verify 旧密码，再 hash 新密码。
ContextVar
无参取上下文数据，并发任务互相隔离。
