构建发布速查表

配合《构建发布互动教学课程》与《29.构建发布》使用。建议打印一份放在手边。

流水线

源码 + pyproject.toml
   │  python -m build（或 uv build）
   ▼
dist/  ←── sdist（.tar.gz）+ wheel（.whl）
   │  twine check dist/*   （校验）
   ▼
twine upload dist/*       （发布到 PyPI / 私有仓库）
   │
   ▼
pip install 包名          （用户安装）

pyproject.toml 关键段

[build-system]
requires = ["hatchling"]          # 构建后端依赖
build-backend = "hatchling.build" # 后端入口

[project]
name = "duyi-utils"              # 发行版名称（小写连字符）
version = "0.1.3"                # 语义化版本
requires-python = ">=3.14"
dependencies = [
    "python-dateutil>=2.8",
]

常用命令

python -m build               # 构建（产物在 dist/）
twine check dist/*            # 校验产物
twine upload dist/*           # 上传（用 API token 认证）
pip install -e .              # 可编辑安装：.pth 链接直指源码，改码即时生效
