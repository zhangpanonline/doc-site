常用函数与关键参数

sns.histplot(data=df, x='salary', bins=30, kde=True)
sns.boxplot(data=df, x='education', y='salary', hue='city', ax=ax1)
sns.violinplot(data=df, x='education', y='salary', inner='quart')
sns.barplot(data=df, x='city', y='salary', estimator='mean', errorbar='ci')
sns.regplot(data=df, x='experience', y='salary', ci=95, ax=ax2)
sns.heatmap(df.corr(numeric_only=True), annot=True, cmap='vlag')
ax=
Axes 级函数专用：把图画进指定子图，布局交给 Matplotlib 管。
hue= / style= / size=
按额外变量分组着色 / 区分线型 / 区分点大小（分组而非分面）。
whis=
箱线图须线长度：标量表示「距最近 hinge 的 whis × IQR 内最远的点」，也可传百分位元组。
estimator= / errorbar=
barplot 等分类聚合图的统计量与误差表示（默认均值 + 置信区间）。
ci=
regplot / lmplot 的置信区间；样本越少区间越宽。
set_theme()
一次设定全局主题样式；reset_orig() 回到 Matplotlib 默认。

读图避坑三条

离群点 ≠ 脏数据
须线外只是「按 IQR 规则偏离主体」，删掉会系统性低估上限；要稳健统计就用中位数/分位数。
barplot 画的是聚合值
默认均值 + 误差棒，会掩盖分布形态与样本量差异；要看分布用箱线图/小提琴图。
相关 ≠ 因果
回归线只说明趋势与不确定性（置信带宽度反映样本量）；结论要检查组间可比性与混杂因素。
