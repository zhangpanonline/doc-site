建表选型速查

需求类型关键点
不限长文本textPG 原生字符串类型，无性能差异
限长文本varchar(n)n 是字符数不是字节数
定长编号（慎用）char(n)补空格：比较/LIKE 有坑，现代实践几乎不用
金额numeric(p, s)精确十进制；禁止 float/double
整数integer / bigint按范围选，默认 integer
绝对时刻timestamptz内部存 UTC，按会话时区展示
当地时间语义timestamp存字面值，不随时区变化

面试速记

超长两条路径
直接存储：报错（多余全空格则截断）；显式 CAST：静默截断到 n。
varchar 缺省长度
接受任意长度字符串（官方原文）。
timestamp 精度
p（0~6）控制秒的小数位，如 timestamp(3) = 毫秒。
DateStyle
模糊日期解析顺序：MDY（月日年）/ DMY / YMD——跨客户端格式坑。
钱为什么不能用浮点
浮点是二进制近似值，0.1+0.2 类误差在对账时现形。
