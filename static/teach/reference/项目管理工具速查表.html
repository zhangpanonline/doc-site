uv 替代关系

传统工具uv 命令
pipuv pip
venvuv venv
pyenvuv python install / pin
pip-toolsuv lock / uv sync
pipxuv tool / uvx
poetry/pdmuv init / add / remove
build + twineuv build / uv publish

常用命令

uv init --lib                # 库项目（src layout）
uv add requests             # 加依赖（--dev 开发依赖）
uv remove requests          # 移除依赖
uv sync                     # 按 uv.lock 重建环境
uv run python main.py       # 项目环境中运行
uv tree                     # 依赖树
uv build                    # 构建（dist/）
uv publish                  # 发布 PyPI；私有：--publish-url 地址 --username/--password
uv python install 3.12.3    # 装 Python 版本
uv python pin 3.12          # 固定项目版本（.python-version）
uvx ruff check .            # 临时运行工具（用完即弃）
uv tool install ruff        # 持久安装 CLI 工具
uv cache clean              # 清全局缓存

入口配置与 Makefile

# pyproject.toml：命令行入口
[project.scripts]
my-cli = "my_project:main"   # 命令名 = "模块:函数"

# Makefile：统一入口约定
.PHONY: test lint build
test:
	uv run pytest
lint:
	uv run ruff check .
build:
	uv build
