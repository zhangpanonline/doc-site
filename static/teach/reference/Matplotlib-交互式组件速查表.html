Matplotlib-交互式组件速查表

配合《Matplotlib-交互式组件互动教学课程》使用。

五种组件对照表

组件构造关键参数连接回调回调收到典型用途
Sliderax, label, valmin, valmax, valinit, valstepon_changed(func)当前值 val拖动调整连续数值（频率、振幅、系数）
Buttonax, label, color, hovercoloron_clicked(func)事件对象 event一次性动作：重新生成数据、重置参数
CheckButtonsax, labels, activeson_clicked(func)被切换的 label多个独立开关：多条曲线显隐
RadioButtonsax, labels, activeon_clicked(func)选中项 label一组互斥选项：切换函数 / 图表类型
TextBoxax, label, initialon_submit(func)输入文本（字符串）精确数值或自定义表达式，回车 / 失焦提交

选型口诀：连续值用 Slider，一次性动作用 Button，多个独立开关用 CheckButtons，互斥单选才用 RadioButtons，要精确输入用 TextBox。

通用四步套路

# ① 建 ax：给组件单独一块 Axes，并腾地方
fig, ax = plt.subplots(figsize=(8, 4))
fig.subplots_adjust(bottom=0.25)                 # 给底部的组件留空间
slider_ax = fig.add_axes((0.2, 0.1, 0.6, 0.03))  # (left, bottom, width, height)

# ② 建组件：结果必须赋值给变量（留住引用）
slider = Slider(ax=slider_ax, label='频率', valmin=0.1, valmax=5.0,
                valinit=1.0, valstep=0.1)

# ③ 回调：改数据（范围变了再 relim + autoscale_view）
def update(freq):
    line.set_ydata(np.sin(freq * x))
    fig.canvas.draw_idle()                       # ④ 请求重绘

slider.on_changed(update)
ax 参数
组件是画在独立 Axes 上的图形元素，位置与大小由 fig.add_axes((left, bottom, width, height)) 的四个归一化坐标决定；Matplotlib 不替你算布局。
留住引用
Slider(...) 裸调用不赋值 = 失去引用，组件会不响应且无法 on_changed / reset。官方原文：要保持响应必须保留引用。
draw_idle()
请求 GUI 事件循环回来时重绘一次；交还控制权前调用多次也只渲染一次。set_ydata / set_visible 只改数据，不重绘屏幕不会变。
valinit / valstep
valinit 是初始位置；valstep 是吸附步长（浮点数 → 吸附到其整数倍；数组 → 吸附到数组里的值）。
reset()
slider.reset() 把滑块恢复到 valinit 值——官方 Reset 按钮示例的标准写法。
数据范围联动
数据整体换了一批、y 范围会变时，回调里补 ax.relim() + ax.autoscale_view()，否则新数据可能跑出可视区。
复选框查表
回调只给 label，所以要先把 label → Line2D 建成字典：lines[label].set_visible(not lines[label].get_visible())。
单选读状态
RadioButtons.value_selected / index_selected 直接给当前选中项；CheckButtons.get_status() 一次返回全部开关状态。

组件不显示 / 拖不动 · 排查清单

现象最可能根因修法
图能出，但组件完全拖不动、是静态图Notebook 用了默认的 inline 后端（渲染一次即插静态图，不能接收输入）装 ipympl，改用 %matplotlib widget（本章第一段代码）
点了 / 拖了毫无反应，也不报错组件对象没有留住引用（裸调用，被回收）一定要 slider = Slider(...) 赋值给变量
拖了数值在变，曲线不变回调末尾少了 fig.canvas.draw_idle()在回调最后一行补重绘请求
组件压在曲线上、盖住了数据没给组件腾地方用 fig.subplots_adjust(bottom=…, left=…) 压缩主图坐标区
一拖就报 NameError回调里引用的组件变量名没定义（组件没赋值或写错名字）统一用第一步赋值的变量名读 xxx.val
文本框输入非法值就崩没做类型转换与异常保护try: freq = float(text) except ValueError: pass
点按钮换数据后曲线跑出画面坐标范围没跟着数据更新回调里 ax.relim() + ax.autoscale_view()

排查顺序：后端 → 引用 → 重绘——三步覆盖本章练习里绝大多数「组件不工作」的现场。
