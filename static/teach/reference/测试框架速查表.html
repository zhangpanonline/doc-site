三价值与三件套

三价值
防回归；保契约；提效率。
依赖
uv add --group dev httpx / pytest / pytest-asyncio。
配置
[tool.pytest.ini_options] asyncio_mode="auto"、testpaths=["test"]。
命令
make test → uv run pytest apps/web-service/test/integration/ -v。

conftest 生命周期

阶段动作
sessionstart连 postgres 库 → DROP/CREATE duyi_test_db → alembic upgrade head → 起 18000 服务器并轮询 /docs
每测试后autouse cleanup：reversed(sorted_tables) TRUNCATE ... RESTART IDENTITY CASCADE
sessionfinish停服务器 → DROP 测试库

fixtures：async_client（httpx）/ base_url / event_loop。DB_NAME 必须在 import app 之前 setdefault。

组织

两层断言
status_code（协议）+ code（业务：422001 校验 / 422002 约束 / 404001 不存在）。
