基础语法速查表

配合《基础语法互动教学课程》与《1.基础语法》使用。建议打印一份放在手边。

术语表

解释型
逐行解释执行，无需编译；写错只到运行到那一行才报错。
强类型
不同类型运算会报错（如 10 + "5"），需显式转换。
动态类型
变量类型在运行时确定，可随时改变（a = 10 后 a = "hi"）。
原子类型
int / float / complex / bool / str / NoneType，单个值的基本类型。
容器类型
存储多个数据的类型：list / tuple / dict / set（见第 2 章）。
f-string
f"..." 字符串内嵌变量与表达式：f"{a} + {b} = {a + b}"。
链式比较
a < b < c 等价于 a < b and b < c，中间的 b 只计算一次。
三元运算符
真值 if 条件 else 假值，一行完成条件取值。
海象运算符
:=（Python 3.8+）在表达式中赋值并求值：while (line := input()) != "quit"。
循环 else
循环正常结束（未被 break 打断）时执行；break 跳出则不执行。

常见误区

  • int(3.9) 是截断不是四舍五入，结果 3；四舍五入用 round(3.9)。
  • / 总是返回 float：10 / 4 → 2.5，想要 int 用 //。
  • and / or 返回操作数：0 or 5 → 5（不是 True）。
  • 空字符串是假值："" and "hello" → ""。
  • 变量名：不能数字开头、不能含连字符/空格、不能用关键字（if/for/class/...）。
  • 缩进即代码块：同一块必须一致缩进（惯例 4 空格），不用花括号。
