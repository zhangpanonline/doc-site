概念与骨架

横切关注点
跨越多个功能、可被横切的共同逻辑。
AOP
把共同逻辑分离出去，不侵入功能本身；FastAPI 中间件是其实现手段。
骨架
前置 → response = await call_next(request) → 后置 → return。

中间件形态要点
unified_response函数只包 /api/；重拼 body_iterator；弹 content-length；成功 code="0"，失败取异常处理器的 code/message

def register_middleware(app):
    for callable_obj, kwargs in MIDDLEWARES:
        if inspect.isclass(callable_obj):
            app.add_middleware(callable_obj, **kwargs)  # 类中间件
        else:
            app.middleware("http")(callable_obj)        # 函数中间件
