可调用对象速查表

配合《可调用对象互动教学课程》与《9.可调用对象》使用。建议打印一份放在手边。

调用协议

调用走什么结果
f() 函数type(f).__call__(f)执行函数体
Dog() 类type.__call__(Dog)__new__ + __init__ 实例化
obj() 实例type(obj).__call__(obj)类里定义的 __call__

统一规则：x() 永远查找 type(x).__call__(x)，不找 x 自己的 __call__ 属性。

callable() 速查

callable(len)        # True   内置函数
callable(int)        # True   类（type.__call__ 实例化）
callable(lambda: 1)  # True   lambda 函数
callable(obj)        # True   当且仅当类里定义了 __call__
callable([1, 2])     # False  列表没有 __call__
callable("hello")    # False  字符串没有 __call__

__call__ 模板（带状态的函数对象）

class Logger:
    def __init__(self, prefix):
        self.prefix = prefix
        self.log_count = 0

    def __call__(self, message):
        self.log_count += 1
        print(f"[{self.prefix}] #{self.log_count}: {message}")

error_log = Logger("ERROR")
error_log("文件未找到")      # [ERROR] #1: 文件未找到
error_log("网络连接失败")    # [ERROR] #2: 网络连接失败

# 计数器模板
class Counter:
    def __init__(self, start):
        self.start = start
        self.value = start

    def __call__(self):
        self.value += 1
        return self.value

    def reset(self):
        self.value = self.start

    def get(self):
        return self.value

常见误区

  • 实例的 __call__ 属性不会被调用：obj.__call__ = f 后 obj() 仍走类里的 __call__。
  • callable 判断的是「能不能调用」：callable(Dog) 是 True，但 callable(dog) 要类里定义了 __call__ 才是 True。
  • super().__call__() 沿 MRO：B(A) 里 super().__call__() 调 A 的 __call__——先打印子类再打印父类。
  • 状态存在实例属性里：self.xxx 是「可调用对象携带状态」的关键，与闭包捕获变量异曲同工。
