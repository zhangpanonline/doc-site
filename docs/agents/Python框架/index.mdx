# Python框架

袁进 · Python 框架：以 **FastAPI + SQLAlchemy** 为主线的后端全栈实战课程，共 24 章。

从 Web 服务框架选型与 ASGI 协作机制讲起，依次覆盖包结构优化、ORM 与数据迁移、业务逻辑分层、依赖注入、统一异常处理、中间件、测试、三层架构、文件上传、系统设置、用户系统与日志，最后完成容器化、云资产规划、k8s 与 CI/CD 的部署链路。每一章都配套一份互动教学课程（9 道分级测验 + 面试实战）与一张可打印速查表。

## 课程主线

| 阶段 | 章节 | 目标 |
| :-- | :-- | :-- |

| 数据层 | 03 初识SQLAlchemy · 04 ORM · 05 数据操作 · 06 数据迁移 | 用 ORM 建模并管理数据库演进 |
| 业务层 | 07 业务逻辑 · 08 依赖注入 · 09 统一异常处理 · 10 中间件 | 三层架构落地与横切关注点 |
| 质量保障 | 11 测试框架 · 12 测试方案 · 13 三层架构 | 测试体系与架构约束 |

| 部署上线 | 21 认识Docker · 22 云资产 · 23 k8s · 24 CICD · 25 部署总结 · 26 python收官检验 | 从镜像到流水线，完整上线并自检 |

> 编号 16（长事务和短事务）、19（AI 导购）源仓库无课件，按源保留跳号。

## 学习建议

1. **跟着 duyi-service 走**：每章的代码都是在上一步的基础上增量叠加，跳章会看不懂
2. **配套互动课**：每章一节互动课与一张速查表，测验解释都指回对应章节
3. **环境**：Python ≥ 3.12，依赖用 uv 管理；部署章节需要 Docker 与云资源

从 [01.Web服务框架](/agents/python-framework/Web服务框架) 开始。
