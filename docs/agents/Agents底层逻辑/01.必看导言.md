# 必看导言

## 为什么要学习 Agents 底层逻辑？

开发 Agent 应用时，大模型对我们来说往往是一个「黑盒」：

- 它为什么会**胡编乱造**（幻觉）？
- 为什么有时听懂了指令，有时又**答非所问**？
- `temperature`、`top_p` 这些参数到底在调什么？
- 上下文一长它就「失忆」，token 到底是怎么算的？

不懂底层，就只能背 API、抄 Prompt，出了问题无从下手。懂底层，才能：

- **写出更好的提示词**——知道模型「看」到的是什么；
- **做出更靠谱的架构**——知道模型的能力边界在哪；
- **排查线上问题**——知道概率、采样、上下文各自会引入什么偏差。

## 学什么，不学什么？

**要学**（Agents 开发用得上）：

- 神经网络的最小原理——但只到「能解释模型行为」的程度
- Transformer 的注意力机制——理解上下文与「失忆」
- token 与词嵌入——写提示词、算成本都靠它
- tools / ReAct / MCP / 子代理——Agent 的工程骨架

**不学**（用不上或另有课程）：

- 手推反向传播的完整数学证明
- 从零手写训练框架
- 大模型微调（后续《大模型微调实战》单独讲）
- 模型部署与推理优化

## 如何学习？

本课程的公式只要求「看懂」，不要求「会推」。比如梯度下降的本质一句话就能说清：

$$
\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)
$$

> 沿着损失下降最快的方向，一小步一小步地挪。

学习建议：

1. **先建立直觉，再看公式**。每一章先讲「为什么需要它」，公式只是直觉的精确化。
2. **代码是验证工具**。课程中的代码都很短，例如：

```python title="一个最小的神经元"
def neuron(x, w, b):
    """加权求和 + 激活，就是神经元的全部"""
    return max(0, w * x + b)  # ReLU 激活

print(neuron(2, 0.5, -0.3))  # 0.7
```

3. **每个概念都问一句**：它解释了大模型的哪个行为？
4. 按章节顺序学，后面的章节默认前面的概念已经建立。
