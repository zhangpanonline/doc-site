## 神经元

<img src="/img/duyi/202607081415781.png" width="100%" />
:::success 神经元
多个树突：接收信号  
单个轴突：输出信号  
轴突 = f([信号1, 信号2, 信号3, ...])  
轴突 标量（单个数字）
:::

1943年，Warren McCulloch（神经科学家）和 Walter Pitts（逻辑学家）为神经元建立了数学模型。

经过几十年的发展，最终每个神经元的数学模型变成了下面的样子：

$y = \sigma(\sum_{i=1}^n w_i x_i + b) = \sigma(w_1 x_1 + w_2 x_2 + ... + w_n x_n + b)$

- **输入值**：$[x_1, x_2, ... x_n]$

  输入值中的每一个分量表示某一个维度的信息。

- **输出值/激活值**：一个标量
  
- **权重**：$[w_1, w_2, ... w_n]$

  没个权重表示该维度的信息的重要程度
  
- **偏置**：b

  改变被激活的阈值
  
- **参数**：权重和偏置的统称

- $\sigma$：激活函数

  激活函数决定了是否输出有效值

  经典激活函数 $ReLU(z)=max(0, z)$



## 总结

核心理解如下

- 单个神经元，接受一个向量，输出一个标量
- 激活函数是固定的
- 参数（权重和偏置）唯一的决定了该神经元的输出是否正确
