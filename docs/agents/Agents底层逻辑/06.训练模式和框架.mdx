# 训练模式和框架

## 梯度下降的训练模式

![mnist_100_digits](/img/duyi/202607161711415.png)

**Stochastic Gradient Descent (SGD) 随机梯度下降**

- 每一步**只取 1 个样本**算梯度更新参数
- 梯度噪声极大，收敛震荡；早年小数据集用，现代大模型基本不用



**Full Batch Gradient Descent 全批量梯度下降**

- 每一轮更新参数：**使用全部训练集所有样本**计算损失与梯度，再更新权重
- 特点：梯度方向最稳定；大数据集显存 / 内存爆炸，迭代极慢，几乎不用于大模型训练



**Mini-Batch Gradient Descent 小批量梯度下降（大模型主流）**

- 每一步取固定数量样本（batch_size，如 32/128/1024）计算梯度更新
- 平衡稳定性与速度，显存可控，LLM、CV 模型全部默认使用

:::tip 张量
张量是神经网络中使用的数据结构，用于表示模型的参数、输入、输出等。  
0维张量：标量，如 123.456  
1维张量：向量，如 [1, 2, 3]  
2维张量：矩阵，如 [[1, 2, 3], [4, 5, 6]]  
3维张量：多维矩阵，如 [[[1, 2, 3], [4, 5, 6]]]
:::
:::tip 灾难性遗忘
为什么训练时不按照数字顺序以此训练，而是打乱？  
- 因为如果按照数字顺序训练，模型会学习到数字之间的顺序关系，而不是数字之间的关联关系。
- 这会导致模型在实际应用中，无法正确识别数字。
- 所以，我们通常会打乱样本顺序，来避免这种问题。
:::
:::tip 概念
泛化：是指模型在训练集上学习到的知识，能够泛化到新的、未见过的数据上。
- 好的泛化能力：模型在新的数据上表现良好，不会因为数据的差异而表现不佳。
- 坏的泛化能力：模型在新的数据上表现不佳，或者表现与训练集上的表现不同。  

过拟合：默认只认识训练集上的数据。  
欠拟合：模型连训练集上的数据都没认识全。
:::

## 模型

模型是训练的结果，通常以多个文件的形式存储，文件包含：

- **核心权重文件**：占99%体积
- **配置文件**：模型的网络的架构、隐藏层维度、权重精度等信息
