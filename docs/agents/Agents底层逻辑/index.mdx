# Agents底层逻辑

从神经网络的数学原理出发，一路讲到可自主规划、调用工具的 Agent 工程，共 34 章。课程以底层原理为主线：先建立神经元、前向传播、梯度下降的认知，再理解词元、词嵌入与 Transformer，最后落到一个 Agent 应用所需的提示词、会话、工具调用、MCP 与多代理编排。

## 课程主线

| 阶段 | 章节 | 主题 |
| :-- | :-- | :-- |
| 导览 | 必看导言 · AI的分类 | AI 岗位分布、课程安排与三大问题域 |
| 神经网络基础 | 神经元 · 前向传播 · 梯度下降 · 训练模式和框架 | 从单个神经元到矩阵计算与训练方式 |
| 语言与表征 | 词元 · token统计 · 神经网络的本质 · 词嵌入 | 分词、词表、矩阵运算与向量语义 |
| Transformer 原理 | 注意力机制 · Transformer的完整训练流程 · 推理机制 · 训练阶段 | 注意力、Block 结构、采样策略与训练阶段 |
| 模型接入 | 模型接口契约 · 系统提示词 · 会话 | 本地模型运行、提示词编写与上下文维护 |
| 工具与 Agent | tools · 封装tools · ReAct · Agent · Agent 搜索引擎 | 工具调用、封装、推理循环与联网搜索 |
| 能力扩展 | Skill · MCP协议 · MCP Client · Agent接入MCP · 实现MCP服务器 · Skill VS MCP · 子代理 | 技能注入、MCP 通信与并行子代理 |
| 工程化前沿 | Prompt · Context · Harness · Loop · Graph Engineering | 提示词、上下文、驾驭、循环与图编排 |

## 学习建议

1. **按顺序推进**：前面章节的矩阵与向量推导是后面注意力机制的基础
2. **配合代码课件**：Agent 工程部分的每章都给出可运行的 Python 代码
3. **概念与实现对照**：Transformer 原理部分注意区分训练态与推理态
