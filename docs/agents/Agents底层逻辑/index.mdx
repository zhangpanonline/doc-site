# Agents底层逻辑

袁进 · Agents底层逻辑：这门课回答一个问题——**你每天在用的 Agent，底下到底是怎么转的**。

路线是「自下而上」：先把神经网络与 Transformer 的原理打通（词元、注意力、推理机制、训练阶段），再一层层搭出 Agent 工程（系统提示词、会话、工具调用、ReAct 循环、Skill、MCP、子代理），最后收在五类工程方法论上（Prompt / Context / Harness / Loop / Graph）。

## 学习建议

1. **别跳过原理**：16 章之后每一章的「为什么这么设计」都指向 03–14 的机制，跳章会变成背 API
2. **跟着 agent/ 代码走**：16 章起每章都有一个 `agent/` 工程，逐章增量演进（薄课件章的真实内容在代码里）
3. **公式不用怕**：站点已支持数学排版，公式按「输入 → 运算 → 输出」的链路读即可
4. **配套材料**：源仓库另有一个 React 互动演示工程（神经元/前向传播/注意力等可视化），见 <a href="https://gitee.com/dev-edu/agent-core" target="_blank" rel="noopener">gitee.com/dev-edu/agent-core</a> 的 `HTML/`

从 [01.必看导言](/agents/Agents底层逻辑/必看导言) 开始。
