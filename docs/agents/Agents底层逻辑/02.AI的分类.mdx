# AI的分类

:::success 笔记
1. NLP、语音、CV 是 AI 的三大问题域，分别对应自然语言处理、语音识别与计算机视觉。
2. ASR（Automatic Speech Recognition）是语音识别的核心技术，主要用于将语音信号转换为文本。
3. TTS（Text To Speech）是语音合成的核心技术，主要用于将文本转换为语音信号。
4. Transformer 是一种深度学习模型架构，广泛应用于 NLP、语音和 CV 等领域。
5. * 强化学习是机器学习的一种训练方法。
   * 神经网络是机器学习的一种实现手段，深度学习（肯定是神经网络）是在神经网络之上沉淀的更多更复杂，Transformer 就是深度学习的一种具体实现。
:::
