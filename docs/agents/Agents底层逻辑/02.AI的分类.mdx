# AI的分类

本章内容源仓库以图示为主——一张分类图，外加一份 XMind 导图（源仓库未提供正文文稿）。

![AI 的分类](/img/agent-core/02-AI的分类.jpg)

## 怎么读这张图

从外到内是**包含关系**，不是并列关系：

- **人工智能（AI）**：最大的圈，一切让机器表现出智能行为的方法都算
- **机器学习（ML）**：AI 的子集，不靠人写规则，而是从数据里学规律
- **深度学习（DL）**：机器学习的子集，用多层神经网络来学
- **生成式 AI / 大模型**：深度学习里以「生成内容」为目标的那一支

后面的课程就从这张图的最内层往下钻：先讲神经网络（03–09），再讲 Transformer 与推理（10–14），最后落到 Agent 应用工程（15 起）。
