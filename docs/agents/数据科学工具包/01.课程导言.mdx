# 课程导言

## 课程内容简介

- `NumPy` & `Pandas`

  这两个库是数据分析和科学计算的基石，是 Agent 处理结构化数据的核心工具

- `Matplotlib` & `Seaborn`

  这两个库负责将枯燥的数据转化为直观的图表，是 Agent“秀出”分析成果的关键

## 课程目标

本课程为后续学习 **AI Agents 应用开发** 做准备（注意：是 Agents 应用开发，而非模型训练、微调、部署或推理）。

讲解上述四个库时，**只讲与 Agents 应用开发相关的内容**——不做统计学的系统性铺陈，也不追求可视化样式的穷举，够用、能用、能读懂 AI 给出的代码即可。

## 课程目录

本课程共 10 章，全部以 **Jupyter Notebook** 格式编写，使用 VS Code 的 Jupyter 插件运行（解释器必须选择**本工程虚拟环境**中的 Python）：

| 章 | 内容 | 核心知识点 |
| :--: | :-- | :-- |
| 01 | 课程导言 | 课程定位与四个库的分工 |
| 02 | Jupyter | uv 工程初始化、安装 Jupyter、选择虚拟环境解释器 |
| 03 | Numpy - 核心概念 | ndarray、shape、dtype、strides、axis |
| 04 | Numpy - 数据操作 | 创建、索引切片、花式/布尔索引、变形重塑、广播、数学与统计运算 |
| 05 | Pandas - 数据类型 | Series、DataFrame、从文件/数据库读取、组成结构 |
| 06 | Pandas - 数据清洗 | 真实招聘数据初探、应届/学历/城市/经验/薪资逐列清洗 |
| 07 | Matplotlib - 核心概念 | Figure / Axes / Artist 三层架构、样式、脊线、注解与图例 |
| 08 | Matplotlib - 动画 | FuncAnimation、ArtistAnimation、Blit 模式、动画保存 |
| 09 | Matplotlib - 交互式组件 | Slider、Button、CheckButtons、RadioButtons、TextBox |
| 10 | Seaborn | 薪资分布、学历与薪资、经验与薪资的统计分析 |
