# 数据科学工具包

袁进 · 数据科学工具包：为 **Agents 应用开发** 补齐数据处理与可视化能力。

四个库各司其职——**NumPy 与 Pandas 管「算」**（结构化数据的基础设施），**Matplotlib 与 Seaborn 管「看」**（把数据变成可读的图表）。课程全程使用真实招聘数据，边清洗边验证，目标是能读懂、能改造、能验证 AI 给出的数据处理代码。

## 学习建议

1. **按顺序学**：Pandas 建立在 NumPy 之上、Seaborn 建立在 Matplotlib 之上，跳章会看不懂底层行为
2. **动手跑**：课件都是 Jupyter Notebook，用 VS Code 打开并选择本工程虚拟环境的解释器
3. **配套互动课**：每章一节互动课（9 道分级测验 + 面试实战）与一张可打印速查表

从 [01.课程导言](/agents/数据科学工具包/课程导言) 开始。
