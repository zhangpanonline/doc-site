## GRANT：两种变体（官方）

官方原文：GRANT 命令有**两个基本变体**：

1. **在数据库对象上授予权限**——把表/列/视图/函数/模式等对象上的指定特权交给一个或多个角色；已授予的特权会**叠加**
2. **授予角色的成员资格**——让角色 A 成为角色 B 的成员（继承 B 的特权）

关键官方语义：

- **PUBLIC**：特权授予给**所有角色**，包括之后创建的角色——官方定义其为"隐式定义的、总是包含所有角色的组"
- 任何角色的实际特权 = **直接授予 + 所在成员角色的特权 + 授予给 PUBLIC 的特权**（三者并集）
- **WITH GRANT OPTION**：接收者可转授他人；**授权选项不能授予 PUBLIC**
- **对象拥有者默认拥有全部特权**，无需自我授权

## 行级安全（RLS）

官方原文要点（§5.8 行安全策略）：

- 表启用 `ENABLE ROW LEVEL SECURITY` 后，所有普通访问必须被**行安全策略**允许
- **表上不存在策略 → 默认否定策略：所有行不可见、不可修改**（默认拒绝是最安全的起点）
- **表的拥有者通常不受行安全策略限制**（除非 FORCE）
- 表级操作（TRUNCATE、REFERENCES）**不受行安全限制**
- 策略可针对**特定命令**（ALL / SELECT / INSERT / UPDATE / DELETE）与**特定角色**
- 策略表达式返回布尔值；**在计算任何用户查询条件之前先求值**——不返回 true 的行不被处理（多租户隔离的核心机制）

```sql
ALTER TABLE orders ENABLE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON orders
  USING (tenant_id = current_setting('app.tenant_id')::int);
```
