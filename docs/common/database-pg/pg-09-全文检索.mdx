## 全文检索的组成（官方介绍）

官方提供的类型与操作符：

- **`tsvector`**：存储预处理后的文档（分词后的词位列表）
- **`tsquery`**：表示处理过的查询（查询词 + 逻辑组合）
- **`@@`**：最重要的匹配操作符（文档是否匹配查询）
- 全文搜索**可以用索引加速**（GIN，§12.9）

官方对「文档」的定义：全文搜索系统中进行搜索的单元（一篇文章、一封邮件）——在 PG 中，文档通常是**表中一行内的一个文本字段**，或**多个字段的组合**（官方原例）：

```sql
SELECT title || ' ' || author || ' ' || abstract || ' ' || body AS doc FROM ...
```

## 基本用法

```sql
-- 文档转 tsvector
SELECT to_tsvector('english', 'The quick brown fox');
-- 查询转 tsquery
SELECT to_tsquery('english', 'quick & fox');
-- 匹配
SELECT to_tsvector('english', 'The quick brown fox')
       @@ to_tsquery('english', 'quick & fox');   -- true
```

高频要点：

- `to_tsvector` 做**分词 + 词形还原**（复数→单数等，取决于语言配置）
- tsquery 支持逻辑：`&`（与）、`|`（或）、`!`（非）
- 索引：`CREATE INDEX ON t USING gin(to_tsvector('english', body));`——查询侧必须用**完全相同**的表达式才能命中
- 中文分词需要 `pg_jieba`/`zhparser` 等扩展（内置解析器主要面向空格分词语言）
