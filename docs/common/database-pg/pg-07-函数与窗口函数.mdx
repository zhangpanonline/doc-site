## 字符串函数速选

- **`format(formatstr, ...)`**：sprintf 风格的格式化输出（官方：形式类似 C 的 sprintf）。格式说明符 `%[position][flags][width]type`——如 `format('%1$s 年龄 %2$s', name, age)`（`1$` 指定参数索引）；常用于拼日志、动态 SQL（配合 `%L`/`%I` 安全引用字面量与标识符）
- **`string_agg(expr, sep)`**：聚合函数，把组内文本串起来（如把每个部门的员工名拼成一行）
- 常用：`length` / `split_part(s, sep, n)` / `trim` / `upper/lower`

## 窗口函数：官方定义

官方原文：

> 一个**窗口函数**在一系列**与当前行有某种关联**的表行上执行一种计算。这与聚合函数有可比之处，但窗口函数**不会使多行聚合成一个单独的输出行**——行保留它们独立的标识。

官方原例（比较每位员工的工资与其所在部门的平均工资）：

```sql
SELECT depname, empno, salary,
       avg(salary) OVER (PARTITION BY depname)
FROM empsalary;
-- 每行都是「自己的 salary + 本部门的 avg」：develop 部门 avg 5020、personnel 3700、sales 4866.67
```

语法骨架：`函数(...) OVER (PARTITION BY 分组列 ORDER BY 排序列)`。

**与聚合的本质区别**：`GROUP BY` 把多行压成一行；窗口函数**每行都在**，附带"窗口"上的计算结果。

高频窗口函数：`ROW_NUMBER()`（行号）、`RANK()`/`DENSE_RANK()`（排名，并列时 RANK 跳号 DENSE_RANK 不跳）、`SUM(...) OVER (ORDER BY ...)`（累积和）。

:::warning 窗口函数的限制

窗口函数在 WHERE / GROUP BY / HAVING 之后求值——**不能直接写在 WHERE 里**（要过滤窗口结果须包一层子查询/CTE）。

:::
