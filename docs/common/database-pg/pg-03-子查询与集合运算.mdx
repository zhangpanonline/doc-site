## 子查询：查询里嵌套查询

官方文档在 §7.2 表表达式中系统介绍了子查询的四种形态：

| 形态 | 用法 | 关键语义 |
|---|---|---|
| **标量子查询** | 当做一个**值表达式**用（SELECT 列表、WHERE 比较的右侧） | 必须恰好返回一行一列，多行直接报错 |
| **FROM 子查询** | 子查询结果作为派生表参与外层查询 | 外层可继续 JOIN/过滤/聚合 |
| **EXISTS** | `WHERE EXISTS (SELECT ...)` | 存在匹配行即为真；内层列引用外层（**相关子查询**） |
| **IN** | `WHERE x IN (SELECT ...)` | 等值匹配集合；注意 NULL 三值逻辑陷阱 |

官方特别指出：**外层查询的列名范围会扩展到内层查询**——内层可以引用外层 FROM 派生的列（如 `EXISTS (SELECT c1 FROM t2 WHERE c2 > fdt.c1)` 里的 `fdt.c1`）。这种"里层引用外层"的写法叫**相关子查询**，是 EXISTS 类题目的核心。

## 集合运算：UNION / INTERSECT / EXCEPT

官方 §7.4 原文语法与语义：

```sql
query1 UNION [ALL] query2      -- 并：query2 结果附加到 query1 结果
query1 INTERSECT [ALL] query2  -- 交：两者都有的行
query1 EXCEPT [ALL] query2     -- 差：query1 有而 query2 没有的行
```

- **UNION**：附加 + **删除所有重复行**（效果同 DISTINCT）；**UNION ALL** 保留全部行（不去重、更快）
- **INTERSECT**：共同行，默认同样去重
- **EXCEPT**：差集（query1 独有的行），同样默认去重
- **并操作兼容**（官方硬性要求）：两个查询必须**返回相同数量的列，且对应列类型兼容**——列数不同或类型不兼容直接报错
