## pg_dump：SQL 转储（官方思想）

官方原文开宗明义：

> SQL 转储方法的思想是创建一个由 **SQL 命令组成的文件**——当把这个文件回馈给服务器时，服务器将利用其中的 SQL 命令**重建与转储时状态一样的数据库**。

基本用法（官方原文）：

```bash
pg_dump dbname > dumpfile          # 结果输出到标准输出
psql dbname < dumpfile             # 恢复：把文件回放给服务器
```

官方要点：

- **pg_dump 是普通客户端应用**——可以在**任何能访问该数据库的远端主机**上做备份（不用登录服务器主机）
- pg_dump 不跑任何特殊权限：**必须对备份对象有读权限**——备份整个库几乎总要以**超级用户**运行（官方原文）
- 除纯文本外，pg_dump 还支持**其他格式**（custom 等）以支持**并行恢复与细粒度的对象恢复**（如只恢复一张表）
- `pg_dumpall`：转储整个集簇（含角色与表空间）

## 面试高频

- **备份的恢复演练**：备份没测过恢复 = 没有备份（转储文件可回放才算数）
- 大数据量/停机窗口敏感 → 文件系统级备份或 PITR（官方后续章节），pg_dump 是逻辑层方案
- 恢复单张表：custom 格式 + `pg_restore -t`
