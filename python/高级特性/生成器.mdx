# 生成器

生成器是一种惰性求值的迭代器，按需产生数据，节省内存。

## yield 关键字

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for num in countdown(3):
    print(num)
# 输出: 3 2 1
```

## 生成器表达式

```python
# 类似列表推导式，但用小括号
gen = (x**2 for x in range(5))
print(list(gen))  # [0, 1, 4, 9, 16]
```

## 对比：内存占用

```python
import sys

# 列表 — 一次性创建所有元素
lst = [x for x in range(1000000)]
print(sys.getsizeof(lst))  # 约 8MB

# 生成器 — 只保存当前状态
gen = (x for x in range(1000000))
print(sys.getsizeof(gen))  # 约 200 字节
```
