# 装饰器

装饰器是一种在不修改原函数的情况下，为其增加额外功能的设计模式。

## 基本语法

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("函数执行前...")
        result = func(*args, **kwargs)
        print("函数执行后...")
        return result
    return wrapper

@my_decorator
def greet(name):
    print(f"你好, {name}")

greet("World")
# 输出:
# 函数执行前...
# 你好, World
# 函数执行后...
```

## 带参数的装饰器

```python
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def say_hello():
    print("Hello!")

say_hello()  # 打印 3 次
```
