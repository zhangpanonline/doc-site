# 流程控制

## 条件判断

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

## 循环

```python
# for 循环
for i in range(5):
    print(i)  # 0 1 2 3 4

# while 循环
count = 0
while count < 3:
    print(count)
    count += 1
```

## 推导式

```python
# 列表推导式
squares = [x**2 for x in range(5)]
# [0, 1, 4, 9, 16]
```
