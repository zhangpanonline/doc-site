# 变量与数据类型

## 变量

Python 是动态类型语言，变量不需要声明类型：

```python
name = "Python"
version = 3.13
is_stable = True
```

## 基本数据类型

| 类型 | 示例 | 说明 |
|------|------|------|
| `int` | `42` | 整数 |
| `float` | `3.14` | 浮点数 |
| `str` | `"hello"` | 字符串 |
| `bool` | `True` / `False` | 布尔值 |
| `None` | `None` | 空值 |

## 类型检查

```python
x = 42
print(type(x))  # <class 'int'>

y = "hello"
print(isinstance(y, str))  # True
```
