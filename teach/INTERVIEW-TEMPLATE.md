# 面试实战模板 v2（互动课程「💼 面试实战」小节）

2026-09-09 与用户讨论定稿。适用：**所有互动教学课程**（`teach/lessons/*.html`）的面试实战小节，含既有课程的批量改造与未来新生成课程（agents / ai-coding 等章节一律按本模板执行）。其余小节（分级测验、最终考核、知识讲解、速查表、巩固延伸）不受本模板影响。

## 1. 题型（5 类，可复合）

- 🕳️ **陷阱**——概念上的坑：预测、识别、规避
- ⚙️ **机制**——把原理讲清楚，能判断 AI 输出的对错
- 🩺 **代码审查排错**——给一段（AI 写的）代码或日志找问题
- 🏗️ **设计选型**——RAG 架构、技术选型等开放综合题
- 🤖 **AI 辅助场景**——给 AI 工具限时完成真实小任务（任务卡形态）

- 每课按弹性题数选配，无需 5 类都出；复合题按**主型**排位，题内标注副型（如 `[🤖 场景 · 含陷阱]`）。
- 取消原「中/高/专家」难度分组——理解判定由分级测验与最终考核负责，面试实战定位是练面试形态。

## 2. 展示交互（弹框单题推进）

- 弹框内**一次只展示一道题**；核对完点击「下一题」进入下一道。
- **不显示总数、不显示第几题**。
- 每题展示：题型 + 职级小标签、题干（场景题为任务卡：任务描述 + 建议用时 + 验收点）、出处。
- **作答框**：先写下自己的答案再点击核对；答案按题缓存到 localStorage（键 `interview-answer:<课程id>:<题序号>`），下次打开自动回填；作答框下提示「已自动保存到本地」，附低调的「清空本题」入口。
- 点击核对 → 展开**思路拆解**（场景题给思路拆解而非标准答案）；**用户自判，无对错校验**。
- 最后一道核对完 → 结束页「所有题做完了」+ 低调的「重新练习」入口（重走一遍，同一顺序）。

## 3. 展示顺序（固定，不随机）

陷阱 → 机制 → 代码审查排错 → 设计选型 → AI 辅助场景；同类内按职级升序；复合题按主型排位。

## 4. 职级标签

初级岗常问 / 中级岗常问 / 高级岗常问 / 专家岗常问——仅作小标签，不用于分组。

## 5. 题数

弹性：每课 4–8 道为宜，由本课素材质量决定，不硬凑、不硬砍。**不做题池、不做随机抽取**（固定题 + 弹性数量）。

## 6. 题源协议

- **A. 传统考点场景化**：考点来自牛客/CSDN 等中文题集真题 → 题干改写进 AI 环境；**改题干不改考点**；注明「考点来源 X 题 + 场景改写」。
- **B. AI 原生题源**（按可信度降序）：官方文档实践 FAQ（Anthropic/OpenAI/LangChain 等）→ 公司官方技术博客（字节/阿里等）→ 面经平台真题（牛客面经区、脉脉/小红书，需筛选）。
- 考点优先级以岗位地图 `jobsStats` 的 bossTags 词频为依据（市场标签在问什么，题就考什么）。
- 每道题标注来源层级：一手 / 二手 / 场景化改写。
- **AI 方向题每半年复核一次题源时效**（大模型迭代快，旧题易过时）。

## 7. 边界

- 不出手撕算法题（与目标岗错配）、纯行为题（归就业指导板块）。
- 代码一律实际运行验证无 bug（沿用 NOTES.md 代码校验约束）。
