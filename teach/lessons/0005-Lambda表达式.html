知识速览

先花几分钟把核心机制过一遍——细节都在《5.Lambda表达式》里，测验和考核会考。

五个高阶函数一张表

函数作用返回典型 lambda
map(f, xs)逐元素转换迭代器（要 list()）lambda x: x ** 2
filter(f, xs)按条件筛选迭代器（要 list()）lambda x: x % 2 == 0
sorted(xs, key=f)按 key 排序新列表lambda s: len(s)
max/min(xs, key=f)按 key 取极值元素本身lambda s: s["score"]
reduce(f, xs)两两累积成一个值单个值lambda x, y: x + y（在 functools）

三个要点

  1. lambda 只有一个表达式：不能写语句（赋值、if 块都不行），表达式的值自动返回。逻辑复杂就用 def。官方文档：Lambda
  2. map / filter 返回迭代器：惰性求值，必须 list(...) 才能看到结果；迭代器只能消费一次。
  3. key 参数接收的是「取值函数」：sorted(products, key=lambda p: p["price"]) 是按「每个元素的 price」排序，而不是把 lambda 结果当作元素。官方文档：sorted

分级测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。三级难度：初级考概念，中级考应用，高级考综合与陷阱。

🌱 初级测验 · 概念

1. lambda 的函数体有什么限制？
lambda 只能包含一个表达式，表达式的值自动返回（不能写 return）。lambda 是匿名函数，通常即用即走。详见「基本语法」一节。
2. list(map(lambda x: x ** 2, [1, 2, 3])) 的结果是？
map 对每个元素执行 lambda：1→1、2→4、3→9。注意 map 本身返回迭代器，打印它只会看到 <map object...>——必须用 list() 转成列表。详见「map()」一节。
3. callable(lambda: 1) 的结果是？
lambda 本质是匿名函数，函数是可调用对象 → callable 返回 True。详见第 9 课「可调用对象」的前置呼应。

🌿 中级测验 · 应用

4. list(filter(lambda x: x % 2 == 0, [1, 2, 3, 4, 5])) 的结果是？
filter 保留条件为 True 的元素：x % 2 == 0 筛选出偶数 2、4。注意它不是把条件结果返回给你，而是用条件过滤原序列。详见「filter()」一节。
5. sorted(["banana", "pie", "Washington", "book"], key=lambda s: len(s)) 的结果是？
按 len(s) 升序：pie(3) → book(4) → banana(6) → Washington(10)。key 只是「排序依据」，结果仍是原元素本身。详见「sorted()」一节。
6. max(students, key=lambda s: s["score"]) 返回的是什么？
max 按 key 比较，但返回的是元素本身——分数最高的那个学生字典（如 {'name': 'Bob', 'score': 92}）。详见「max()/min()」一节。

🎯 高级测验 · 综合

7. sorted(["banana", "pie", "book"], key=lambda s: s[-1]) 的结果是？
按最后一个字母排序：banana→a、pie→e、book→k，升序排列 → ['banana', 'pie', 'book']。key 可以是任意表达式——这是「按任意维度排序」的通用套路。详见「sorted()」一节。
8. 以下代码的输出是？ 
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])
闭包延迟绑定陷阱：lambda 捕获的是变量 i 本身而不是当时的值——列表推导完成后 i=2，三个函数调用时都读到 2 → [2, 2, 2]。修复：lambda i=i: i（默认参数绑定值）。这是真实面试高频题。
9. list(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, range(6)))) 的结果是？
由内向外读：range(6) → filter 留偶数 [0, 2, 4] → map 平方 → [0, 4, 16]。filter 与 map 可以流水线式串联，注意执行顺序是从里到外。

最终考核

下面是《5.Lambda表达式》源课程作业的改编题，数据为源课程的 products 产品列表（41 条，折叠区可见完整数据）——这就是本课的最终考核。规则：不查资料、不运行代码，先用 lambda + 高阶函数在心里算出答案，再点击核对。

考核一（作业·任务5）：找出价格最高的产品所属的公司列表（字符串列表），结果是？
先找最高价：max(products, key=lambda p: p["price"]) → MacBook Pro，14999 元，公司 APPLE。思路：max 取最高价 → filter 出价格等于最高价的产品 → map 取公司 → set 去重 → ['APPLE']。
考核二（作业·任务2）：按价格降序排序，前三个产品名是？
价格前三：MacBook Pro 14999 → Dell XPS 13 10999 → ThinkPad X1 9999。代码：sorted(products, key=lambda p: p["price"], reverse=True)[:3]。注意 reverse=True 才是降序。
考核三（作业·任务4）：XIAOMI 的所有产品共有几个？
XIAOMI 的产品：Xiaomi 14、Redmi K70、Mi Pad 6、Mi Band 8、Xiaomi Buds、Xiaomi Book——共 6 个。代码：list(filter(lambda p: p["inc"] == "XIAOMI", products)) 再取 len（或 map 出名字得字符串列表）。
考核四（作业·任务7）：APPLE 公司的产品平均价格是？
APPLE 有 5 款产品：(5999 + 14999 + 1899 + 4799 + 2999) / 5 = 30695 / 5 = 6139.0。代码：先 filter 出该公司产品 → map 出价格列表 → sum / len。
查看源课程参考答案（任务 3/4/5/7 核心写法）与完整数据 
# 按库存总额升序（价格 × 库存）
sorted(products, key=lambda p: p["price"] * p["stock"])

# XIAOMI 所有产品（字符串列表）
list(map(lambda p: p["name"], filter(lambda p: p["inc"] == "XIAOMI", products)))

# 价格最高产品的公司列表
max_price = max(products, key=lambda p: p["price"])["price"]
list(set(map(lambda p: p["inc"], filter(lambda p: p["price"] == max_price, products))))

# 每家公司平均价格
def avg(inc):
    inc_prices = list(map(lambda p: p["price"], filter(lambda p: p["inc"] == inc, products)))
    return sum(inc_prices) / len(inc_prices)

companies = set(map(lambda p: p["inc"], products))
list(map(lambda inc: {"inc": inc, "avg_price": avg(inc)}, companies))

💼 面试实战

下面是真实面试官会问的问题，选自中文互联网面试题集（出处附后）。先自己回答，再点击核对。三级面试难度：中级考应用，高级考陷阱，专家考机制与设计。

⚡ 中级面试题

面试题一（lambda 局限·高频）：关于 lambda 的使用，下列说法正确的是？
lambda 的局限：只能是单表达式，不能包含语句和赋值；适用场景是 sort/filter/map 的 key、简短回调。逻辑复杂或需要复用时应该用 def。出处：老男孩 IT 教育「Python 基础教程之最常见的面试题」
面试题二（函数式组合·高频）：把 [1, 2, 3, 4, 5] 中大于 2 的数平方，用 lambda 组合怎么写？
先 filter 再 map（由内向外）：filter(lambda x: x > 2, ...) 筛出 [3, 4, 5]，再 map(lambda x: x**2, ...) → [9, 16, 25]。第二个顺序反了（先平方再筛，条件语义错）✗；第三个语法错（if 应在 for 后）✗。这是高阶函数组合的必考题。出处：CSDN「Python 面试宝典（终极版）」

🔥 高级面试题

面试题三（多级排序·高频）：产品列表要先按公司名升序、同公司内按价格升序，正确写法是？
key 返回元组即可多级排序：先比第一项（公司），相同再比第二项（价格）→ key=lambda p: (p["inc"], p["price"])。第二个顺序反了（稳定排序下要先按次要键再按主要键，易错）✗；第三个字符串拼接没有排序语义 ✗；第四个两次 sort 顺序也需倒置 ✗。这是真实项目里字典列表排序的标配写法。出处：CSDN「Python 篇——常考的数据类型」
面试题四（排序稳定性·概念）：Python 的 sorted 是稳定排序，这个特性有什么用？
稳定排序保证相等元素的相对顺序不变——多级排序的经典技巧：先按次要键排序，再按主要键排序，两次稳定排序即得「主键 + 次键」的有序结果（不依赖 key 元组写法时用它）。出处：CSDN「Python 篇——常考的数据类型」

🧠 专家面试题

专家题一（迭代器一次性·深水区）：以下代码第二次 list(m) 的结果是？ 
m = map(lambda x: x * 2, [1, 2, 3])
print(list(m))
print(list(m))
map 返回迭代器：第一次 list 消费完毕，第二次从头再取得到空列表（迭代器无回退）。需要复用结果时先 list(m) 存下来；需要可重复遍历用推导式。这是「惰性计算」的另一面。出处：CSDN「Python 面试宝典（终极版）」
专家题二（reduce 机制）：reduce(f, xs, initial) 的第三个参数 initial 的作用是？
reduce(f, xs, initial) 把 initial 作为第一个累积值参与运算：空序列时直接返回 initial（不报错），非空时 f(f(initial, x1), x2)...。求和、求积之外，「带初始状态的折叠」是函数式编程的通用模式。出处同专家题一
