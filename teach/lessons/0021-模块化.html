知识速览

先花几分钟把核心机制过一遍——细节都在《21.模块化》里，测验和考核会考。

包、模块、成员

包（含 __init__.py 的目录） ─ 包含 ─▶ 模块（.py 文件） ─ 导出 ─▶ 成员（顶层变量/函数/类）

⚙️ 模块首次导入执行一次并缓存进 sys.modules；搜索顺序：内置模块 → 脚本目录 → PYTHONPATH → site-packages。

三个要点

  1. __all__ 控制 from 模块 import * 的清单：没进 __all__ 的公开成员星号导入不进来；下划线开头的成员本来也不会被星号导入。它同时是模块的「公开 API 文档」。官方文档：import 语句
  2. if __name__ == "__main__" 区分直接运行与导入：直接运行脚本时 __name__ 是 "__main__"，被导入时是模块名——测试代码放进这个分支。
  3. __slots__ 省内存、禁动态属性：__slots__ = ("x", "y") 后实例没有 __dict__，只能有声明过的属性——大量小对象省内存；代价是不能再随意加属性，且与多重继承等有兼容注意点。官方文档：__slots__

分级测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。三级难度：初级考概念，中级考应用，高级考综合与陷阱。

🌱 初级测验 · 概念

1. 一个 .py 文件在模块化体系中是什么？
创建 .py 文件就是定义模块：my_math.py → 模块 my_math。文件顶层的变量/函数/类是它的导出成员。详见「定义模块」一节。
2. 目录成为「包」的条件是？
目录含 __init__.py 即视为包；该文件在首次导入包时执行，可组织导出接口、做包级初始化。详见「包」一节。
3. __all__ 的作用是？
__all__ = ["PI", "add"] 只影响 from my_math import *：只有清单里的成员被导入；同时作为公开 API 的文档。整模块 import my_math 不受影响。详见「使用 __all__ 控制导出清单」一节。

🌿 中级测验 · 应用

4. 直接运行 python my_math.py 时，模块内 __name__ 的值是？
直接运行：__name__ == "__main__"；被 import：__name__ == "my_math"。用 if __name__ == "__main__": 包裹测试代码。详见「模块的 __name__ 与直接运行」一节。
5. 相对导入 from .math_ops import add 的限制是？
相对导入（. 当前包、.. 父包）只用于包内模块被导入时；直接运行含相对导入的模块会报错。详见「相对导入」一节。
6. 同一个模块被 import 三次，模块代码执行几次？
模块首次导入执行一次，之后从 sys.modules 缓存直接返回，不重复执行。详见「模块的执行与缓存」一节。

🎯 高级测验 · 综合

7. a.py 里 from b import bar；b.py 里 from a import foo。直接运行 a.py 会怎样？
a 执行到 from b import bar 时去执行 b；b 里 from a import foo 时 a 还没执行到定义 foo 的那行 → ImportError。解法：公共代码抽到第三个模块，或把导入延迟到函数内部。详见「循环导入问题」一节。
8. __slots__ = ("x", "y") 的类，实例化后 p.z = 1 会怎样？
__slots__ 声明后实例没有 __dict__，只能使用声明的槽位——p.z = 1 抛 AttributeError。这是省内存的代价，也是拼写错误的「报警器」。
9. 模块 M 的 __all__ = ["PI", "add"]，另外有公开成员 E 与 _secret。执行 from M import * 后可用的是？
定义了 __all__ 后，星号导入只按清单来：E 虽是公开成员但不在清单里也进不来；_secret 无论如何都不进。完整规则：有 __all__ 用 __all__，没有则排除下划线成员。

最终考核

下面是《21.模块化》源课程作业的改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里算出答案，再点击核对。

📣 源作业还要求费曼复述：包/模块/成员关系、__all__ 作用、__init__.py 作用、模块搜索顺序——四者任选其一讲给空气（或 AI 老师）听，讲不通就回看文档。

考核一（__name__ 预测）：模块 my_math.py 末尾写有 if __name__ == "__main__": print(add(3, 5))。以下两种用法哪种会打印 8？
直接运行时 __name__ == "__main__" 成立 → 打印 8；被 import 时 __name__ == "my_math" → 分支不进入。这是「测试代码只在自己运行时执行」的标准技巧。
考核二（__all__ 预测）：my_math.py 定义 __all__ = ["PI", "add"]，另有两个公开成员 E、subtract。执行 from my_math import * 后可用的是？
星号导入只导入 __all__ 清单：PI 和 add。E、subtract 虽然是公开成员，但不在清单里，星号导入进不来（仍可用 from my_math import subtract 显式导入）。
考核三（循环导入预测）：a.py 里 from b import bar；b.py 里 from a import foo。直接运行 a.py 会怎样？
a 执行到 from b import bar 时去执行 b；b 里 from a import foo 时 a 还没执行到定义 foo 的那行 → ImportError。解法：公共代码抽到第三个模块，或把导入延迟到函数内部。详见「循环导入问题」一节。
考核四（__slots__ 研究题）：class Point: __slots__ = ("x", "y")。下列说法正确的是？
__slots__ 把实例属性固定为声明的槽位：实例没有 __dict__，p.z = 1 抛 AttributeError，同时每个实例不再携带字典——大量小对象时显著省内存。属性访问本身与字典类相当，好处在内存。
查看 __slots__ 演示（源作业研究题） 
class Point:
    __slots__ = ("x", "y")

    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
print(p.x, p.y)        # 1 2
print(hasattr(p, "__dict__"))   # False —— 没有属性字典
# p.z = 3              # AttributeError! 只能有声明过的槽位

# 对比普通类
class Plain:
    pass
q = Plain()
q.z = 3                # 普通类可以随意添加属性

💼 面试实战

下面是真实面试官会问的问题，选自中文互联网面试题集（出处附后）。先自己回答，再点击核对。三级面试难度：中级考应用，高级考陷阱，专家考机制与设计。

⚡ 中级面试题

面试题一（模块 vs 包·必问）：模块和包的区别？__init__.py 的作用？
模块是一个 .py 文件；包是含 __init__.py 的目录（即使为空，也是包的标识）。__init__.py 的作用：① 标识包身份；② 导入包时自动执行（初始化、配置）；③ 定义 __all__ 控制 import *；④ 提前导入子模块简化外部导入路径。记忆口诀「标识 + 控制」。出处：CSDN「100 道 Python 面试必背题目（基础理论 + 工程实践篇）」
面试题二（循环导入·高频）：两个模块相互 import 导致 ImportError，怎么解决？
循环导入的成因：互相导入时一方尚未完成初始化就访问其成员。标准解法：① 重构——把共享依赖抽到第三个模块；② 延迟导入——把 import 挪进函数体内（用时才导入，还能加快启动）。出处：腾讯云「Python 模块化编程：面试题深度解析」

🔥 高级面试题

面试题三（__slots__ 继承·深水区）：父类声明了 __slots__，子类没有声明，子类实例还有 __dict__ 吗？
__slots__ 不自动沿继承传递：子类未声明自己的 __slots__（即使声明空元组也不行——空 slots 才继承父类限制）时，子类实例仍会有 __dict__，省内存的效果在子类上失效。这是 __slots__ 深水区的经典追问：想全程省内存，每一层都要声明。出处：CSDN「100 道 Python 面试必背题目」
面试题四（PEP 562·机制）：模块级 def __getattr__(name) 的作用是？
PEP 562：模块级 __getattr__ 在访问模块中不存在的属性时被调用——用于惰性导入重依赖（首次访问才 import）、给已改名/弃用的 API 发 DeprecationWarning（如 numpy 的兼容层）。这是「模块也是对象」的高级应用。出处同面试题三

🧠 专家面试题

专家题一（导入副作用·机制）：模块顶层的代码什么时候执行？
模块顶层的可执行语句在首次导入时运行（打印、连接数据库等都会发生），之后由 sys.modules 缓存不再重复。所以「import 有副作用」是真实风险——这也是模块级代码要克制、用 if __name__ == "__main__" 隔离测试代码的原因。出处：腾讯云「Python 模块化编程：面试题深度解析」
专家题二（导入方式·设计）：相对导入（from . import x）与绝对导入如何选择？
包内部用相对导入（from . import x）——包改名/移动时不受影响；包外部与直接运行的脚本用绝对导入。注意：含相对导入的模块不能作为脚本直接运行。选型理由比选型本身更被面试官看重。出处同专家题一
