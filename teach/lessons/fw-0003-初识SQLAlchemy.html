本课目标

知识速览

先花几分钟把核心机制过一遍——细节都在《03.初识SQLAlchemy》里，测验和面试会考。

分工（课件概念图）

  • SQLAlchemy engine：管理连接池、处理不同数据库的差异
  • asyncpg：仅负责和 PostgreSQL 数据库通信（数据库驱动）
  • 连接字符串：postgresql+asyncpg://用户名:密码@主机:端口/数据库名

连接池四参数

  • pool_size：连接池维持的连接数（课件 10）
  • max_overflow：池满后额外可创建的连接数（课件 20）
  • pool_pre_ping：每次连接前检查是否存活（防死连接）
  • echo：是否打印 SQL 日志（开发调试用）

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与《03.初识SQLAlchemy》覆盖的内容。

🌱 初级测验 · 概念

1. 课件里 asyncpg 的职责是？
课件概念图：asyncpg 仅负责和 PostgreSQL 数据库通信——它就是数据库驱动。
2. SQLAlchemy engine 的职责是？
课件概念图：engine 管理连接池、处理不同数据库的差异。
3. 异步连接字符串的正确格式是？
课件注释：postgresql+asyncpg://用户名:密码@主机:端口/数据库名——dialect+driver 结构。

🌿 中级测验 · 应用

4. pool_pre_ping 的作用是？
课件注释：pool_pre_ping 每次连接前检查是否存活——数据库重启后旧连接失效的兜底。
5. max_overflow 的含义是？
课件注释：max_overflow 是池满后额外可创建的连接数——峰值并发 = pool_size + max_overflow。
6. _DBSettings 的 env_prefix 是 DB_，则 host 字段读取哪个环境变量？
env_prefix 前缀拼接：DB_ + host = DB_HOST——课件 .env 里正是这么写的。

🎯 高级测验 · 综合

7. get_engine() 里 global _engine 判空缓存的目的是？
连接池是昂贵资源——engine 全应用共享一个（课件用模块级 _engine 缓存实现单例）。
8. 连接池的连接是不是越多越好？
作业题答案：PG 每连接一个进程——连接数要与实际并发匹配，过多连接耗尽数据库资源。
9. result.scalar() 的作用？
课件注释：获取结果（第一行第一列）——SELECT 1 场景拿到 1。
