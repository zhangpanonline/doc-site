Seaborn

配合《10.Seaborn》使用预计 15–20 分钟9 道分级测验 + 面试实战

本课目标

完成本课后，你将能：

  1. 用 histplot / kdeplot 做单变量分布分析，并读出偏态与异常
  2. 用 boxplot / violinplot / barplot 做分类对比，说清三者传达的信息差异
  3. 用 regplot / lmplot 做回归分析，理解趋势线与置信区间的含义
  4. 把 Seaborn 图嵌入已有 Matplotlib 子图，并说清两者的分工

知识速览

先花几分钟把三条分析主线过一遍——细节都在《10.Seaborn》里，测验和面试会考。

三类任务，三组函数

  • 单变量分布：histplot（直方图）、kdeplot（核密度曲线）、displot（Figure 级）
  • 分类对比：boxplot（四分位与离群点）、violinplot（分布形状 + 密度）、barplot（默认聚合均值 + 误差棒）、countplot（计数）
  • 回归分析：regplot（Axes 级）、lmplot（Figure 级，可分面）——画散点 + 拟合线 + 置信区间

Seaborn 与 Matplotlib 的关系

  • Seaborn 建在 Matplotlib 之上：它负责统计语义与默认样式，最终仍然由 Matplotlib 渲染
  • Axes 级 vs Figure 级：boxplot/regplot 返回 Axes，可用 ax= 画进已有子图；displot/catplot/lmplot 自带 Figure（分面能力）
  • 主题：sns.set_theme() 一次设定全局样式；想回到 Matplotlib 默认用 reset_orig

读图时的两个易错点

  • 离群点不等于错误数据：箱线图的须默认延伸到最近 hinge 1.5 × IQR 内最远的点，超出者只是「按 IQR 规则被标为离群」
  • barplot 画的是聚合值不是原始点：默认画均值，样本少或分布偏斜时，均值条会掩盖真实分布——这种情况该用箱线图或小提琴图

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与《10.Seaborn》覆盖的内容。

🌱 初级测验 · 概念

1. 想看一列薪资数据的整体分布形态（是否偏斜、有没有双峰），首选的函数是？
单变量分布分析用直方图 histplot 或核密度曲线 kdeplot；regplot 做回归、barplot 做分类聚合，都不适合看分布形态。
2. 对比「不同学历的薪资水平」，下面哪一组函数最合适？
学历是分类变量、薪资是连续变量，属于「分类对比」任务：boxplot 看四分位与离群点，violinplot 额外显示分布密度形状。
3. 研究「工作经验年限」与「薪资」的关系，应该用？
两个连续变量的关系属于回归分析：regplot / lmplot 会画散点并拟合趋势线，lmplot 还支持按额外变量分面。

🌿 中级测验 · 应用

4. 关于箱线图的「离群点」（flier），下面说法正确的是？
箱线图的须默认延伸到最近 hinge 1.5×IQR 内最远的点，超出者被标为离群——这是统计规则判定，不是数据质量判定。高薪岗位真实存在，删掉会低估上限。
5. barplot 画「各城市平均薪资」时，最容易产生的误读是？
barplot 画的是聚合统计量（默认均值）而非原始观测点：一个城市两个极端高薪就能把均值拉高，样本量差异也不体现在条高上。要看分布应改用 boxplot / violinplot。
6. 想在一张已经用 Matplotlib 建好的 2×2 子图里，把第 3 个 Axes 画成 Seaborn 箱线图，正确做法是？
boxplot 是 Axes 级函数，官方签名里有 ax 参数：「Axes object to draw the plot onto, otherwise uses the current Axes」。传 ax 就画进指定子图；catplot/displot 这类 Figure 级函数才会自建画布。

🎯 高级测验 · 综合

7. 一份数据里「经验 1 年」样本只有 3 条却恰好都是高薪。用 regplot 画经验-薪资回归线时，需要注意什么？
回归图给的是「拟合趋势 + 不确定性」：置信带宽度直接反映样本量与离散程度，稀疏区间上的趋势不可当结论；相关也不等于因果。看图的正确姿势是「趋势线 + 散点密度 + 置信带」三件套一起读。
8. 一个 Agent 需要把「三张分析图」拼进同一张 Figure 输出给用户，下面哪种组合最合理？
混排的正确姿势是「Matplotlib 管布局、Seaborn 管统计图层」：先用 subplots 定好网格，再把每个 Axes 通过 ax= 交给 Axes 级 Seaborn 函数。Figure 级函数（displot/catplot/lmplot）各自建画布，不会自动拼进别人的 Figure。
9. 分析「学历与薪资」时，箱线图显示本科中位数高于硕士。最稳妥的下一步是？
分类对比出现反直觉结果时，第一反应应该是检查可比性：样本量、组内构成（岗位/城市/经验）是否均衡。学位与薪资的关系很容易被「硕士更多进入低薪行业/初级岗位」之类的混杂因素扭曲；删样本以迎合直觉是数据造假。
