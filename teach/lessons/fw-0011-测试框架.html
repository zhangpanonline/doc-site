知识速览

先花几分钟把核心机制过一遍——细节都在《11.测试框架》里，测验和面试会考。

三价值 + 三件套

  • 防回归：改一处坏一片，没测试不敢重构
  • 保契约：契约即承诺，测试锁死预期输入输出
  • 提效率：验证十次，不如脚本跑一秒
  • 三件套：uv add（httpx/pytest/pytest-asyncio）+ pyproject 配 asyncio_mode="auto" + Makefile pytest -v

conftest.py 生命周期（课件）

  • session 开始：连 postgres 库 → 杀掉旧连接 → DROP/CREATE 独立测试库 duyi_test_db → alembic upgrade head → 起真实服务器（18000 端口，等 /docs 就绪）
  • 每个测试后：autouse 的 cleanup_db 按 sorted_tables 倒序 TRUNCATE ... RESTART IDENTITY CASCADE
  • session 结束：停服务器 → DROP 测试库
  • fixtures：async_client（httpx.AsyncClient）、base_url、event_loop

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与《11.测试框架》覆盖的内容。

🌱 初级测验 · 概念

1. 课件「为什么需要测试框架」的三个理由？
课件三条：防回归——改一处坏一片没测试不敢重构；保契约——测试锁死预期输入输出；提效率——验证十次不如脚本跑一秒。
2. pyproject 里 asyncio_mode = "auto" 的作用？
课件配置：[tool.pytest.ini_options] asyncio_mode = "auto"——pytest-asyncio 自动识别 async def 测试并调度事件循环，无需每个测试都标 @pytest.mark.asyncio。
3. 集成测试用什么库发 HTTP 请求？
课件 conftest：async_client fixture 用 httpx.AsyncClient(base_url=f"http://localhost:{TEST_SERVER_PORT}")——对真实启动的服务进程发请求，是端到端的集成测试。

🌿 中级测验 · 应用

4. 为什么测试用独立的 duyi_test_db 而不是开发库？
课件 conftest：pytest_sessionstart 里 DROP DATABASE IF EXISTS → CREATE → alembic upgrade head，session 结束再 DROP。测试永远从「刚跑完迁移的空库」出发，结果可复现，也不碰开发数据。
5. cleanup_db 里 sorted_tables 为什么要倒序遍历 TRUNCATE？
课件 cleanup_db：for table in reversed(Base.metadata.sorted_tables)——sorted_tables 按依赖拓扑排序（父在前），倒过来就是子在前；TRUNCATE ... RESTART IDENTITY CASCADE 把自增序列一并归位，保证测试里 id 可预期。
6. _start_server 里的 50 次轮询在等什么？
课件 conftest：subprocess.Popen 起服务后 for _ in range(50) 每 0.1s 探一次 /docs，成功 break，否则 raise 启动超时——进程活着 ≠ 端口可用，uvicorn 启动要几秒。

🎯 高级测验 · 综合

7. 测试断言里为什么同时检查 code 和 status_code？
课件测试：assert response.status_code == 422 且 response.json()["code"] == "422001"——同一 HTTP 422 下业务码区分「字段校验失败」与「关联分类不存在」（422002），保契约 = 两层都锁。
8. 删除测试里为什么「删完再开一个 fresh_client 复查」？
课件 TestDeleteCategory：delete 204 后用 AsyncClient(base_url=base_url) 新起客户端 GET 同 ID 断言 404——验证的是「删除真的写进数据库并对外生效」，而不只是接口回了正确状态码。
9. 每个测试文件里的 _create/_create_product 辅助函数是干嘛的？
课件模式：async def _create(client, name) 发 POST 断言 201 返回 data——准备数据（Arrange）与断言目标（Act/Assert）分离，测试函数读起来是「先造一个分类，再断言列表里有 2 条」。
