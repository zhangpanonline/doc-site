Numpy - 数据操作

配合《04.Numpy - 数据操作》使用预计 15–20 分钟9 道分级测验 + 面试实战

本课目标

完成本课后，你将能：

  1. 用 zeros / ones / arange / linspace / default_rng 快速造出指定形状与分布的数组
  2. 分清基本切片（视图）、花式索引与布尔索引（拷贝），并解释为什么改切片会改到原数组
  3. 用 reshape / -1 / ravel / 转置做变形与重塑，并读懂 sum / mean / std / var 的 axis 与 ddof
  4. 按广播规则推演两个数组能否运算，并在报 ValueError 时指出哪一维不兼容

知识速览

先花几分钟把本章的九个操作块串一遍——细节都在《04.Numpy - 数据操作》里，测验和面试会考。

创建与索引：先想清楚「拿到的是谁」

  • 创建：np.zeros((2,3)) / np.ones(...) / np.eye(3)；np.arange(0,10,2) 按步长走（不含终点），np.linspace(0,1,5) 按个数均分（默认含终点，endpoint=False 去掉）
  • 随机数：用 rng = np.random.default_rng(41) 拿生成器，再调 rng.uniform / rng.normal / rng.integers；固定种子 = 结果可复现
  • 基本切片（arr[1:, 2:]、整数索引）返回视图，改它会改到原数组
  • 花式索引（arr[[0,2]]）与布尔索引（arr[arr > 15]）返回拷贝，改它不影响原数组；布尔条件要用 & / | 并给每项加括号

变形、运算与统计：元素总数与自由度

  • reshape 只改形状不改数据，总元素数必须一致；arr.reshape(2, -1) 里的 -1 让 NumPy 自动推断那一维（一次只能写一个 -1）
  • np.resize 不一样：元素不够会循环重复填充，够多则截断
  • 向量化：arr + 10、prices * 0.8、celsius * 9 / 5 + 32 一次作用于整个数组，不要写 for 循环
  • axis 方向：sum(axis=0) 沿行方向压扁 → 按列求和；sum(axis=1) → 按行求和
  • ddof：分母是 N - ddof。std() 默认 ddof=0（总体标准差），std(ddof=1) 才是样本标准差（Bessel 校正），同一份数据后者一定更大
  • 变异系数 CV = std() / mean()，无量纲，用来跨量纲比较离散程度（CV > 50% 时平均值几乎没有代表性）

筛选、拼接、排序与广播

  • np.where(cond, x, y) 是向量化 if-else：条件成立取 x，否则取 y；只传 cond 时返回满足条件的下标（np.where(arr > 25) → (array([2,3,4]),)）
  • 拼接：np.concatenate([a,b], axis=0/1) 是通用形式，vstack 垂直拼、hstack 水平拼；分割：np.split(arr, [1,3]) 按切点分、np.hsplit(arr, 2) 按列均分
  • 排序：np.sort(arr) 返回排好序的值，np.argsort(arr) 返回能把它排好序的下标（arr[np.argsort(arr)] 才等于 np.sort(arr)）；arr.sort() 是原地排序，np.unique 去重
  • 广播规则：从尾部维度开始逐个比，维度相等或其中一个是 1 才兼容，结果维度取较大者；不满足就抛 ValueError: operands could not be broadcast together

分级测验

🌱 初级测验 · 概念

1. 想快速得到一个 2 行 3 列、全是 0 的数组，写法是？
文档「数组创建」：形状必须是一个元组——np.zeros((2,3))。写成 np.zeros(2,3) 会被理解成「第一个位置参数 2、第二个位置参数 3」，实际报 TypeError（dtype 收到了 3）；np.ones((2,3), dtype=np.float32) 是同一族的写法。
2. np.arange(0, 10, 2) 与 np.linspace(0, 1, 5)，两者最本质的区别是？
文档「数组创建」：np.arange(0,10,2) → [0 2 4 6 8]（终点 10 取不到）；np.linspace(0,1,5) → [0. 0.25 0.5 0.75 1.]，第三个参数是元素个数且默认 endpoint=True；写成 linspace(0,1,5,endpoint=False) 得到 [0. 0.2 0.4 0.6 0.8]。
3. arr = np.arange(12).reshape(3, 4)，那么 arr[0] 的结果是？
文档「基本索引与切片」：索引给得比维度少时，剩余维度默认全取（相当于 arr[0, :]），并且返回的是视图；标量 0 要用 arr[0, 0] 才拿得到。

🌿 中级测验 · 应用

4. 下面关于「花式索引 arr[[0, 2]]」与「布尔索引 arr[arr > 15]」的说法，正确的是？
文档「花式索引（Fancy Indexing）」与「布尔索引（Boolean Indexing）」：两种都是高级索引，返回拷贝；只有基本切片与整数索引才是视图。它们也正是用来挑「不连续/满足条件」的元素的——连续区间应该用切片。
5. arr 是一维数组、共 12 个元素。执行 sub = arr[[0, 2]]，然后 sub[0] = -1，结果会怎样？
文档「花式索引」：用整数数组选取元素返回的是拷贝。如果写成 arr[0:2]（基本切片）再改，才会连带改到原数组——这是本章最容易踩的坑。想显式拿拷贝也可以 arr[0:2].copy()。
6. 对于 arr = np.arange(12)，arr.reshape(2, -1) 得到的结果是？
文档「变形与重塑」：-1 表示「这一维让 NumPy 自己算」，前提是总元素数不变（12 个元素拆成 2 行 → 6 列）；一次 reshape 里只能出现一个 -1。若元素数不整除则会抛 ValueError: cannot reshape array。

🎯 高级测验 · 综合

7. 有两个数组 a 与 b：a = np.array([[1], [2], [3]])（形状 (3,1)），b = np.array([10, 20, 30, 40])（形状 (4,)）。执行 a + b 会？
文档「广播（Broadcasting）」：从尾部开始比——(3,1) 与 (4) 对齐后是 3×1 与 1×4，两处都有 1 可被拉伸，结果 (3,4)。注意如果写成形状 (3,4) 的矩阵去加形状 (3,) 的向量就会失败：ValueError: operands could not be broadcast together with shapes (3,4) (3,)，因为尾维 4 与 3 既不相等也没有 1。
8. 对同一份数据，arr.std() 与 arr.std(ddof=1) 的关系是？
文档「标准差」与 std 参数说明：ddof 是 Delta Degrees of Freedom，分母为 N - ddof，默认 0 对应总体标准差；取 1 得到样本标准差（Bessel 校正）。本章示例里 arr 为 0~11 的 3×4 矩阵：std()=3.4521，std(ddof=1)=3.6056，并且 std(ddof=1)**2 == var(ddof=1) == 13.0。
9. arr = np.array([30, 10, 20])。关于 np.sort(arr) 与 np.argsort(arr)，正确的是？
文档「排序」：np.sort 给值，np.argsort 给「能把它排好序的下标」。下标很有用：sales[np.argsort(sales)[::-1][:3]] 就能拿到销量前 3 名；而原地改写原数组的是 arr.sort()（无返回值）。
