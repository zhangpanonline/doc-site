函数与窗口函数

来源：教程 §3.5 窗口函数 + 官方文档 §9.4（postgres.cn）非渡一课程内容预计 15–20 分钟9 道分级测验 + 4 道最终考核 + 面试实战

知识速览

先花几分钟把核心机制过一遍——细节与测验依据都来自官方文档 教程 §3.5 与 §9.4。

窗口函数（官方定义与例）

  • 官方定义：在与当前行有某种关联的表行上执行计算；与聚合可比，但不把多行压成一行——行保留独立标识
  • 官方原例：avg(salary) OVER (PARTITION BY depname)——每行带本部门平均工资
  • 高频：ROW_NUMBER() 行号、RANK()/DENSE_RANK() 排名、SUM() OVER (ORDER BY ...) 累积
  • 限制：窗口函数在 WHERE/GROUP BY/HAVING 之后求值——不能直接写进 WHERE

字符串函数速选

  • format(fmt, ...)：sprintf 风格（官方原文），说明符 %[position][flags][width]type；%L/%I 安全引用字面量/标识符（拼动态 SQL 用）
  • string_agg(expr, sep)：聚合函数——组内文本按分隔符拼接
  • 常用：split_part(s, sep, n) / length / trim

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与官方文档覆盖的内容。

🌱 初级测验 · 概念

1. 官方对窗口函数的定义，关键点是？
官方原文：窗口函数在与当前行有某种关联的表行上执行计算；不会使多行聚合成一个单独的输出行——行保留独立标识。
2. 官方 empsalary 例中，avg(salary) OVER (PARTITION BY depname) 每行显示什么？
PARTITION BY depname 按部门分区——每行附上本部门的 avg（develop 5020、personnel 3700、sales 4866.67）。
3. string_agg(name, ', ') 的作用是？
string_agg 是聚合函数——把组内每个值用分隔符串起来（如部门内所有人名拼成一行）。

🌿 中级测验 · 应用

4. 窗口函数与 GROUP BY 聚合的本质区别是？
官方定义直击这点：窗口函数不使多行聚合成一行——行保留独立标识，每行附带关联行集的计算结果。
5. WHERE row_number() OVER (...) = 1 能过滤出每组第一行吗？
窗口函数的求值发生在 WHERE/GROUP BY/HAVING 之后——WHERE 里引用会报错；标准解法：子查询/CTE 包一层再过滤。
6. RANK 与 DENSE_RANK 在并列时的区别是？
经典区别：并列名次后 RANK 跳过序号（1,1,3），DENSE_RANK 连续（1,1,2）——按「要不要跳号」选。

🎯 高级测验 · 综合

7. 官方说 format 函数的形式类似于 C 的什么？
官方原文：format 根据格式字符串产生格式化输出，其形式类似于 C 函数 sprintf。
8. 拼动态 SQL 时官方推荐的防注入姿势是？
%L 把值正确加引号并转义、%I 处理标识符（表名/列名）——动态 SQL 的标准姿势，手拼引号是注入源头。
9. 「每人工资与本部门平均工资的差」的写法是？
窗口函数直接参与行内表达式：salary - avg(...) OVER (PARTITION BY depname) 每行算出与部门平均的差。

最终考核

四道题覆盖本课全部要点——答完它们，函数与窗口函数就过关了。

考核一：每个部门工资最高的员工（同名次都列出）——标准写法是？
分组内排名 + 外层过滤的标准模式；RANK（并列同名次）配合 rank=1 可列出并列最高。
考核二：输出每个部门「员工名单：张三、李四」这样的聚合字符串，用什么？
string_agg 聚合组内文本——「组内名单」场景的标准答案。
考核三：给订单按时间排序后算「截至当前行的累计金额」，写法是？
OVER (ORDER BY ...) 定义「从窗口起点到当前行」的滑动窗口——累积和的标准写法。
考核四：format('%1$s 的分数是 %2$s', name, score) 中 %1$s 表示？
官方说明符 %[position][flags][width]type：n$ 指定参数索引（1$=第一个参数），s 表示字符串格式。

四道考核全部答对，说明你掌握了函数与窗口函数——继续学习 pg-08 · 索引进阶。
