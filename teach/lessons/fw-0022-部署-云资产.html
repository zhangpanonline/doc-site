部署-云资产

配合《22.部署-云资产》使用预计 15–20 分钟9 道分级测验 + 面试实战

本课目标

完成本课后，你将能：

  1. 说出五类云资产（证书/VPC/OSS/RDS/ACR）各自的职责
  2. 讲清 VPC 的规划要点：同地域、CIDR、4 个交换机
  3. 按 12 步创建 RDS Serverless 实例并记录内网连接地址
  4. 跑通「docker login → build → push」到 ACR 的镜像推送

知识速览

先花几分钟把核心机制过一遍——细节都在《22.部署-云资产》里，测验和面试会考。

五类云资产（课件）

  • 数字证书：SSL 服务，为 duyi-api.域名 申请 HTTPS 证书
  • VPC：私有网络 10.0.0.0/16，4 个交换机（每可用区 2 个）——后续所有云产品同地区
  • OSS：至少两个——线上测试 / 生产，地域与 VPC 一致（ch14 的上传落点）
  • RDS：PostgreSQL 16 Serverless（RCU 0.5~1、20G 起）——高权限账号 + duyi_db + 记录内网地址
  • ACR：镜像仓库——命名空间 duyiedu、仓库 duyi-service、公网地址 push

连接关系（本课脉络）

  • RDS 只给内网地址——应用部署进同 VPC 后走内网，公网不开
  • 应用容器（ch21 镜像）push 到 ACR，k8s（ch23）从 ACR pull
  • 双 OSS 与「环境」对齐：测试环境用测试桶，生产用生产桶，权限分离

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与《22.部署-云资产》覆盖的内容。

🌱 初级测验 · 概念

1. 本课准备了哪五类云资产？
课件五节：数字证书（HTTPS）、VPC（网络）、OSS（对象存储×2）、RDS（数据库）、ACR（镜像仓库）——部署五件套。
2. VPC 的 ipv4 网段规划是？
课件 VPC 节：duyi-vpc，ipv4 10.0.0.0/16，交换机 4 个、每个可用区两个——高可用布局（多可用区冗余）。
3. OSS 为什么要至少两个？
课件 OSS 节：至少两个——一个线上测试、一个生产，地域必须和 VPC 一致。测试环境乱传的文件绝不进生产桶。

🌿 中级测验 · 应用

4. RDS 选 Serverless 的 RCU 0.5~1 意味着什么？
课件 RDS 步骤 7：RCU 选 0.5~1——Serverless 的计算单元范围，低峰缩到 0.5、高峰弹到 1，学习/小流量场景成本最低。
5. RDS 创建好后要记录什么地址？为什么？
课件 RDS 步骤 4：数据库连接——记录内网连接地址。应用容器（ch21 的 DB_HOST）部署进同 VPC 后填这个地址，数据库不需要公网暴露。
6. ACR 里创建了命名空间和仓库后，三句命令的顺序是？
课件 ACR 命令：先 docker login（鉴权）→ docker build --platform linux/amd64（本地 Mac 是 arm，服务器是 amd，必须指定平台）→ docker push。

🎯 高级测验 · 综合

7. 「地域必须和 VPC 相同」在本课出现了两次（OSS、RDS），为什么？
课件两处强调：OSS 与 RDS 地域都必须和 VPC 一致——同地域的资源之间走内网（低延迟、免流量费），跨地域只能走公网或专线，性能与成本都差。
8. 本课为什么买「个人测试证书」而不是正式证书？
课件数字证书节：购买个人测试证书申请 duyi-api.域名——本课目标是跑通「证书→域名→HTTPS」的完整链路，测试证书便宜（几块钱）；生产环境换正式 DV/OV 证书，申请与部署流程一样。
9. 从 ch21 到本课，镜像传输方式发生了什么升级？
ch21 简易部署第三步是「将镜像传输给服务器」（手工）；本课 ACR 把它变成 docker push 到云端仓库——ch23 的 k8s 集群直接从 ACR pull，这是 CICD 流水线（ch24）的基础设施。
