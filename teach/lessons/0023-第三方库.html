pip 核心命令

命令作用
pip install 包名安装最新版（可一次装多个）
pip install 包名==2.31.0固定版本
pip install -U 包名升级到最新
pip uninstall -y 包名卸载（-y 跳过确认）
pip list / pip show 包名列出已安装 / 查看详情
pip freeze > requirements.txt冻结依赖清单
pip install -r requirements.txt按清单安装
python -m venv .venv创建虚拟环境（隔离依赖）

三个要点

  1. 版本约束符号：== 固定、>= 最低、~= 同系列小版本更新、, 组合多条件——pip install "requests>=2.20,<3.0"。官方文档：Requirement Specifiers
  2. venv 隔离依赖：python -m venv .venv + source .venv/bin/activate——每个项目一套依赖，互不污染。官方文档：venv
  3. requests 流式请求：requests.post(url, json=payload, stream=True) 后 resp.iter_lines() 逐行读取 SSE 数据——data: 前缀、[DONE] 结束标记。官方文档：requests

分级测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。三级难度：初级考概念，中级考应用，高级考综合与陷阱。

🌱 初级测验 · 概念

1. pip 默认从哪里下载包？
pip 从 PyPI（Python Package Index，默认源 pypi.org）下载包；网络慢可临时换镜像源 -i URL。详见「pip 概述」一节。
2. pip install "requests>=2.20,<3.0" 表示？
>=2.20,<3.0 是组合条件：版本在 [2.20, 3.0) 范围内。逗号表示「同时满足」。详见「指定版本」一节。
3. 虚拟环境（venv）解决什么问题？
每个 venv 是独立的 Python 环境：项目 A 用 flask 2、项目 B 用 flask 3，互不冲突。详见「虚拟环境」一节。

🌿 中级测验 · 应用

4. 把当前环境所有依赖锁定到文件，用？
pip freeze 输出「包名==版本」清单，重定向到 requirements.txt 即可复现环境（pip install -r 恢复）。详见「依赖管理」一节。
5. python -m pip install ... 比直接 pip install ... 的好处是？
多版本 Python 共存时 pip 可能指向别的解释器；python -m pip 明确用当前 python 去运行 pip 模块。详见「pip 概述」提示框。
6. pip uninstall 包名 想跳过确认提示，加什么参数？
pip uninstall -y 包名 自动确认（-y = yes）；-U 是 install 的升级简写，别混了。详见「卸载第三方库」一节。

🎯 高级测验 · 综合

7. 项目同时依赖 requests（HTTP）与 python-dotenv（读 .env），requirements.txt 正确内容是？
两个第三方依赖都要进清单；python-dotenv 不是标准库必须列出来。API 密钥等敏感配置放 .env（不进版本库），而不是 requirements.txt。
8. 新机器上复现项目环境的正确顺序是？
标准复现流程：python -m venv .venv → source .venv/bin/activate → pip install -r requirements.txt。顺序不能乱：先隔离环境再装依赖，避免污染全局。详见「使用 venv 管理项目依赖」一节。
9. pip freeze 输出的清单与手写的 requirements.txt 有什么区别？
pip freeze 是「当前环境的完整快照」——所有已装包（含传递依赖）的精确版本；手写清单通常只列直接依赖并可用范围约束。工程实践：手写直接依赖、用 freeze 或锁文件锁定完整版本。

最终考核

下面是《23.第三方库》源课程作业（实现命令行 AI 聊天工具）的改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里选出正确实现，再点击核对。

考核一（聊天主循环）：终端聊天工具要求——循环读输入；/exit 退出；空输入跳过；每轮把用户消息发给 AI，再把 AI 回复记回消息历史。下列实现中正确的是？
正确结构：while True 读输入 → /exit break → 空输入 continue → messages.append({"role": "user", ...}) → 请求 → messages.append({"role": "assistant", ...})（多轮对话靠历史上下文）。第二个三次就结束 ✗；第三个退出词也会发给 AI ✗；第四个没有对话记忆 ✗。
查看源课程参考答案（chat 主循环） 
def chat() -> None:
    messages: list[dict[str, str]] = []
    print("AI 聊天工具 (输入 /exit 退出)")
    while True:
        user_input: str = input("\n你: ").strip()
        if user_input == "/exit":
            print("再见！")
            break
        if not user_input:
            continue
        messages.append({"role": "user", "content": user_input})
        stream = completions(messages)
        print("AI: ", end="", flush=True)
        full_content = ""
        for content in stream:
            print(content, end="", flush=True)
            full_content += content
        messages.append({"role": "assistant", "content": full_content})
        print()
考核二（流式输出）：AI 回复是逐块到达的生成器，要「边到边打印」。下列实现中正确的是？
流式输出要点：print(content, end="", flush=True)——end="" 不换行拼成一句话，flush=True 立即刷出（否则终端缓冲，看不到「边到边」）。第二个失去流式体验 ✗；第三个可能被缓冲 ✗；第四个每块一行 ✗。
考核三（依赖清单）：该聊天工具用了 requests（发 HTTP 请求）与 python-dotenv（读 .env 配置），requirements.txt 应为？
两个第三方依赖都要进清单：requests>=2.31.0 与 python-dotenv>=1.0.0（dotenv 不是标准库）。api 密钥等敏感配置放 .env，不进 git。
考核四（SSE 解析）：逐行解析流式响应——行格式为 data: {...}，遇到 data: [DONE] 结束，JSON 解析失败要跳过该行。下列实现中正确的是？
正确解析三步：if not text.startswith("data: "): continue → 去掉前缀后 [DONE] 则 break → json.loads 包 try/except 跳过坏行。第二个把心跳行（如 : ping）当 JSON 会崩 ✗；第三个多等一轮 ✗；第四个一个坏块就崩溃 ✗。
查看源课程参考答案（SSE 解析核心） 
for line in resp.iter_lines():
    if not line:
        continue
    text: str = line.decode("utf-8")
    if not text.startswith("data: "):
        continue
    data_str = text[6:]
    if data_str.strip() == "[DONE]":
        break
    try:
        chunk = json.loads(data_str)
        content = chunk["choices"][0].get("delta", {}).get("content", "")
        if content:
            yield content
    except (json.JSONDecodeError, KeyError, IndexError):
        continue
