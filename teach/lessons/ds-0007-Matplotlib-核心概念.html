知识速览

先把这三层对象的关系和常用开关过一遍——细节都在《07.Matplotlib - 核心概念》里，测验和面试会考。

三层架构：Figure → Axes → Artist

  • Figure（画布）：最顶层容器，管整体大小、样式、布局；一个 Figure 可以装一个或多个 Axes。官方文档原话是 Figure "is like a canvas"，Axes "is a part of that canvas on which we will make a particular visualization"
  • Axes（绘图区）：数据真正被画上去的地方，有自己的坐标空间、坐标轴（Axis）、刻度、标签、图例。配置图形的主体 API 都在 Axes 上——"The Axes methods are the primary interface for configuring most parts of your plot"
  • Artist（绘制元素）：一切可见之物。官方定义：连 Figure、Axes、Axis 本身都是 Artist；还包括 Line2D（折线）、Patch / Rectangle（柱体）、Text（文字）、Legend（图例）等
  • 别混淆 Axes 与 Axis：一个 Axes 通常带 2 个 Axis（x 轴、y 轴；3D 是 3 个）。Axis 只管刻度和刻度标签

一个 Figure 多个 Axes：plt.subplots(m, n)

  • fig, ax = plt.subplots()：一张画布 + 一个 Axes，此时 ax 是单个对象，直接 ax.plot(...)
  • fig, axes = plt.subplots(2, 2)：返回一个 2×2 的 Axes 数组，用 axes[0, 0]、axes[1, 1] 这种「先行后列」的二维下标取用
  • plt.subplots(2) 这类一维写法返回一维数组，用 axes[0]、axes[1]；fig, (ax1, ax2) = plt.subplots(1, 2) 还能直接解包
  • 每个 Axes 是独立对象：axes[0, 1].bar(...) 与 axes[1, 0].scatter(...) 互不影响；画布级的大标题用 fig.suptitle(...)，单个绘图区的标题用 ax.set_title(...)

样式、脊线与注解：三处最容易踩坑的开关

  • 样式：plt.style.available 看可选风格，plt.style.use('ggplot') 切换（影响配色、网格、字体），plt.style.use('default') 恢复默认。rcParams 是全局运行配置（plt.rcParams.update({...})），本章用它设中文字体 font.sans-serif、axes.unicode_minus、figure.dpi
  • Spines（脊线）：一个 Axes 有 top / right / left / bottom 四条脊线，是 Axes 边界的那条线。「干净风格」就是隐藏上、右两条：ax.spines['top'].set_visible(False)；也可以直接 ax.spines[['top','right']].set_visible(False) 一次设两条。spines 属于 Axes 层，不是 Figure 层
  • 注解：ax.annotate(text, xy=(x,y), xytext=(x2,y2), arrowprops={...})——xy 是被标注的点（箭头指向），xytext 是文字摆放的位置；两者默认都用 data 坐标系（xycoords='data'、textcoords 默认跟随 xycoords）。ax.text(x, y, s) 则只放文字、不画箭头
  • 图例：ax.legend() 的条目来自各 Artist 的 label=（ax.plot(..., label='sin')），没写 label 就没有图例条目

🌱 初级测验 · 概念

1. 在 Matplotlib 的三层架构里，「画布」指的是哪个对象？
对应文档「1. Figure — 画布」：Figure 是最顶层的容器，相当于一张画布，一个 Figure 可以包含一个或多个 Axes。Axes 是绘图区、Artist 是绘制元素、Axis 是坐标轴——都不是画布。
2. 执行 fig, axes = plt.subplots(2, 2, figsize=(8, 6)) 之后，axes 是什么？
对应文档「多个 Axes 的 Figure」：plt.subplots(2, 2) 返回 2×2 的 Axes 数组（先行后列），课件里就是 axes[0, 0].plot(...)、axes[0, 1].bar(...)、axes[1, 0].scatter(...)、axes[1, 1].hist(...) 这么用的。
3. 一个普通的二维 Axes，有几条 spines（脊线），分别是哪几条？
对应文档「Spines（脊线）」：Axes 的四条边框线称为 spines，常见的「干净风格」就是隐藏 top 与 right 这两条。所以默认是 4 条，不是 2 条（2 条指的是 Axis 对象）。

🌿 中级测验 · 应用

4. AI 给出两种写法：甲是 plt.plot([1,2,3],[1,4,9]); plt.title('t')，乙是 fig, ax = plt.subplots(); ax.plot([1,2,3],[1,4,9]); ax.set_title('t')。关于两者取舍，下面哪种说法最准确？
对应文档「1. Figure — 画布」与「2. Axes — 绘图区」的写法对比：plt.* 靠 pyplot 隐式管理「当前 Figure / 当前 Axes」，简单脚本很方便；而 fig, ax 把对象显式拿到手里，才能准确地对某一个 Axes 反复改标题、范围、脊线、注解。多个 Axes 时甲几乎无法表达，乙是唯一直接的做法。
5. 下面代码想给 2×2 布局右上角那个绘图区画柱状图，写法正确的是？
对应文档「多个 Axes 的 Figure」：下标是「行, 列」且从 0 开始。2×2 的右上角是第 0 行第 1 列 → axes[0, 1]。课件原文正是 axes[0, 1].bar([1, 2, 3], [3, 5, 2])；axes[2, 2] 越界，axes.bar 只有在返回值是单个 Axes 时才成立（plt.subplots()，不传 2, 2）。
6. ax.annotate('最大值', xy=(5, 25), xytext=(4, 23), arrowprops={'arrowstyle': '->'}) 中，xy 与 xytext 的语义分别是？
对应文档「注解与图例」：xy=(5, 25) 指向二次函数的最大值点，xytext=(4, 23) 是把「最大值」这四个字放在那里，arrowprops 负责从文字指向 xy 画箭头。两者默认都在 data 坐标系里取值。

🎯 高级测验 · 综合

7. 审查这段代码：plt.plot([1,2,3],[1,4,9]); plt.figure(); plt.plot([1,2,3],[3,2,1]); plt.show()。运行图上为什么只看得到一条线？
对应文档「1. Figure — 画布」与「3. Artist — 绘制元素」：pyplot 隐式接口维护「当前 Figure / 当前 Axes」的全局状态，plt.figure() 会新建一张画布并把它设为当前，后续 plt.plot 就画到新画布上了。两条线分布在两张图上，屏幕上自然只看到（当前/最后的）一张。这正是显式 fig, ax 更能避免的坑：想要同一个 Axes 上两条线，应该复用同一个 ax。
8. 要实现课件的「干净风格」——同时隐藏 ax 的上、右两条脊线，下面哪种写法不可行？
对应文档「Spines（脊线）」：spines 归属 Axes，所以 ax.spines[...] 是对的；ax.spines[['top','right']] 这种列表索引会返回广播代理、同样可用。而 Figure 没有 spines 属性（脊线是绘图区边界，不是画布边界），fig.spines 会直接报 AttributeError——这也是「该查 Figure 的 API 还是 Axes 的 API」这一核心理念的典型考法。
9. 需求是「给某个已有图表把上、右脊线去掉，并把 y 轴标签改成中文」。按三层架构，最该去查哪一层的 API？
对应文档「总结：三层架构」：Figure 管容器与全局配置，Axes 管数据与坐标（画什么、坐标范围、标签、图例），Artist 管视觉表现（颜色、线型、透明度、大小）。脊线与轴标签都属于 Axes 的职责；用 rcParams 改是全局生效，会波及所有图，不是「改这一张」的正确手段。
