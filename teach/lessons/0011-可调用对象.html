本课目标

完成本课后，你将能：

  1. 用 callable() 判断对象是否可调用，并说出判断依据
  2. 通过定义 __call__ 把实例变成「带状态的函数」——最终考核考的就是它

知识速览

先花几分钟把核心机制过一遍——细节都在《11.可调用对象》里，测验和考核会考。

调用协议

函数 f() → type(f).__call__(f)
类 Dog() → type.__call__(Dog)：__new__ + __init__
实例 obj() → type(obj).__call__(obj) = 类里的 __call__

⚙️ 统一规则：x() 永远查找 type(x).__call__，不直接找 x 自己的 __call__。

三个要点

  1. 可调用 = 定义了 __call__：函数有、类有（type 的 __call__）、定义了 __call__ 的实例也有；列表没有，所以 callable([1,2]) → False。官方文档：callable
  2. 实例调用走类的 __call__：add_5(10) 等效于 Adder.__call__(add_5, 10)——self 就是实例本身。
  3. __call__ 让实例携带状态：闭包能做的它都能做（self.xxx 存状态），还更面向对象——计数器、可配置函数、带日志的回调都是它。官方文档：object.__call__

分级测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。三级难度：初级考概念，中级考应用，高级考综合与陷阱。

🌱 初级测验 · 概念

1. callable([1, 2]) 的结果是？
列表没有 __call__ 方法，不可调用 → False。对比：callable(len)、callable(int)、callable(lambda: 1) 都是 True。详见「如何判断对象是否可调用」一节。
2. 定义 __call__ 方法，让哪个对象变得可调用？
在类中定义 __call__，实例就变成可调用对象：add_5(10) → 15。详见「让对象变成可调用对象」一节。
3. add_5 = Adder(5); add_5(10) 等效于？
实例调用时 self 自动传入：add_5(10) 即 Adder.__call__(add_5, 10)。注意实例自己的 __call__ 属性不会被调用——走的始终是类里的 __call__。

🌿 中级测验 · 应用

4. 类（如 Dog）可以被调用，是因为？
Dog() 走调用协议 type(Dog).__call__(Dog)——type(Dog) 是 type，type.__call__ 内部执行 __new__ + __init__ 完成实例化。详见「类也是可调用对象」一节。
5. double = Multiplier(2); double(5) 的结果是？
__init__ 保存了 factor=2，__call__ 返回 self.factor * value → 2 × 5 = 10。这就是「可配置的函数对象」。详见「实现可配置的函数对象」一节。
6. error_log = Logger("ERROR") 调用两次后，log_count 是？
__call__ 里 self.log_count += 1，状态保存在实例属性中，两次调用后为 2——「状态保持的回调」正是可调用对象的优势。详见「实现状态保持的回调函数」一节。

🎯 高级测验 · 综合

7. 调用协议规定：x() 永远查找什么？
统一规则：x() 查找 type(x).__call__(x)——函数走 function 类型的 __call__，类走 type 的 __call__，实例走类里定义的 __call__。实例自身的 __call__ 属性不参与。
8. class B(A)，两者都定义 __call__，B 里 super().__call__() 调用的是？
与普通方法一样，super().__call__() 沿 MRO 调用下一个类的 __call__——B(A) 中即 A 的 __call__。这是源作业思考题的核心：先打印 B called 再打印 A called。
9. 下列哪一组 callable() 结果全部正确？
逐项核对：len 是内置函数 → True；int 是类（type.__call__ 实例化）→ True；[1, 2] 列表无 __call__ → False；lambda: 1 是函数 → True。第一个组合全部正确。

最终考核

下面是《11.可调用对象》源课程作业的两道改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里算出答案，再点击核对。

考核一（作业一·计数器）：实现 Counter 类——实例化时指定起始值，每次调用实例值加 1，支持 reset() 与 get()。要求 c = Counter(10); c() → 11。下列实现中正确的是？
正确实现：__init__ 同时存 start 和 value；__call__ 里 self.value += 1; return self.value；reset 恢复 self.value = self.start；get 返回 self.value。第二个调用 c() 返回 None，题目要求输出 11 ✗；第三个重置错目标 ✗；第四个拿到的是旧值 ✗。
查看源课程参考答案（作业一） 
class Counter:
    def __init__(self, start):
        self.start = start
        self.value = start

    def __call__(self):
        self.value += 1
        return self.value

    def reset(self):
        self.value = self.start

    def get(self):
        return self.value

c = Counter(10)
print(c())      # 11
c()             # 12
print(c.get())  # 12
c.reset()
print(c.get())  # 10
考核二（作业二·思考题）：以下代码的输出是？ 
class A:
    def __call__(self):
        print("A called")

class B(A):
    def __call__(self):
        print("B called")
        super().__call__()

b = B()
b()
b() 调 B.__call__(b)：先打印 B called，然后 super().__call__() 沿 MRO 调到父类 A 的 __call__，打印 A called。顺序：B called → A called。与第 6 课 MRO 知识呼应。
考核三（状态保持回调）：以下代码第二次调用的输出是？ 
class Logger:
    def __init__(self, prefix):
        self.prefix = prefix
        self.log_count = 0

    def __call__(self, message):
        self.log_count += 1
        print(f"[{self.prefix}] #{self.log_count}: {message}")

error_log = Logger("ERROR")
error_log("文件未找到")
error_log("网络连接失败")
log_count 是实例属性，第一次调用后为 1，第二次 += 1 后为 2 → [ERROR] #2: 网络连接失败。实例「记住」了调用历史，这是闭包之外的另一种状态保存方式。
考核四（callable 判断组合）：下列哪一组 callable() 结果全部正确？
逐项核对：len 是内置函数 → True；int 是类（type.__call__ 实例化）→ True；[1, 2] 列表无 __call__ → False；lambda: 1 是函数 → True。第一个组合全部正确。
