知识速览

先花几分钟把核心机制过一遍——细节都在《3.函数》里，测验和考核会考。

参数全景图

def f(a, b=2, *args, **kwargs)
a 位置参数 → b 默认参数 → *args 多余位置参数 → 元组 → **kwargs 多余关键字 → 字典

⚙️ 顺序固定：位置 → 默认 → *args → **kwargs。默认参数必须放在非默认参数后面。

三个要点

  1. *args 收成元组，**kwargs 收成字典：函数内部 args 是 tuple、kwargs 是 dict——它们是「收纳袋」，不是特殊语法。官方教程：Arbitrary Argument Lists
  2. 多返回值本质是元组：return a, b 打包成一个元组返回，x, y = f() 只是解包。官方教程：Defining Functions
  3. 可变默认值是经典陷阱：def f(items=[]) 的 [] 只在定义时创建一次，多次调用会共享同一个列表；正确写法是 items=None + 函数内判断后新建——考核一考的正是这个。官方教程：Default Argument Values

分级测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。三级难度：初级考概念，中级考应用，高级考综合与陷阱。

🌱 初级测验 · 概念

1. 函数没有 return 语句时，调用它的返回值是？
没有 return（或 return 后不带值）的函数默认返回 None。详见「返回值」一节。
2. def show_args(*args) 中，args 的类型是？
*args 把多余的位置参数收进一个元组：show_args(1, 2, 3) 内部 args 是 (1, 2, 3)。详见「可变参数」一节。
3. def greet(greeting="Hello", name): 会发生什么？
默认参数必须放在非默认参数后面：greeting="Hello" 在前、name 在后，定义函数时就抛出 SyntaxError。详见「默认参数」一节。

🌿 中级测验 · 应用

4. def show_kwargs(**kwargs) 中，kwargs 的类型是？
**kwargs 把多余的关键字参数收进一个字典：show_kwargs(name="Alice") 内部 kwargs 是 {'name': 'Alice'}。详见「可变参数」一节。
5. return min(numbers), max(numbers) 返回的本质上是什么？
return a, b 只是把 a 和 b打包成元组返回；x, y = f() 是对元组解包。详见「多返回值」一节。
6. person_info(name="Alice", 25, "北京") 会发生什么？
位置参数不能出现在关键字参数之后：name="Alice" 后跟 25 会直接触发 SyntaxError。正确写法：位置参数在前——person_info("Alice", 25, city="北京")。详见「关键字参数」一节。

🎯 高级测验 · 综合

7. def demo(a, b=2, *args, **kwargs)，调用 demo(1, 3, 4, 5, x=10, y=20) 后各参数的值是？
逐个分配：1 → a；3 覆盖默认值 → b=3；4、5 是多余位置参数 → args=(4, 5)；x/y 是关键字 → kwargs。注意 b 被位置传参覆盖，默认值 2 没用上。这是参数分配规则的完整演练。详见「参数顺序规则」一节。
8. 以下代码的输出是？ 
def outer(x):
    def inner(y):
        return x + y
    return inner

add_5 = outer(5)
print(add_5(10))
闭包：inner 记住了外层变量 x=5，即使 outer 已返回。调用 add_5(10) 时 5 + 10 = 15——这就是「内部函数捕获外部变量」的经典用法（装饰器的基础）。详见第 4 课「闭包作用域」。
9. 以下代码的输出是？ 
def f():
    return 1, 2

x, y = f()
print(x * 10 + y)
多返回值 = 元组：f() 返回 (1, 2)，解包后 x=1, y=2 → 1 × 10 + 2 = 12。选项 102 是「字符串拼接」的错觉——这里是数字运算。

最终考核

下面是《3.函数》源课程作业的四道改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里算出答案，再点击核对。全部答对且能讲清理由，才算过关。

考核一（作业一·默认参数陷阱）：以下代码最后一行 print(result1) 输出是？ 
def add_items(base, items=None, *tags):
    if items is None:
        items = []
    items.append(base)
    for tag in tags:
        items.append(tag)
    return items

result1 = add_items(10)
result2 = add_items(20, [1, 2], 30, 40)
print(result1)
两次调用互不影响：第一次 add_items(10) 里 items is None 成立，新建列表后 append → [10]；第二次调用传入了自己的 [1, 2]，与 result1 无关。所以 result1 仍是 [10]。若默认值写成 items=[]，两次调用会共享同一列表，result1 就会被污染——这正是「可变默认值」陷阱。
考核二（作业二·**kwargs 合并）：以下代码 print(merged) 输出是？ 
def merge_data(base, **extra):
    result = base.copy()
    for key, value in extra.items():
        if key in result:
            result[key] += value
        else:
            result[key] = value
    return result

data = {"a": 10, "b": [1, 2]}
merged = merge_data(data, a=5, b=[3], c="hello")
print(merged)
逐键推演：a=5 → 键存在，10 + 5 = 15；b=[3] → 键存在，[1, 2] + [3] = [1, 2, 3]（列表相加是拼接）；c="hello" → 键不存在，直接放入。输出 {'a': 15, 'b': [1, 2, 3], 'c': 'hello'}。进阶注意：base.copy() 是浅拷贝——顶层字典被保护（a 键是重新赋值），但嵌套列表 b 与原 data 共享，result["b"] += [3] 会顺带把原 data 的 b 也改成 [1, 2, 3]。想彻底隔离要用 copy.deepcopy。
考核三（作业三·多返回值与 enumerate）：以下代码 print(result) 输出是？ 
def split_data(data):
    mid = len(data) // 2
    return data[:mid], data[mid:]

def find_indices(items, target):
    indices = []
    for i, item in enumerate(items):
        if item == target:
            indices.append(i)
    return indices

nums = [1, 2, 3, 4, 5, 6]
first, second = split_data(nums)
scores = [85, 92, 85, 78, 85]
positions = find_indices(scores, 85)
result = second + [len(positions)]
print(result)
split_data 从中间切开：second = [4, 5, 6]；find_indices 收集 85 出现的位置 [0, 2, 4]；second + [len(positions)] = [4, 5, 6] + [3] → [4, 5, 6, 3]。
考核四（作业四·列表扁平化）：实现 flatten，把任意嵌套的列表展开为一维，如 flatten([1, [2, 3], [[4], 5]]) 应返回 [1, 2, 3, 4, 5]。下列实现中正确的是？
关键是两个 API 的差别：extend 把内层列表的元素逐个并入，append 把内层列表整体作为一个元素。正确答案递归处理：flatten([1, [2, 3], [[4], 5]]) → 1 直接 append，[2, 3] 递归展开后 extend → [1, 2, 3]，[[4], 5] 递归得到 [4, 5] 再 extend → [1, 2, 3, 4, 5]。第三个选项用 append 接递归结果，内层列表会变成嵌套元素 ✗。
查看源课程参考答案（作业四·三个函数） 
# 任务 1：列表扁平化
def flatten(nested_list):
    result = []
    for item in nested_list:
        if type(item) is list:
            result.extend(flatten(item))
        else:
            result.append(item)
    return result

# 任务 2：列表/元组转链表
def to_linked_list(items):
    if not items:
        return None
    head = {"value": items[0], "next": None}
    current = head
    for item in items[1:]:
        current["next"] = {"value": item, "next": None}
        current = current["next"]
    return head

# 任务 3：字典合并（后面的覆盖前面的）
def merge_dicts(*dicts):
    result = {}
    for item in dicts:
        result.update(item)
    return result

下面是真实面试官会问的问题，选自中文互联网面试题集（出处附后）。先自己回答，再点击核对。

面试题一（闭包·高频）：什么是闭包？闭包的三大要素是？
闭包三要素：① 函数嵌套；② 内层函数引用外层函数的变量；③ 外层函数返回内层函数。作用：数据封装、延迟计算，也是装饰器的基础。只返回函数但内层没捕获外层变量，不构成严格意义的闭包。出处：itying「分享下你遇到过的 Python 经典面试题」
面试题二（可变默认参数·经典坑题）：以下代码的输出是？ 
def append_to(element, target=[]):
    target.append(element)
    return target

print(append_to(1))
print(append_to(2))
默认参数在函数定义时只求值一次：target=[] 的列表在定义时创建，之后所有不传 target 的调用共享同一个列表对象——所以第二次调用追加后是 [1, 2]。正确写法是 None 哨兵模式：target=None + 函数内 if target is None: target = []。经验法则：默认参数慎用可变类型。出处：老男孩 IT 教育「Python 基础教程之最常见的面试题」
面试追问参考：闭包延迟绑定陷阱（经典） 
# 输出 [6, 6, 6, 6]，不是 [0, 2, 4, 6]
def multipliers():
    return [lambda x: i * x for i in range(4)]
print([m(2) for m in multipliers()])

# 原因：闭包捕获的是变量本身（而非值），调用时 i 已是 3
# 修复：默认参数绑定值
def multipliers():
    return [lambda x, i=i: i * x for i in range(4)]
