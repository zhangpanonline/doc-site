知识速览

先花几分钟把核心机制过一遍——细节都在《01.Web服务框架》里，测验和面试会考。

三大框架一句话

  • Django：开箱即用（Batteries-included）——大型复杂应用、要后台管理
  • Flask：微内核可扩展——小型应用、快速原型
  • FastAPI：高性能现代化——API 服务、微服务、AI 模型封装成 API（本课程主角）

ASGI 协作（核心）

  • 服务器：socket 通信、报文解析、事件循环、进程线程管理（Uvicorn 是 FastAPI 首选）
  • 应用程序：业务逻辑（FastAPI / Starlette / Django）
  • 对接：应用暴露可调用对象 app(scope, receive, send)——scope 是连接上下文字典，receive 收消息，send 发消息
  • WSGI vs ASGI：WSGI 早期标准、多线程处理；ASGI 现代标准、异步处理

文档与校验

  • openapi.json：FastAPI 首次启动自动生成并暴露在 /openapi.json，遵循 OpenAPI 规范
  • Swagger UI（/docs）：交互式测试（Try it out）；Redoc（/redoc）：纯阅读、惰性加载
  • Pydantic：数据校验与转换（'123' → 123、'2' → 2），失败抛 ValidationError；模型会被 FastAPI 生成进 openapi.json

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与《01.Web服务框架》覆盖的内容。

🌱 初级测验 · 概念

1. 三大框架中「开箱即用 (Batteries-included)」指的是？
Django 内置 ORM、后台管理、用户认证等几乎所有常用功能——开箱即用。
2. 「微内核，可扩展 (Microframework)」是哪个框架？
Flask 只提供最基础的核心功能，数据库、表单等按需选择。
3. FastAPI 的核心哲学是？
FastAPI 利用类型注解和异步特性，为 API 设计而生——课件原文。

🌿 中级测验 · 应用

4. WSGI 与 ASGI 的核心区别是？
课件原文：WSGI 用于多线程处理请求任务，ASGI 用于异步处理请求任务。
5. 下列哪项不是 ASGI 服务器的职责？
业务逻辑是 ASGI 应用程序（FastAPI 等框架）的职责；服务器管通信、解析、事件循环、进程线程。
6. Uvicorn 的特点是？
课件表格：Uvicorn 基于 uvloop + httptools、性能极高，是 FastAPI/Starlette 首选。

🎯 高级测验 · 综合

7. ASGI 对接中，scope 参数是什么？
课件原文：scope 是包含连接上下文信息的字典——连接类型、路径、方法、请求头等。
8. Swagger UI（/docs）与 Redoc（/redoc）的核心差异是？
课件表格：Swagger UI 核心功能是交互式测试；Redoc 纯只读、惰性加载，适合对外发布。
9. Pydantic 模型收到 id="123"（声明 int）会怎样？
Pydantic 核心功能是数据校验和转换——'123' 会转换为整数 123；转换失败才抛 ValidationError。
