知识速览

先花几分钟把核心机制过一遍——细节都在《4.容器类型》里，测验和考核会考。

容器可变有序元素可重复一句话记忆

三个要点

  1. == 比内容，is 比身份：[1, 2] == [1, 2] 为 True，但两个变量 is 只有指向同一对象才为 True；判断 None 永远用 is。官方文档：Value Comparisons · Identity Comparisons
  2. in 的语义因容器而异：字典查的是键不是值（"Alice" in {"name": "Alice"} → False）；字符串查的是子串（"el" in "hello" → True）。
  3. 切片左闭右开，解包与排序有坑：fruits[1:4] 取索引 1~3；[::-1] 反转；first, *rest = t 扩展解包；sort() 原地排序返回 None，sorted() 才返回新列表。官方文档：序列操作

分级测验

点击选项立即获得反馈。答错也没关系——仔细读解释，它会把文档里对应的小节指给你。三级难度：初级考概念，中级考应用，高级考综合与陷阱。

🌱 初级测验 · 概念

1. print([1, 2] == (1, 2)) 的输出是？
== 比较时类型必须相同：列表和元组即使内容看起来一样也不相等，输出 False。详见「相等运算符」一节。
2. print({1, 2, 3, 3, 3}) 的输出是？
集合自动去重且无序：重复的 3 只保留一个，输出 {1, 2, 3}。注意空集合必须写 set()，{} 是空字典。详见「集合」一节。
3. print(type((1))) 的输出是？
(1) 只是带括号的数字，类型是 int；单元素元组必须加逗号：(1,) 才是 tuple。这是本课最经典的坑。详见「创建元组」一节。

🌿 中级测验 · 应用

4. print("Alice" in {"name": "Alice"}) 的输出是？
对字典用 in 检查的是键，不是值："name" in d 才是 True，"Alice" in d 是 False。详见「成员运算符」一节。
5. 执行 a = [1, 2]; b = a; print(a is b)，输出是？
b = a 只是让 b 指向同一个列表对象，is 判断身份相同 → True。若写 c = [1, 2] 则是新对象：a is c 为 False，但 a == c 为 True。详见「身份运算符」一节。
6. nums = [3, 1, 4, 1, 5]; print(nums.count(1)) 的输出是？
count(1) 统计值 1 的出现次数：列表里有两个 1 → 输出 2。注意 index(1) 才是第一个匹配的位置（0）。详见「列表操作」一节。

🎯 高级测验 · 综合

7. fruits = ["苹果", "香蕉", "橙子"]; print(fruits[::-1]) 的输出是？
切片 [start:end:step]，step = -1 表示倒着取，即反转列表。返回的仍是列表，原列表不变。详见「索引与切片」一节。
8. 执行 nums = [3, 1, 4]; result = nums.sort(); print(result)，输出是？
sort() 是原地排序，修改 nums 本身并返回 None——所以打印 result 得到 None。想要新列表用 sorted(nums)。详见「列表操作」一节。
9. d = dict.fromkeys(["a", "b"], 0); print(d) 的输出是？
dict.fromkeys(键序列, 默认值) 以序列为键创建字典，所有键共享同一个默认值 0 → {'a': 0, 'b': 0}。详见「创建字典」一节。

最终考核

下面是《4.容器类型》源课程作业的四道改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里算出答案，再点击核对。全部答对且能讲清理由，才算过关。

考核一（作业一·切片拷贝）：执行以下代码，最后的 print(nums == copy, nums is copy) 输出是？ 
nums = [3, 1, 4, 1, 5]
copy = nums[:]          # 切片拷贝
nums[0] = 10
print(nums == copy, nums is copy)
nums[:] 创建的是新列表（内容相同但身份不同）。修改 nums 后内容也不同了：== 比内容 → False，is 比身份 → 本来就不是同一对象 → False。输出 False False。
考核二（作业三·字典遍历）：执行 d = {"x": 10, "y": 20} 后，print("x" in d, 20 in d) 输出是？
字典的 in 只查键："x" 是键 → True；20 是值不是键 → False。输出 True False。想查值要用 20 in d.values()。
考核三（作业五·zip 与 get）：以下代码最后一行输出是？ 
names = ["Alice", "Bob"]
ages = (25, 30)

d = {}
i = 0
while i < len(names):
    if ages[i] > 20:
        d[names[i]] = ages[i]
    i += 1
print(d.get("Charlie", "not found"))
d 里只有 Alice 和 Bob（年龄都 > 20 被加入）。get("Charlie", "not found") 键不存在时返回默认值，不报错 → 输出 not found。对比：d["Charlie"] 会抛 KeyError。
考核四（作业六·学生信息查找）：任务要求「找到 id 为 796997 的学生，打印其姓名和电话；找不到打印 未找到」。下列实现中正确的是？（students 为字典列表，学生数据见下方折叠区）
正确答案是for-else 模式：找到就打印并 break；循环的 else 只在「没被 break 打断」时执行，恰好表达「没找到」。第二个选项不 break，找到后仍会走 else 多打印一行 ✗；第三个无论找到与否都打印未找到 ✗；第四个第一次迭代就 break，若目标不在第一个就漏找 ✗。
查看学生数据与参考答案（作业六·任务12） 
# 学生数据（源课程作业，节选前 3 条；完整 60 条见源课程）
students = [
    {"id": 988985, "name": "梁平", "sex": "女", "age": 15, "tel": "12957961008"},
    {"id": 299422, "name": "邱杰", "sex": "男", "age": 25, "tel": "12685726676"},
    {"id": 796997, "name": "郝霞", "sex": "女", "age": 29, "tel": "15734778439"},
    # ... 共 60 条
]

# 参考答案：for-else 查找
for student in students:
    if student["id"] == 796997:
        print(f"找到学生: {student['name']}, 电话: {student['tel']}")
        break
else:
    print("未找到")
# 输出：找到学生: 郝霞, 电话: 15734778439
