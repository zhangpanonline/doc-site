三个要点

  1. 返回 NotImplemented 让 Python 找 __rmul__：v1 * 3 走 __mul__；2 * v1 时 int 不会处理 Vector，Python 转而调用 v1.__rmul__(2)——右操作数的逆运算。官方文档：emulating numeric types
  2. 类型不符返回 NotImplemented 而不是抛错：给 Python 机会尝试别的路径；NotImplemented 不是 NotImplementedError。
  3. 属性拦截要防无限递归：__setattr__ 内写 self.x = v 会再次触发 __setattr__——必须用 object.__setattr__(self, ...) 绕过。官方文档：object.__setattr__

🌱 初级测验 · 概念

1. __str__ 与 __repr__ 的分工是？
__str__ 给 print() 用（友好格式）；__repr__ 给 repr() 和交互式显示用（精确重建格式）。只实现 __repr__ 时 __str__ 会回退到它。详见「字符串表示」一节。
2. alice == bob 会自动调用哪个方法？
== 触发 __eq__：alice == bob 即 alice.__eq__(bob)。默认（不实现时）比较的是身份（is）。详见「比较操作」一节。
3. 只实现 __eq__ 和 __lt__，想让 >、<=、>=、!= 自动可用，用什么？
@total_ordering 只需 __eq__ 加一个比较方法（如 __lt__），其余自动推导。详见「简化方案」提示框。

🌿 中级测验 · 应用

4. 2 * v1（v1 是 Vector）最终会调用？
int 无法处理 Vector，int.__mul__(2, v1) 返回 NotImplemented，Python 转而调用右操作数的 v1.__rmul__(2)——「右乘」逆运算。详见「算术运算」一节。
5. __setattr__ 内部要设置属性，正确的做法是？
__setattr__ 拦截所有赋值，内部再写 self.xxx = v 会再次触发它 → 无限递归。必须 object.__setattr__(self, name, value)。详见「属性访问拦截」一节。
6. __getattr__ 与 __getattribute__ 的区别是？
__getattribute__ 拦截一切属性访问（优先级最高）；__getattr__ 只在常规查找失败（属性不存在）时才被调用。详见「__getattr__ vs __getattribute__」一节。

🎯 高级测验 · 综合

7. __mul__ 遇到不认识的类型返回 NotImplemented 后，Python 会做什么？
NotImplemented 是「我处理不了，换人试试」的信号：Python 转调右操作数的 __rmul__；若两边都不支持，才抛 TypeError。NotImplemented（单例信号）≠ NotImplementedError（异常类）。
8. 1/2 + 1/3（Fraction 实现）的运算过程是？
分数加法必须通分：a/b + c/d = (a×d + c×b) / (b×d)——(1×3 + 1×2) / (2×3) = 5/6。第二个是经典错误（2/5）✗。这是考核一的核心。
9. class Money 实现了 __bool__（return self.amount != 0），bool(Money(0)) 与 bool(Money(100.5)) 分别是？
__bool__ 定义对象的真假值：amount 为 0 时 False，非 0 时 True——不实现 __bool__ 时对象默认恒为 True（即使属性为空）。这就是「为什么默认所有实例都是真值」的来源。

最终考核

下面是《14.魔术方法》源课程作业（实现 Fraction 分数类）的四道改编题——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里选出正确实现，再点击核对。

考核一（Fraction.__add__）：1/2 + 1/3 = 5/6。实现 __add__，下列正确的是？
分数加法要通分：a/b + c/d = (a*d + b*c) / (b*d)——1/2 + 1/3 = (1×3 + 2×1)/(2×3) = 5/6 ✓。第二个是典型错误（1/2 + 1/3 ≠ 2/5）✗；第三个分母不对 ✗；第四个不返回 Fraction ✗。
考核二（Fraction.__eq__）：判断 f1 == f2，下列正确的是？
交叉相乘：a/b == c/d ⟺ a*d == c*b——1/2 与 2/4 不约分也能判等。先 isinstance(other, Fraction) 检查，不符返回 NotImplemented。第二个是比较身份（is 语义）✗；第三个 1/2 与 1/3 会被误判相等 ✗；第四个依赖字符串格式，脆弱 ✗。
考核三（字符串表示与转换预测）：f1 = Fraction(1, 2)，以下输出组合正确的是？
实现 __float__ → float(f1) 是 1/2 = 0.5；__str__ 返回 "1/2"；__repr__ 返回 "Fraction(1, 2)"（精确重建格式）。第一个组合全部正确。
考核四（Fraction.__lt__）：实现 f1 > f2（1/2 > 1/3 为 True）。下列 __lt__ 中正确的是？
交叉相乘比较：a/b < c/d ⟺ a*d < c*b——1/2 < 1/3 → 1×3 < 1×2 → False，所以 f1 > f2（即 f2 < f1）为 True。只比分子：1/2 与 1/3 会相等 ✗；只比分母更乱 ✗；转 float 有精度风险且漏类型检查 ✗。
查看源课程参考答案（Fraction 核心） 
import math
from functools import total_ordering

@total_ordering
class Fraction:
    def __init__(self, numerator, denominator):
        if denominator == 0:
            raise ValueError("分母不能为0")
        if denominator < 0:               # 负号统一到分子
            numerator, denominator = -numerator, -denominator
        g = math.gcd(abs(numerator), abs(denominator))   # 约分
        self.numerator = numerator // g
        self.denominator = denominator // g

    def __str__(self):
        return f"{self.numerator}/{self.denominator}"

    def __repr__(self):
        return f"Fraction({self.numerator}, {self.denominator})"

    def __eq__(self, other):
        if not isinstance(other, Fraction):
            return NotImplemented
        return (self.numerator == other.numerator
                and self.denominator == other.denominator)

    def __lt__(self, other):
        if not isinstance(other, Fraction):
            return NotImplemented
        return self.numerator * other.denominator < other.numerator * self.denominator

    def __add__(self, other):
        if not isinstance(other, Fraction):
            return NotImplemented
        return Fraction(self.numerator * other.denominator + other.numerator * self.denominator,
                        self.denominator * other.denominator)

    def __float__(self):
        return self.numerator / self.denominator
