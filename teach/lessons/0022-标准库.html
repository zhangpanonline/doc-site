🌱 初级测验 · 概念

1. os.path.abspath("test.txt") 返回什么？
abspath 把相对路径转成绝对路径（拼上当前工作目录）。相对/绝对路径统一处理的第一步。
2. os.path.basename("/a/b/c.txt") 返回？
basename 取路径最后一段（文件或目录名）；目录部分是 os.path.dirname。
3. os.listdir(path) 返回什么？
listdir 返回该目录下直接子项的名称列表（字符串），不含递归内容、无序——树形展示时要自己 sort 并递归子目录。

🌿 中级测验 · 应用

4. 匹配 Markdown 标题行（一至六级）的正则是？
^(#{1,6})\s+(.+)$：行首 1-6 个井号 + 至少一个空白 + 标题内容。组 1 是井号（判断级数），组 2 是标题文字。第二个只匹配一级标题 ✗；第三个只匹配二级 ✗。
5. open(path, encoding="utf-8") 显式指定编码的原因？
默认编码随平台/环境变化（Windows 上可能是 GBK），处理中文 Markdown 时显式 encoding="utf-8" 才稳。
6. 模块里 __all__: list[str] = ["show_tree"] 的作用？
同第 19 课：__all__ 是模块的公开 API 清单，只影响 from x import *。源答案 p1 就用它导出 show_tree。

🎯 高级测验 · 综合

7. 目录结构 dir1 下有两个文件 a.txt、b.txt，树形输出中子目录项 a.txt 应打印为？
树形规则：非最后一项用 ├──、最后一项用 └──——a.txt 后面还有 b.txt，所以是 ├── a.txt；b.txt 才是 └──。判断依据是 i == len(entries) - 1。
8. Markdown 合并规则中，原文件里的 ###### 小标题（六级）在合并结果里变成？
降级规则的特例：一级到五级各加一个井号；六级没有第七级，按题意降为正文并加粗——**小标题**。这是 merge_markdown 最容易漏的边界。
9. show_tree(dir, show_hidden=False)，目录里同时有 .env 文件与 .git/ 子目录，输出会包含它们吗？
隐藏判断只看 basename 是否以 . 开头——文件与目录一视同仁：.env 与 .git 都被过滤。传 show_hidden=True 才全部显示。

最终考核

下面是《22.标准库》源课程作业的两道实现题改编——这就是本课的最终考核。规则：不查资料、不运行代码，先在心里选出正确实现，再点击核对。

考核一（作业一·树形目录展示）：show_tree(dir_path, show_hidden=False) 输出 tree 风格的目录树（隐藏项 = 以 . 开头；目录递归；最后一项用 └──，其余用 ├──）。下列实现中正确的是？
正确实现三要素：① show_hidden=False 时过滤 basename.startswith(".") 的项；② 按 is_last 选 └──/├──；③ 递归子目录时前缀追加 " "（该项是最后一个）或 "│ "（还有兄弟）。第二个没有树 ✗；第三个该显示的没显示 ✗；第四个竖线连不到底 ✗。
查看源课程参考答案（作业一） 
import os

def show_tree(dir_path: str, show_hidden: bool = False, _prefix: str = "") -> None:
    path = os.path.abspath(dir_path)
    if not _prefix:
        print(os.path.basename(path) or path)

    entries = os.listdir(path)
    if not show_hidden:
        entries = [e for e in entries
                   if not os.path.basename(e).startswith(".")]
    entries.sort()

    for i, entry in enumerate(entries):
        is_last = i == len(entries) - 1
        print(f"{_prefix}{'└── ' if is_last else '├── '}{entry}")
        entry_path = os.path.join(path, entry)
        if os.path.isdir(entry_path):
            show_tree(entry_path, show_hidden,
                      _prefix + ("    " if is_last else "│   "))
考核二（作业二·Markdown 合并）：merge_markdown(files, output)——首行固定 # 合并结果，所有原文件标题降一级（一级→二级…六级→加粗正文）。下列实现中正确的是？
正确实现：HEADING_RE.sub 回调里 level < 6 → 井号 +1；level == 6 → **内容**（题目规定六级降为正文加粗）。第二个只处理一级 ✗；第三个丢了六级内容 ✗；第四个标题没降级 ✗。
查看源课程参考答案（作业二） 
import re
import os

HEADING_RE = re.compile(r"^(#{1,6})\s+(.+)$", re.MULTILINE)

def _demote_heading(match):
    hashes, content = match.group(1), match.group(2)
    level = len(hashes)
    if level < 6:
        return f'{"#" * (level + 1)} {content}'
    return f"**{content}**"

def merge_markdown(files: list[str], output: str) -> None:
    parts: list[str] = ["# 合并结果", ""]
    for filepath in files:
        with open(os.path.abspath(filepath), encoding="utf-8") as f:
            content = f.read()
        parts.append(HEADING_RE.sub(_demote_heading, content).strip())
        parts.append("")
    with open(os.path.abspath(output), "w", encoding="utf-8") as f:
        f.write("\n".join(parts).strip() + "\n")
考核三（合并结果预测）：a.md 内容为 # 标题一 与正文「你好」；b.md 内容为 ## 标题二。用正确实现合并后，b.md 的标题在结果中是？
降级规则：一级 → 二级、二级 → 三级……所以 ## 标题二 变成 ### 标题二；只有六级才会变成加粗正文。首行固定是 # 合并结果。
考核四（隐藏过滤预测）：目录里有 .env（文件）与 app.py。show_tree(dir, show_hidden=False) 的输出包含？
show_hidden=False 时，basename.startswith(".") 的项被过滤——.env 不显示，app.py 显示。传 show_hidden=True 才全部显示。
