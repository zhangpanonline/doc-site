本课目标

完成本课后，你将能：

  1. 背出参数的五种值类型与「参数名大小写不敏感」的官方规则
  2. 解释带单位数字的语法：内存单位 1024 进制、显式单位必须写成字符串
  3. 用 SET/SHOW/current_setting/pg_settings 做会话级调参，说出「不影响其他会话」

知识速览

先花几分钟把核心机制过一遍——细节与测验依据都来自官方文档 §19.1。

参数名称与值（官方语法）

  • 所有参数名大小写不敏感；五种值类型：布尔/字符串/整数/浮点/枚举
  • 布尔：on/off/true/false/yes/no/1/0 或任何无歧义前缀（官方原文）
  • 带单位的数字：内存单位乘数是 1024 不是 1000（B/kB/MB/GB/TB）；时间单位 us/ms/s/min/h/d；显式单位须写成字符串（'120 ms'）
  • 数字：整数参数小数值四舍五入；十六进制 0x 前缀、八进制 0 前缀；不能用千位分隔符

会话级设置（官方要点）

  • SHOW 查看当前值（函数 current_setting）；SET 修改会话本地值——对其他会话没有影响
  • 部分参数只有超级用户/有 SET 特权者可设（官方原文）
  • pg_settings 视图：类似 SHOW ALL、可过滤连接；UPDATE ... SET setting 等效 SET；SET ... TO DEFAULT 恢复默认
  • 部分参数需重启——启动后不能被这些命令更改（官方原文）

分级测验

即时反馈：点击选项立刻显示对错与解释。题目只考本课与官方文档覆盖的内容。

🌱 初级测验 · 概念

1. 官方说参数名的大小写规则是？
官方原文：所有参数名都是大小写不敏感的。
2. 参数接受哪五种值类型（官方）？
官方原文：每个参数都可以接受五种类型之一的值：布尔、字符串、整数、浮点数或枚举。
3. 内存单位的乘数是（官方原文）？
官方原文：内存单位的乘数是 1024，而不是 1000——'1GB' = 1024³ 字节，面试经典考点。

🌿 中级测验 · 应用

4. SET work_mem = '64MB' 的生效范围是？
官方原文：SET 命令允许修改可以在会话本地设置的参数的当前值；它对其他会话没有影响。
5. 时间值 '120 ms' 必须写成字符串的原因（官方）？
官方原文：要使用显式单位，注意值必须被写成一个字符串（带有引号）。
6. 官方说部分参数谁才能 SET？
官方原文：许多参数可以通过任何用户设置，但有些只能由超级用户和被授予该参数上 SET 特权的用户设置。

🎯 高级测验 · 综合

7. 布尔参数的合法写法是（官方）？
官方原文：布尔值可写成 on/off/true/false/yes/no/1/0（大小写不敏感）或这些值的任何无歧义前缀。
8. 官方说 UPDATE pg_settings SET setting 的效果等同于？
官方原文：在这个视图上使用 UPDATE 并且指定更新 setting 列，其效果等同于发出 SET 命令。
9. max_connections 这类参数在运行中 SET 会怎样（官方）？
官方原文：部分参数在服务器启动后不能被更改，并且因此不能被这些命令设置——重启级参数的典型。

最终考核

四道题覆盖本课全部要点——答完它们，服务器配置就过关了。

考核一：会话里 SET 的临时调参怎么恢复默认？
官方原文给出了 SET configuration_parameter TO DEFAULT 的写法；会话级设置随连接结束自然消失。
考核二：调 shared_buffers 写 '2GB' 与写 2GB 的区别？
官方原文：显式指定单位时值必须写成一个字符串（带引号）；不带单位的裸数字按该设置的默认单位解释。
考核三：临时给当前查询加大 work_mem 又不影响其他连接，正确姿势是？
SET 只影响当前会话——「临时调大、用完 TO DEFAULT」的官方姿势；要永久生效才改配置文件/ALTER SYSTEM。
考核四：排查「参数改了没生效」，按官方知识先检查什么？
pg_settings 的 context 列标注参数生效级别（postmaster=重启、user=会话可 SET 等）——「改了没生效」先查这里。
