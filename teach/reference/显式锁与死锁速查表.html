显式锁与死锁速查表

配合《显式锁与死锁互动教学课程》使用。来源：官方文档 §13.3（postgres.cn），非渡一课程内容。

锁分级

级别模式要点
表级锁ACCESS SHARE ~ ACCESS EXCLUSIVELOCK 命令显式获取；名字含 row 的也是表级锁（历史遗产）
行级锁FOR UPDATE / FOR NO KEY UPDATE / FOR SHARE / FOR KEY SHARESELECT ... FOR UPDATE 原子化「先查后改」

官方定位：显式锁用于MVCC 无法给出期望行为的情境；大多数命令自动取锁（TRUNCATE → ACCESS EXCLUSIVE）。

死锁四原则

自动检测
PG 检测死锁并终止其中一个事务（deadlock detected），不会无限挂起。
预防
一致的加锁顺序（破坏循环等待）、缩短事务、缩短锁持有时间。
应对
应用捕获死锁错误并重试——并发系统的正常现象。
观察
pg_locks 视图：granted = f 的行是「等待中」的锁。
