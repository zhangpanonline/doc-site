对象的创建过程速查表

配合《对象的创建过程互动教学课程》与《8.对象的创建过程》使用。建议打印一份放在手边。

创建三步

def create_object(cls, *args, **kwargs):
    obj = cls.__new__(cls, *args, **kwargs)   # 1. 分配并创建实例
    if isinstance(obj, cls):                  # 2. 类型检查
        obj.__init__(*args, **kwargs)         # 3. 初始化
    return obj
__new__
静态方法，第一参数 cls；负责创建实例并 return 它。重写必须 return super().__new__(cls)。
__init__
实例已存在时被调用，只负责装属性；不能 return 非 None 值。
类型检查
__new__ 返回的不是 cls 实例时（如返回 int 0），__init__ 被跳过。

单例模板

class Database:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

conn1 = Database()
conn2 = Database()
print(conn1 is conn2)   # True

对象池模板

class ConnectionPool:
    _pool = {}

    def __new__(cls, conn_id):
        if conn_id not in cls._pool:
            cls._pool[conn_id] = super().__new__(cls)
        return cls._pool[conn_id]

pool1 = ConnectionPool("conn_1")
pool2 = ConnectionPool("conn_1")   # is pool1 → True
pool3 = ConnectionPool("conn_2")   # is pool1 → False

常见误区

  • 忘了 return：重写 __new__ 不 return super().__new__(cls)，实例化得到 None。
  • 单例的 __init__ 每次都会执行：__new__ 返回的仍是 cls 实例（isinstance 通过），所以第二次实例化会重新初始化属性——需要时加「已初始化」标志跳过。
  • __init__ 不是构造函数：它被调用时对象已存在；真正的构造在 __new__。
  • 返回别的类型会跳过 __init__：PositiveInt(-3) 返回 int 的 0，得到的是纯 int 对象。
