角色与权限速查表

配合《角色与权限互动教学课程》使用。来源：GRANT 参考 + §5.8（postgres.cn），非渡一课程内容。

GRANT 两种变体

变体作用要点
对象特权表/列/视图/函数等对象授权特权叠加；WITH GRANT OPTION 可转授（不能给 PUBLIC）
成员资格GRANT role_b TO role_aA 继承 B 的特权

角色实际特权 = 直接授予 + 成员角色特权 + PUBLIC 特权（官方三源并集）。

RLS 速查

ALTER TABLE orders ENABLE ROW LEVEL SECURITY;

CREATE POLICY tenant_iso ON orders
  USING (tenant_id = current_setting('app.tenant_id')::int);

ALTER TABLE orders FORCE ROW LEVEL SECURITY;  -- 拥有者也受限
默认否定
启用后无策略 = 所有行不可见不可改（fail-safe）。
拥有者
通常不受限；FORCE 后同样受限。
不受限的操作
TRUNCATE、REFERENCES（表级操作）。
求值顺序
策略表达式先于用户查询条件（官方原文）。
