四个库的分工

库负责典型任务
NumPy同质多维数组与数值计算ndarray、向量化运算、广播、统计聚合
Pandas带列名的表格数据读写 CSV/Excel/数据库、清洗、分组聚合
Matplotlib底层绘图引擎Figure/Axes/Artist、动画、交互式组件
Seaborn统计图表与样式分布、分类对比、回归分析

一句话：前两个管「算」，后两个管「看」。

课程地图（10 章）

章内容关键产出
01课程导言定位与四个库分工
02Jupyter工程初始化 + 跑通 Notebook
03Numpy - 核心概念ndarray / shape / dtype / strides / axis
04Numpy - 数据操作索引切片、变形、广播、统计运算
05Pandas - 数据类型Series / DataFrame / 读取数据
06Pandas - 数据清洗招聘数据逐列清洗与验证
07Matplotlib - 核心概念Figure / Axes / Artist 三层架构
08Matplotlib - 动画FuncAnimation / ArtistAnimation
09Matplotlib - 交互式组件Slider / Button / CheckButtons 等
10Seaborn分布、分类对比、回归分析

顺序依据：Pandas 建立在 NumPy 之上，Seaborn 建立在 Matplotlib 之上——先底层后高层。

工程与工具链

uv init .              # 初始化工程（生成 pyproject.toml）
uv add numpy           # 运行时依赖 → project.dependencies
uv add --dev jupyter   # 开发期工具 → dependency-groups
uv sync                # 按 uv.lock 复现环境
课程定位
为 Agents 应用开发做准备——不做模型训练/微调/部署/推理，也不铺陈统计学体系。
课件格式
Jupyter Notebook（.ipynb），用 VS Code 的 Jupyter 插件运行。
解释器
必须选本工程虚拟环境的 Python；选错环境会出现「装了却 import 不到」。
学习姿势
读懂 AI 给出的数据处理代码 → 能改造 → 能验证结果对不对。
