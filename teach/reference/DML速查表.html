DML速查表

配合《DML 互动教学课程》与《04.DML》使用。建议打印一份放在手边。

增删改三件套

-- 增
INSERT INTO students (name, age) VALUES ('张三', 22);
INSERT INTO students (name, age) VALUES ('a',1),('b',2);          -- 多行
INSERT INTO t (…) SELECT … FROM backup WHERE …;                    -- 查询并插入
INSERT … RETURNING id, name;                                       -- PG 特有：拿回行
INSERT … ON CONFLICT (email) DO UPDATE SET age = EXCLUDED.age;     -- UPSERT
INSERT … ON CONFLICT (email) DO NOTHING;                           -- 忽略冲突

-- 删 ⚠️ 必须写 WHERE
DELETE FROM students WHERE name = '张三';
DELETE FROM students WHERE score < 60 RETURNING id, name;

-- 改 ⚠️ 必须写 WHERE
UPDATE students SET score = 98 WHERE name = '张三';
UPDATE students SET score = score + 5 WHERE age < 20;           -- 表达式
UPDATE students s SET score = e.score FROM exam_scores e WHERE s.id = e.student_id;

SELECT 子句速查

子句要点
WHERE= > AND/OR IN BETWEEN LIKE(%,_) IS NULL
ORDER BY默认升序，DESC 降序，可多列
LIMIT / OFFSET分页；第 N 页每页 10 条 = LIMIT 10 OFFSET (N-1)*10
DISTINCT去重，可多列组合去重
GROUP BY非聚合列必须分组
HAVING分组后过滤，可用聚合

执行顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT

聚合函数

函数作用
COUNT(*) / COUNT(列)行数 / 非 NULL 行数
SUM / AVG / MAX / MIN和 / 均值 / 最大 / 最小

JOIN 四种

类型结果
INNER JOIN只保留两边匹配的行
LEFT JOIN左表全保留，右表无匹配补 NULL（最常用）
RIGHT JOIN右表全保留（可改写为 LEFT）
FULL OUTER JOIN两表全保留

⚠️ LEFT JOIN 后在 WHERE 过滤右表字段 → 退化为 INNER；想连接前过滤右表，条件写 ON。

子查询四类

类型返回示例
标量子查询单个值score > (SELECT AVG(score) …)
行子查询单行多列(age, score) = (SELECT …)
表子查询多行多列age IN (SELECT …)
EXISTS有无结果WHERE EXISTS (SELECT 1 …)

⚠️ NOT IN + NULL → 空结果，用 NOT EXISTS 替代。

核心要点

  • 两大危险操作：DELETE 不带 WHERE、UPDATE 不带 WHERE
  • RETURNING：PG 特有，增删改直接拿回行数据
  • EXCLUDED：ON CONFLICT 中本次插入的新值
  • TRUNCATE 重置自增序列，DELETE 不重置
  • WHERE 无聚合、HAVING 有聚合——执行顺序决定
  • 保留字加引号："user"、"order"
