Series vs DataFrame

维度Series（带标签的一维数组）DataFrame（带标签的二维表格）
核心组成values + indexindex + columns + values + dtypes
类型报告s.dtype（一个类型）df.dtypes（逐列，属性不是方法）
形状s.shape → (4,)df.shape → (行数, 列数)
维度s.ndim → 1df.ndim → 2
取值s['a'] 按标签 · s.iloc[0] 按位置df['col'] 取列得 Series · df.loc[行, 列] / df.iloc[i, j]
索引默认值不传 index → RangeIndex（0,1,2,…）不传 index → RangeIndex；不传 columns → 0,1,2,…
对齐行为运算结果索引取并集，单边缺失记 NaN加列时也按 index 对齐，对不上补 NaN

从字典创建 Series：key 自动成为索引；索引长度必须与数据长度一致。

DataFrame 的组成结构（四件套）

index
行标签。默认 RangeIndex(start=0, stop=679, step=1)；类型是 pandas.RangeIndex / pandas.Index。
columns
列名。类型是 pandas.Index；从列表/ndarray 构造时不传 columns= 就用 0、1、2…
values / to_numpy()
核心数据，numpy.ndarray。整表混类型时退化成 dtype=object，且不带列名——先选列再转数组。
dtypes
逐列一个类型（如 name → str、age → int64）；本身是 dtype: object 的 Series。df.dtypes，不要写 ()。
shape / size / ndim
shape=(行,列)、size=元素总数、ndim=2。

一句话判据：NumPy 数组整表只有一个 dtype，DataFrame 每列各有一个 dtype。

常用读取方法对照

方法用途关键参数
pd.read_csv(path) 读 CSV（最常用） encoding 编码 · header=None 无表头 · index_col='id' 指定索引列 · usecols=['a','b'] 只读指定列 · nrows=100 只读前 N 行 · dtype={'订单号': str} 钉住列类型
pd.read_excel(path, sheet_name='Sheet1') 读 Excel，必须指明工作表 sheet_name 工作表名/序号 · index_col · na_values · 引擎：.xlsx 走 openpyxl、.xls 走 xlrd
pd.read_sql(sql, con) 把 SQL 查询结果直接读成 DataFrame sql 查询语句或表名 · con SQLAlchemy engine / connection / URI（未装 SQLAlchemy 时可用内置 sqlite3.Connection）· index_col · parse_dates；它是 read_sql_table / read_sql_query 的便捷封装

其他格式同理：JSON → pd.read_json；落库用 df.to_sql(...)，导出用 to_csv / to_excel。

dtype 三个高频坑

# 1. 标识列（订单号/邮编/工号/手机号）：不指定 dtype 就被推断成数值，前导零丢失
df = pd.read_csv('orders.csv')                          # 007123 → 7123（不可逆）
df = pd.read_csv('orders.csv', dtype={'订单号': str})    # 保住文本语义与前导零

# 2. 事后补救来不及：astype(str) 只能拿到已经丢掉前导零的数字
df['订单号'].astype(str)        # '7123'，原始位宽已不可恢复

# 3. 整数列一旦引入缺失值，会被提升为 float64（1 → 1.0），参与计算前先想清楚
#    float 列：不变 · object 列：不变 · 整数列：cast 到 float64 · 布尔列：cast 到 object
什么时候用 dtype
只要列是标识/编号/带前导零的文本，就在读入那一刻钉成 str；金额、数量这类度量列保持推断，方便后续算术。
什么时候用 index_col
文件里已有一列天然唯一的业务主键（如 id）时，用它当行索引；不指定就用默认 RangeIndex。
检查动作
读完立刻 df.dtypes 复核一遍：类型不对就回来补 dtype，别等到结果对不上再回头找。
