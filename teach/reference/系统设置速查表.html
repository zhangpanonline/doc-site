系统设置速查表

配合《系统设置互动教学课程》使用。源课程：gitee.com/dev-edu/python-framework。

落地流程（三层）

  1. 模型层：复制模型 → 登记 model/__init__ → 迁移（make db-migrate / db-upgrade）
  2. 业务层：复制 DTO → 复制 service → 复制集成/单元测试 → 跑新增测试
  3. API 层：复制 API → 复制 main → 复制 e2e/集成测试 → 跑测 → 查文档 → 手测 → 冒烟 → 提交

声明式配置模式

SETTINGS_DTO
frozen dataclass 清单：组的 key/显示名/描述 + 设置项的 key/默认值/显示名/描述——代码即配置清单。
initialize()
启动时双向收敛：DTO 有库没有→建；库有 DTO 没有→删；都有→同步显示信息（value 不动）。
lifespan
@asynccontextmanager 启动钩子：yield 前完成 initialize，先有数据再有请求。
update_settings
只改 value：in_ 批量查询已知键，未知键忽略。

模型要点：SettingGroup.key 唯一；Setting 有 (group_id, key) 联合唯一 + 组外键 CASCADE。
