Numpy-核心概念速查表

配合《Numpy-核心概念互动教学课程》使用。

ndarray 四要素

ndarray（N-dimensional array）是 NumPy 的核心数据结构：同质化（所有元素同一个 dtype）、连续内存（创建后总大小固定）、向量化运算（不用循环）。四要素决定了它的形状、存储与运算规则：

shape
元组，描述每个维度上的长度。1D (n,)、2D (m, n)、3D (a, m, n)。元组长度就是维度个数，某一维是 1 也不会被自动去掉。
ndim
维度个数，等于 len(a.shape)。
size
元素总数，等于 shape 各元素之积：a.size == math.prod(a.shape)。
dtype
统一的元素类型；同质化意味着禁止在同一个数组里混合不同类型，否则要么报错、要么失去向量化优势。
strides
元组，在每个维度上前进一个元素要跳过的字节数。int64 的 (2, 3) 数组：(24, 8) = (3×8, 1×8)。
itemsize
单个元素占用的字节数（float64 → 8，float32 → 4，bool → 1）；总字节数 a.nbytes == a.size * a.itemsize。
axis
维度索引，从 0 开始、按 shape 元组的先后顺序编号。2D 数组里 axis=0 是行方向、axis=1 是列方向；运算里它表示被压掉的那一维。

dtype 与内存对照表

NumPy dtypeC 类型大小典型用途
boolbool1 字节Mask（布尔掩码）
int8 / int32signed char / int1 / 4 字节小范围计数、量化结果
int64int64_t8 字节Token ID、索引
float32float4 字节Embedding 向量（省一半内存）
float64double8 字节默认浮点、需要精度时
object—指针尽量避免：失去向量化优势

内存量级（记这两个数就够用）：100 万个 float64 ≈ 7.63 MB；100 万个 float32 ≈ 3.81 MB。换算公式恒为 size × itemsize 字节。

dtype 本质上是把 C 的类型系统暴露给 Python：Python 的 int 是不定长对象（对象头就 28+ 字节），ndarray 用 C 的定长类型才换来连续存储与向量化。显式指定 dtype=np.int64 后遇到字符串会直接报 invalid literal for int() with base 10，不会静默降级。

strides 步幅与视图

arr = np.array([[1, 2, 3],
                [4, 5, 6]], dtype=np.int64)

arr.shape     # (2, 3)
arr.strides   # (24, 8)   ← 行步幅 3*8，列步幅 1*8
arr.itemsize  # 8

t = arr.T
t.shape       # (3, 2)
t.strides     # (8, 24)   ← 只是交换了步幅，零拷贝

t[0, 0] = 99  # 视图写穿：arr[0, 0] 也变成 99
arr.T.copy()  # 要独立副本就用 copy()

arr.sum(axis=0)   # [5, 7, 9]  沿 axis=0，按「列」算（结果长度 = 列数）
arr.sum(axis=1)   # [6, 15]    沿 axis=1，按「行」算（结果长度 = 行数）
  • 转置＝换步幅，不是搬数据：arr.T 与 arr 共享同一块内存，改一个另一个跟着变
  • 判定视图：np.shares_memory(a, b) 最可靠；b.base is a 只能说明 b 不拥有内存。id() 与数据相等都不可靠
  • ndarray 不能原地扩容：没有 append；np.append 是复制出一个新数组，逐行 append 在数据管道里是 O(n²)
  • axis 是「被压掉的那一维」：sum(axis=1) 压掉最后一维，结果形状 = 去掉该维后的 shape
  • 选 dtype 先算账：Embedding float32、Token ID int64、Mask bool，用 size × itemsize 估准内存再决定是否降级
