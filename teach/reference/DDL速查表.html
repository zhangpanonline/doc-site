配合《DDL 互动教学课程》与《02.DDL》使用。建议打印一份放在手边。

SQL 四分类

分类全称作用关键字
DDLData Definition数据定义（结构）CREATE / ALTER / DROP / TRUNCATE
DMLData Manipulation数据操作（行）INSERT / SELECT / UPDATE / DELETE
DCLData Control数据控制（权限）GRANT / REVOKE
TCLTransaction Control事务控制BEGIN / COMMIT / ROLLBACK / SAVEPOINT

常用数据类型

类型说明
SERIAL / BIGSERIAL自增整数（INTEGER/BIGINT + 序列）
NUMERIC(m, n)定点精确，m 总位 n 小数——金额
REAL / DOUBLE PRECISION浮点不精确——科学计算
VARCHAR(n) / CHAR(n) / TEXT变长 / 定长补空格 / 不限长
BOOLEAN / DATE / TIME布尔 / 日期 / 时间
TIMESTAMP / TIMESTAMPTZ不带时区 / 带时区
JSON / JSONB文本存储 / 二进制、可索引、查询高效
UUID通用唯一标识，常配 gen_random_uuid()

约束

约束作用
PRIMARY KEY唯一标识一行，自带 NOT NULL + UNIQUE
NOT NULL不允许为空
UNIQUE值唯一
DEFAULT 值缺省值
CHECK (条件)值须满足条件

ALTER 命令清单

ADD COLUMN phone VARCHAR(20)                      -- 加列
DROP COLUMN phone                                 -- 删列
ALTER COLUMN score TYPE NUMERIC(6,2)              -- 改类型（可隐式转换）
ALTER COLUMN score TYPE INTEGER USING score::INTEGER  -- 显式转换
ALTER COLUMN score SET DEFAULT 0.00 / DROP DEFAULT   -- 设/删默认值
ALTER COLUMN email SET NOT NULL                   -- 加非空
ADD CONSTRAINT score_check CHECK (score >= 0 AND score <= 100)  -- 加检查
RENAME COLUMN score TO total_score                -- 列改名
RENAME TO pupils                                  -- 表改名

DELETE vs TRUNCATE vs DROP

维度DELETETRUNCATEDROP
类型DMLDDLDDL
内容删部分/全部行清空全表连表带数据删除
WHERE支持不支持不支持
回滚可PG 中可不可
结构保留保留不保留
速度慢（逐行+日志）快（重置页面）最快

核心要点

  • SERIAL：INTEGER + 自动序列，自增主键懒人写法
  • 金额用 NUMERIC：定点精确；浮点不精确
  • JSONB 优于 JSON：二进制、可索引、查询快
  • 主键 = 唯一 + 非空，可复合多列
  • USING：改类型无法隐式转换时的显式规则
  • pg_dump -s：只导结构（干干净净的建表语句）
