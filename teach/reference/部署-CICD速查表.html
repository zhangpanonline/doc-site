部署-CICD速查表

配合《部署-CICD互动教学课程》使用。源课程：gitee.com/dev-edu/python-framework。

职责与仓库

环节触发做什么
CI代码提交uv sync --frozen + make test-unit（e2e/冒烟按需开）+ 通知
CD合并后构建镜像推 ACR → 还原 kubeconfig → 凭证 secret → helm 部署

三个镜像仓库：duyi-service-ci（测试环境）/ duyi-service-cd（构建环境）/ python（3.14-slim 基础镜像）。

CD 六个环境变量

KUBECONFIG_BASE64
kubeconfig 的 base64（集群控制权，最敏感）
ACR_USERNAME / ACR_PASSWORD
镜像仓库身份
DOCKER_SERVER
ACR 仓库专用网络地址
DB_PASSWORD / JWT_SECRET_KEY
生产数据库密码 / JWT 密钥

全部存流水线密钥区，不进代码库。版本：TAG=${CI_COMMIT_REF_NAME}，杜绝 latest。
