训练模式和框架速查表

配合《训练模式和框架互动教学课程》使用。

三种梯度下降训练模式

模式每一步用多少样本梯度特性适用场景
随机梯度下降
SGD		 只取 1 个样本 梯度噪声极大，收敛震荡 早年小数据集用；现代大模型基本不用
全批量梯度下降
Full Batch		 每一轮用全部训练集样本 梯度方向最稳定 大数据集显存 / 内存爆炸、迭代极慢，几乎不用于大模型训练
小批量梯度下降
Mini-Batch		 固定数量样本（batch_size：32 / 128 / 1024） 稳定性与速度平衡，显存可控 大模型主流；LLM、CV 模型全部默认使用

一句话：三种模式是同一条轴上的档位——batch_size = 1 就是 SGD，batch_size = 整个训练集大小就是全批量，中间都是小批量。

# 档位速记
batch_size = 1        # SGD：梯度噪声极大、收敛震荡
batch_size = N        # 全批量：方向最稳，但显存 / 内存爆炸、迭代极慢
batch_size = 32/128/1024   # 小批量：大模型默认（LLM、CV 通用）

网络架构与深度学习框架

名称定位核心思想 / 现状
CNN
卷积神经网络		 图像领域经典架构 模仿人眼视觉：图像是局部关联的，不用一次性看整张图，只滑动小窗口（卷积核）提取局部纹理、边缘、色块
Transformer NLP 起家，现在通用全能架构 本章只给定位，机制在后续章节展开
PyTorch 现在的主力训练框架 训练侧首选
TensorFlow 现在已经不再流行 通常用于做一些边缘计算

选型直觉：图像类任务想到 CNN 的「局部 + 滑窗」，序列 / 文本类任务想到 Transformer；训练跟主力框架走，端侧（手机离线推理）落在轻量运行时上。

模型文件的构成

模型是什么
模型是训练的结果，通常以多个文件的形式存储。
核心权重文件
占 99% 体积。存的是训练得到的张量数值（各层参数），本身不知道自己属于哪一层。
配置文件
记录模型的网络架构、隐藏层维度、权重精度等信息——说明「数值该按什么结构摆」。
为什么配置不能丢
加载时要先按配置建好同构网络，再把权重逐个填进去；缺了配置就只能靠猜层数 / 维度，形状对不上直接报错。
易错点正确认识
「batch_size 越大越好，设成全集收敛最快」 那是全批量：方向确实最稳，但大数据集显存 / 内存爆炸、迭代极慢——大模型默认仍是小批量。
「每一步只取 1 个样本 = 小批量」 每步 1 个样本是 SGD（随机梯度下降）：梯度噪声极大、收敛震荡。
「CNN 是通用全能架构」 通用全能是 Transformer 的定位；CNN 的主场是图像（局部关联 + 卷积核滑窗）。
「TensorFlow 是现在的主力训练框架」 反了：主力训练框架是 PyTorch，TensorFlow 常用于边缘计算。
「只拷贝权重文件就能跑」 权重只是数值；配置文件（架构、隐藏层维度、精度）一起带上才装得回去。
