三个概念

IoC
设计思想：把某种选择权移交出去，避免与其耦合。
DI
把 IoC 落地的手段（依赖作为参数传入）。
IoC 容器
优化 DI 的工具，负责交付依赖项。

手写容器内核（课件）

class Depends:
    _overrides = {}          # 注册表：原函数 → 替代实现
    def __init__(self, func):
        self.func = func
    def __call__(self, *a, **kw):
        actual = self._overrides.get(self.func, self.func)
        return actual(*a, **kw)
    # override(original, replacement) / clear_override()

调用点声明 Depends(默认实现)；切换/测试时 override 注册表，调用点零改动。
