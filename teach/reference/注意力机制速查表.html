注意力机制速查表

配合《注意力机制互动教学课程》使用。

一句话定位

注意力层解决的是：每个 token 受到上下文影响后，该如何调整自身的值。入口是 Embedding 输出的 $4 \times 6$ 矩阵（4 个 token × 6 维），出口仍是 $4 \times 6$——中间做的是一次「按相关度对信息加权求和」。前提：本章全部推演针对训练的前向传播，不是推理。

$\mathrm{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \mathrm{softmax}\!\left(\dfrac{\mathbf{Q}\mathbf{K}^{\top}}{\sqrt{d_k}}\right)\mathbf{V}$

五步链路与形状自检

步操作形状（X 为 4×6）要点
① 投影$\mathbf{Q}=\mathbf{X}\mathbf{W}^{Q}$、$\mathbf{K}=\mathbf{X}\mathbf{W}^{K}$、$\mathbf{V}=\mathbf{X}\mathbf{W}^{V}$4×6（W 均为 6×6）三个 W 是可学习的不同参数，不是把 X 切三份
② 打分$\mathbf{Q}\mathbf{K}^{\top}$4×4第 i 行第 j 列 = 第 i 个 token 对第 j 个 token 的关注打分（原始点积）
③ 缩放除以 $\sqrt{d_k}$4×4$d_k$ 是每个头的维度；不缩放会把 Softmax 推向梯度极小区域
④ 掩码把 $j > i$ 置为 $-\infty$4×4右上三角＝「未来」，必须遮住以维持自回归性质
⑤ Softmax逐行归一化4×4每行和为 1；被掩位置权重恰为 0
⑥ 加权权重矩阵 × $\mathbf{V}$4×6（单头 4×3）输出就是 V 的各行按权重做的加权和
⑦ 多头拼接各头输出拼接回到 4×6例：6 维切 2 头（每头 3 维）→ 算完拼回 6 维

形状口诀：(4×6)(6×4) → 4×4 打分，(4×4)(4×6) → 4×6 输出——两头都回到 4，中间那个维度被消掉。

术语卡

Q（Query）
我怎么去找别人？——拿着自己的问题去问全场。
K（Key）
别人怎么找到我？——我身上挂的标签，用来被别人匹配。注意 Q 与 K 的指向相反。
V（Value）
我找到别人后，对它施加怎样的影响？——真正被加权汇总进输出的内容。
$\mathbf{W}^{Q}/\mathbf{W}^{K}/\mathbf{W}^{V}$
三组独立的可学习投影矩阵（本章示例均为 6×6）；同一份 X 乘出三种角色的表示。
注意力得分
$\mathbf{Q}\mathbf{K}^{\top}$，形状 $L \times L$（L 为 token 数）；越大表示两个位置越相关。
缩放因子
$1/\sqrt{d_k}$，$d_k$ = 每个头的维度。点积方差随 $d_k$ 增长，不缩放会让 Softmax 过陡、梯度极小。
掩码（Masked）
把 $j > i$ 的位置置 $-\infty$ 再 Softmax，等价于该位置权重为 0；decoder 自注意力的必备件。
多头（Multi-Head）
把 $d_{model}$ 切成 h 份并行做注意力，让模型在不同表示子空间、不同位置上共同关注信息。
Add & Norm
decoder 每一层的残差连接 + 层归一化，跟在注意力子层与 Feed Forward 子层之后。

decoder 里它站在哪

inputs
  → embedding
  → N ×[ Masked Multi-Head Attention → Add & Norm
         → Feed Forward            → Add & Norm ]
  → Linear
  → Softmax
  → Output Probabilities

本章只展开标着 Masked 的那一层注意力；N × 表示这一段结构会重复堆叠 N 次。

易错点

写法问题正确做法
把 X 均分成三份当 Q/K/V没有任何参数，三种角色被锁死在同一组数值上分别乘 $\mathbf{W}^{Q}$、$\mathbf{W}^{K}$、$\mathbf{W}^{V}$ 三个可学习投影
softmax(Q @ K.T) @ V缺缩放、缺掩码；训练时会看到"未来"，结果静默训坏先 / sqrt(d_k)，再 masked_fill(j>i, -inf)，然后 softmax，最后 @ V
先 Softmax 后掩码被掩位置变成正常概率，每行权重和也不再是 1先置 $-\infty$ 再 Softmax
掩码方向写反（遮 j < i）上文被遮光，只剩当前 token 自己遮 j > i（右上三角）
$\sqrt{d_k}$ 用了 $d_{model}$ 或输入维度缩放系数偏大／偏小，Softmax 陡峭程度不对用每个头的维度：$d_k = d_{model} / h$
布尔掩码语义记混F.scaled_dot_product_attention 的 attn_mask 里 True=参与；MultiheadAttention 的 key_padding_mask 里 True=屏蔽从 MHA 迁移到 SDPA 时记得取反（~mask）
