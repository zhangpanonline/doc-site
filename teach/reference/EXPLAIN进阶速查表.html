EXPLAIN 进阶速查表

配合《EXPLAIN 进阶互动教学课程》使用。来源：官方文档 §14.1（postgres.cn），非渡一课程内容。

两个命令

命令执行查询？输出
EXPLAIN否计划 + 估算（cost / rows）
EXPLAIN ANALYZE是（官方原文）计划 + 估算 + 每节点真实行数与时间（actual）

优化方法论

定位
官方：选择正确计划对性能绝对关键；阅读计划是一门艺术。
流程
EXPLAIN 看计划 → 找异常节点（全扫/排序/回表）→ ANALYZE 对照实况 → 对症下药（索引/改写/ANALYZE 表）。
估算偏差
官方：统计是随机样本、成本依赖平台——几倍偏差常态；数量级对不上才判「统计过期」。
生产红线
ANALYZE 真执行查询——大查询先普通 EXPLAIN，必要时在从库 ANALYZE。
输出格式
人读 text；程序分析用 XML/JSON/YAML。
