调试链路与 tracer 原理

调试客户端（VSCode）──DAP 协议──▶ 调试适配器（debugpy）──控制──▶ 被调试程序

# 最小适配器：sys.settrace
def my_tracer(frame, event, arg):
    print(f"事件: {event}, 行号: {frame.f_lineno}")
    return my_tracer          # 返回自身以持续追踪

sys.settrace(my_tracer)
exec(code)
# event 取值：line（执行一行）/ call / return / exception

launch.json 两种模式

# 单文件调试（launch：调试器启动程序）
{
  "name": "Python 调试程序: 当前文件",
  "type": "debugpy",
  "request": "launch",
  "program": "${file}"
}

# 工程调试（attach：连接已运行的程序）
{
  "name": "Attach to make run",
  "type": "debugpy",
  "request": "attach",
  "connect": { "host": "localhost", "port": 5678 }
}

工程调试流程

uv add --dev debugpy          # 安装调试适配器

# Makefile
run-web-debug:
	uv run --package web-service \
	  python -m debugpy --listen 5678 --wait-for-client \
	  app/web-service/main.py

make run-web-debug           # 启动被调试程序（等待客户端）
# 然后 VSCode 里 attach localhost:5678
