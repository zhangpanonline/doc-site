Future 类速查表

配合《Future 类互动教学课程》与《25.Future类》使用。建议打印一份放在手边。

状态机

fut = loop.create_future()      # 创建：未完成
fut.done()                       # False
# fut.result()                   # ❌ InvalidStateError（未完成取结果）

fut.set_result("result")         # 正常完成
fut.set_exception(TypeError())   # 错误完成（result() 会抛该异常）
fut.cancel("不等了")             # 取消（cancelled() → True）

fut.done()      # True
fut.result()    # 结果；异常完成/取消时抛异常
fut.exception() # 异常对象；无异常为 None
fut.cancelled() # 是否被取消

fut.add_done_callback(on_done)   # 完成回调 → 进 ready 队列，事件循环调度

封装套路（把阻塞操作包成 Future）

# 延时封装
def async_delay(duration: int):
    loop = asyncio.get_event_loop()
    future = loop.create_future()
    loop.call_later(duration, future.set_result, None)  # 到点完成
    return future

# 网络封装思路（三步）
# 1. async_connect：非阻塞 connect + add_writer 监听可写 → set_result(sock)
# 2. async_read：send 请求 + add_reader 收数据 → set_result(data)
# 3. async_request：connect 完成的回调里再发起 read，链式传递结果

常见误区

  • 未完成就 result() 抛 InvalidStateError：先 done() 检查或走回调。
  • 回调不是同步执行：add_done_callback 进 ready 队列，等事件循环调度（对已完成 Future 注册也有效）。
  • 异常完成的 Future：回调里 f.result() 会抛异常，要 try/except。
  • Future 本身不执行任务：它只是容器；「做事的」是 call_later/IO 监听/Task。
  • 封装后别忘 stop：demo 里回调执行完没有 stop，run_forever 不会退出。
