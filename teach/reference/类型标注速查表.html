泛型与 TypedDict 模板

# 泛型类
from typing import TypeVar, Generic

T = TypeVar("T")

class Stack(Generic[T]):
    def __init__(self) -> None:
        self._items: list[T] = []
    def push(self, item: T) -> None: ...
    def pop(self) -> T: ...

int_stack: Stack[int] = Stack()

# TypedDict（固定键结构的字典）
from typing import TypedDict

class DatabaseConfig(TypedDict):
    host: str
    port: int
    username: str

class AppConfig(TypedDict):
    app_name: str
    debug: bool
    db: DatabaseConfig          # 可以嵌套

常见误区

  • 运行时不强制：标注是给 IDE/类型检查器（mypy/pyright）看的提示。
  • 裸 List/Dict 等于没说：必须带类型参数 list[int]。
  • 可空的要标出来：可能返回 None 就标 int | None，别用 int 掩盖。
  • type: ignore 尽量少用：必要时 # type: ignore[code] 精确忽略。
  • 泛型别忘 TypeVar：T = TypeVar("T") 才能参数化。
