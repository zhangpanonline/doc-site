统一异常处理速查表

配合《统一异常处理互动教学课程》使用。源课程：gitee.com/dev-edu/python-framework。

五条最佳实践

  1. 异常的自定义处理收拢到统一代码位置
  2. 请求-响应链条中的异常不能中断服务器
  3. 服务端敏感信息不能暴露给响应
  4. 按异常类型响应不同字段：status code / code / message
  5. API 文档中需要包含全局异常表

处理器分支逻辑

HTTPException
code=状态码；消息查协议表，查不到用 exc.detail。
RequestValidationError
exc.errors() 逐条拼「loc: msg」多行消息。
BusinessException
用 exc.message（不暴露 detail）。
未知异常
_lookup 按 MRO 查表回退 Exception 兜底 → 500001。
注册
add_exception_handler × 3：RequestValidationError / HTTPException / Exception。
文档
generate_error_docs() 从两张映射生成异常表注入 description。
