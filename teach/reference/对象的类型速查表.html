对象的类型速查表

配合《对象的类型互动教学课程》与《9.对象的类型》使用。建议打印一份放在手边。

术语表

类型
创建对象的类；type(对象) 得到它。
元类
创建类的类，默认是 type。
继承链
子类 → 父类 → … → object（万物之根，终点）。
创建链
实例 ← 类 ← type（万物之源，起点）。
自指
type(type) → type：type 是自己的实例。

关键结论速查（demo1.py 全部结果）

表达式结果一句话原因
type(type)typetype 是自己的元类（自指）
isinstance(type, type)True同上
isinstance(type, function)Falsetype 是类不是函数
isinstance(type, object)True所有类都继承 object
type(object)typeobject 也由 type 创建
isinstance(object, type)Trueobject 是 type 的实例
type(类A)type类的类型是元类
type(实例a)A实例的类型是类
isinstance(A, A)False类 A 不是 A 的实例
isinstance(a, A)True实例是类的实例
isinstance(a, object)True万物皆 object 实例
type(func)function函数的类型是 function
isinstance(function, function)Falsefunction 类是 type 的实例

成员查找顺序

类成员（类属性/类方法）：
  ① 自身的 MRO 链条（子类 → 父类 → object）
  ② 元类的 MRO 链条

实例成员（实例属性/实例方法）：
  ① 实例自身（__dict__）
  ② 类型的 MRO 链条（类 → 父类 → object）

三种下划线

写法含义外部访问
_a约定私有（推荐日常用）可访问，不建议
__a名称改写 _A__a报错（可绕）
__a__系统内置成员可访问
