模块化速查表

配合《模块化互动教学课程》与《21.模块化》使用。建议打印一份放在手边。

导入语法

import my_math                # 整模块，用 my_math.PI 访问
from my_math import PI, add   # 只导入成员
from my_math import *         # 只导入 __all__ 清单（谨慎）
import my_math as mm          # 模块别名
from my_math import add as my_add   # 成员别名
from .math_ops import add     # 相对导入：. 当前包，.. 父包
importlib.import_module(name) # 动态导入（模块名来自变量）

关键机制

机制要点
__all__只影响 import *；也是公开 API 文档
__name__直接运行 = "__main__"；被导入 = 模块名
__init__.py包的标志；首次导入包时执行；组织导出接口
执行与缓存首次导入执行一次，之后走 sys.modules
搜索顺序内置模块 → 脚本目录 → PYTHONPATH → site-packages
下划线成员_x 不会被 import * 导入（约定私有）

__slots__ 速查

class Point:
    __slots__ = ("x", "y")     # 固定实例属性槽位

    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(1, 2)
# p.z = 3        # AttributeError！没有 __dict__，不能加新属性

# 作用：省内存（无实例 __dict__）、防拼写错误
# 代价：不能动态加属性；与多继承/弱引用有兼容注意点

常见误区

  • 循环导入：a 导 b、b 导 a 会 ImportError——抽公共模块或延迟导入。
  • 相对导入不能直接运行：含 from .x import y 的文件要用包的方式导入。
  • import * 拿不到非 __all__ 成员：E、subtract 不在清单里就进不来。
  • __slots__ 后实例无 __dict__：依赖 vars(obj) 的代码会失效。
