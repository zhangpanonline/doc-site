词元速查表

配合《词元互动教学课程》使用。

核心术语

词元（Token）
文本经过分词后得到的数字序列中的每一个数字。
分词（Tokenize）
把文字序列转化为可被 AI 使用的数字序列的过程。
分词器（Tokenizer）
执行分词的组件：一份词表 + 一套切分规则（匹配顺序）。
分词表（token vocabulary，Vocab）
「有意义的字／词 → 数字」的对照表，由训练得到；固定后不再改动，分词只查表。
BPE（字节对编码）
从 256 个单字节起步，反复合并高频相邻对把词表「长」到目标大小。

三种「文字变数字」的方案

方案表示粒度主要问题
直接用 UTF-8 字节数字1 个汉字 = 3 个数字长度膨胀（计算量／显存／训练速度恶化）、每层重复学习固定字节组合、学不到字词边界
整词词表（word-level）1 个词 = 1 个 id词表巨大；表外词退化成 <unk>，新词无法表示
byte-level BPE（本课）字节起步 + 高频合并词表小或语料未覆盖时，一个汉字会被拆成多个字节片段

目标形态：「你好 → 10000、Hello → 10001、! → 10002、123 → 10003」——整句 4 个数字，且每个数字对应可被学习的语义。

BPE 训练与分词流程

# 训练（词表怎么长出来）
vocab = {i: bytes([i]) for i in range(256)}      # ① 初始词表：256 个单字节
while len(vocab) < target_vocab_size:            # ④ 循环到目标大小
    pair_counts = Counter(相邻对)                 # ② 统计当前序列的相邻对频次
    best_pair = pair_counts.most_common(1)[0]    #    取最高频的一对
    vocab[len(vocab)] = vocab[best_pair[0]] + vocab[best_pair[1]]
    seq = 把 seq 中的 best_pair 全部替换成新 id    # ③ 写入新 id 并替换

易错点与 token 估算

  • 结果里出现 <字节 e6> 这类片段不是编码损坏，而是该字的多字节组合没进词表（词表太小／语料没出现过该词）。
  • 导出词表时，无法按 UTF-8 解码的字节要存十六进制；读回时用 bytes.fromhex 还原，不要 s.encode() 当普通文本处理。
  • 分词是最长匹配（从长到短试），写成从短到长会切出更多碎片。
  • 换语料、换分词算法、换模型 → 词表不同 → 分词结果不同，token 统计与长度拦截必须重算。
  • 「可逆无损」只对整条 token 序列成立；单个 token 可能落在 UTF-8 边界中间，单独解码会有损，要用字节级接口处理。
