部署-认识Docker速查表

配合《部署-认识Docker互动教学课程》使用。源课程：gitee.com/dev-edu/python-framework。

三件套

Dockerfile
配置文件 → 构建镜像；RUN 构建期执行、CMD 容器启动时执行。
镜像
包含运行所需的一切（python/uv/.venv）；slim 比完整镜像小 90%。
容器
镜像启动的实例，运行 CMD；不可变，更新=换新镜像。

多阶段骨架

FROM python:3.14-slim AS builder
WORKDIR /app
RUN pip install uv
ENV UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
COPY . .
RUN uv sync --frozen --no-dev --no-editable

FROM python:3.14-slim          # 干净环境
WORKDIR /app
COPY --from=builder /app/.venv /app/.venv
ENV PATH="/app/.venv/bin:$PATH"
EXPOSE 8080
CMD ["uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8080"]

docker run 六个参数

参数作用
-d后台运行
--name容器命名
-p 9090:8080宿主机:容器端口映射
-e KEY=VAL环境变量（配置/密钥运行时注入）
--restart unless-stopped意外退出/宿主机重启自动拉起
--memory / --cpus资源上限，防拖垮宿主机

简易部署四步：开发 → 本地构建镜像 → 传输给服务器 → 服务器运行容器。
