文件上传速查表

配合《文件上传互动教学课程》使用。源课程：gitee.com/dev-edu/python-framework。

直传流程

  1. 客户端向服务端申请上传凭证（声明文件名与大小）
  2. 服务端生成 policy + signature 并返回凭证六字段
  3. 浏览器表单直接 POST 到 OSS（文件流不经过应用服务器）

凭证六字段

字段含义
hostBucket 域名，表单 POST 目标
access_idOSSAccessKeyId 表单字段
policyBase64 的策略文档（expiration + conditions）
signatureHMAC-SHA1(secret, policy) 再 Base64
key服务端预定的对象路径（dir_strategy + uuid + 后缀）
content_typeMIME 白名单查表得出

安全三件套

conditions
eq $key / eq $Content-Type / content-length-range 0..file_size
目录策略
date_uuid（uploads/YYYY/MM/DD/）vs flat_uuid（uploads/）；Callable 注入可换。
IAM 最小权限
oss:PutObject / oss:GetObject / oss:DeleteObject，Resource 限定 bucket/*。
异步边界
oss2 是同步 SDK——delete/exists 用 asyncio.to_thread 防卡事件循环。
