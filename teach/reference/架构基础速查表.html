架构基础速查表

配合《架构基础互动教学课程》使用。来源：官方教程 §1.2（postgres.cn），非渡一课程内容。

术语表

客户端/服务器模型
PG 的基础架构：服务器管理数据、客户端发起操作，跨主机经 TCP/IP 通信。
postgres 进程
数据库服务器程序：管理数据库文件、接受连接、代表客户端执行操作。
守护进程
最初的 postgres 进程：常驻，等待连接并 fork 连接进程。
连接进程
每个连接 fork 出的新进程：与客户端直接通信，会话结束即退出。
fork
进程复制创建：PG 为每个连接 fork 一个进程（非线程）。
pg_stat_activity
系统视图：观察当前所有连接进程的 pid、状态与执行的语句。

会话生命周期

阶段发生的事关键点
① 等待守护进程常驻监听连接永远在运行
② 接入新连接到来 → fork 新进程每连接一个进程
③ 直连客户端与新进程直接通信不再经过守护进程
④ 结束会话结束 → 连接进程退出起起停停，守护进程不动

面试速记

进程 vs 线程模型
PG 进程模型：隔离好、连接开销大 → 连接数敏感 → 连接池（PgBouncer）动机。
文件可见性
COPY/导入路径由服务器读取；客户端文件用 psql \copy。
观察命令
SELECT pid, usename, state FROM pg_stat_activity; · pg_terminate_backend(pid) 杀掉指定连接。
客户端形态
psql / 图形界面 / Web 服务器 / 管理工具——任何发起连接的程序都是客户端。
