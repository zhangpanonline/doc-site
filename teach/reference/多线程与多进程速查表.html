多线程与多进程速查表

配合《多线程和多进程互动教学课程》与《28.多线程与多进程》使用。建议打印一份放在手边。

场景选型

场景方案
CPU 密集multiprocessing / ProcessPoolExecutor
同步 I/O 密集threading / ThreadPoolExecutor
异步 I/O 密集asyncio / 协程
调用第三方同步库asyncio.to_thread / run_in_executor

GIL：同一时刻只有一个线程执行 Python 字节码——多线程不能加速 CPU 密集任务；I/O 等待时释放 GIL。

锁工具箱

# Lock：互斥锁（不可重入，重复 acquire 会死锁）
lock = threading.Lock()
with lock:
    # 临界区：检查 + 修改整体包进来
    ...

# RLock：可重入锁（递归函数用）
lock = threading.RLock()

# Semaphore：限制并发数（最多 N 个线程进入）
sem = threading.Semaphore(3)
with sem:
    ...

# Event：线程间通知
event.wait()   # 阻塞等待
event.set()    # 唤醒等待者

# Queue：线程安全的队列（内部已同步）
q = queue.Queue(maxsize=5)
q.put(item) / q.get() / q.task_done()

# ThreadPoolExecutor：复用线程
with ThreadPoolExecutor(max_workers=3) as ex:
    results = ex.map(fetch_url, urls)

常见误区

  • 锁要包住「检查 + 修改」整个临界区：只锁扣款一行，检查窗口仍在。
  • 普通 Lock 不可重入：递归/嵌套加锁用 RLock。
  • 死锁解法 = 固定锁顺序：所有线程按相同顺序获取多把锁。
  • 守护线程别操作资源：可能被强制终止在半途。
  • CPU 密集别用多线程：GIL 下不加速，用多进程。
