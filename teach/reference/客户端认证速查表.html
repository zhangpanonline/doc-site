客户端认证速查表

配合《客户端认证互动教学课程》使用。来源：官方文档 §20.1（postgres.cn），非渡一课程内容。

pg_hba 条目

# TYPE  DATABASE  USER  ADDRESS        METHOD
host    all       all   127.0.0.1/32   trust
host    all       all   10.0.0.0/24    scram-sha-256
要点说明
匹配从上到下逐条匹配，命中第一条即生效
重载pg_ctl reload / pg_reload_conf() / kill -HUP（启动与 SIGHUP 时读取）
trust免认证——仅限本机回环开发
scram-sha-256现代密码认证默认
peer本机系统用户名与库用户名同名

排错速记

连接被拒/超时
网络、端口、listen_addresses。
no pg_hba.conf entry
没有匹配的 hba 条目——加覆盖该来源地址的 host 条目。
password authentication failed
hba 已放行，密码/角色问题。
改完没生效
忘 reload（Windows 例外：立即生效）。
