类和对象速查表

配合《类和对象互动教学课程》与《8.类和对象》使用。建议打印一份放在手边。

术语表

类 Class
创建对象的蓝图；类本身也是对象，由元类 type 创建。
实例属性
每个对象独立，通过 self.x 定义，存于实例 __dict__。
类属性
所有实例共享，类体内直接定义；修改要通过类名。
MRO
方法解析顺序：多继承下查找方法/调用 super 的顺序链，C.__mro__ 查看。
super()
沿 MRO 调用下一个类的方法，不一定是直接父类。
名称改写
__name 被改写为 _类名__name，外部直接访问报错。
反射
运行时检查/操作对象：type / isinstance / getattr / setattr / hasattr / vars / dir。

工具作用关键点

常见误区

  • 实例上给类属性赋值不会修改类属性：dog1.species = "X" 只会给 dog1 新建实例属性，其他实例无感；改类属性用 Dog.species = "X"。
  • super() 沿 MRO 而非固定父类：C(A, B) 中 A 的 super() 调到 B。
  • 双下划线只是名称改写：obj.__password 报错，但 obj._BankAccount__password 仍可访问——约定防护，不是安全边界。
  • type 与 isinstance 结论不同：type(dog) == Animal → False，isinstance(dog, Animal) → True。
  • 多继承优先组合：菱形继承难维护，能组合就别多继承。
