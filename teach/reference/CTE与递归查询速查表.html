CTE 与递归查询速查表

配合《CTE 与递归查询互动教学课程》使用。来源：官方文档 §7.8（postgres.cn），非渡一课程内容。

递归 CTE 模板

WITH RECURSIVE 名(列...) AS (
    -- 非递归项（种子，不可引用自身）
    SELECT ... FROM 表 WHERE 根条件
    UNION ALL
    -- 递归项（可引用自身；必须有终止条件）
    SELECT ... FROM 表 e JOIN 名 r ON e.父键 = r.键 WHERE 深度限制
)
SELECT ... FROM 名;

求值五步（官方原文）

步骤动作
①算非递归项；UNION（非 ALL）去重
②剩余行 → 结果 + 工作表
③工作表非空则循环：用它替换递归自引用，算递归项
④UNION 去重（含与历史结果重复）；剩余行 → 结果 + 中间表
⑤中间表替换工作表、清空中间表 → 回到 ③

面试速记

形式铁律
非递归项 + UNION [ALL] + 递归项；只有递归项能引用自身输出。
UNION vs UNION ALL
UNION 每轮去重（开销大）；UNION ALL 不去重（快，但终止条件必须有效，否则无限循环）。
终止
递归项一轮无输出 → 工作表为空 → 终止；防御：深度上限、statement_timeout、防环标记。
适用场景
分层/树形结构（组织树、BOM、目录树）；纯读取让数据库做，带业务逻辑回应用层。
本质
RECURSIVE 内部是迭代评估，不是函数递归调用。
