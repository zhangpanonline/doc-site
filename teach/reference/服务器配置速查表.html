服务器配置速查表

配合《服务器配置互动教学课程》使用。来源：官方文档 §19.1（postgres.cn），非渡一课程内容。

参数语法（官方）

类型语法要点
布尔on/off/true/false/yes/no/1/0 或任何无歧义前缀
字符串单引号包裹；内部单引号双写
数字小数值四舍五入；十六进制 0x、八进制 0；无千位分隔符
带单位数字显式单位须写成字符串（'120 ms'）；内存单位 1024 进制（B/kB/MB/GB/TB）；时间 us/ms/s/min/h/d
枚举固定值集合

参数名大小写不敏感（官方原文）。

会话级操作

SHOW work_mem;                          -- 查看当前值
SET work_mem = '64MB';                   -- 仅当前会话（不影响其他）
SET work_mem TO DEFAULT;                 -- 恢复默认
SELECT current_setting('work_mem');      -- 函数等价 SHOW
SELECT name, setting, unit, context FROM pg_settings;   -- 视图（context=生效级别）
生效级别
context 列：postmaster=重启级（SET 报错）；user=会话可 SET。
持久化
ALTER SYSTEM SET / postgresql.conf——SET 只是会话本地。
