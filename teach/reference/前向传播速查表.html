前向传播速查表

配合《前向传播互动教学课程》使用。

四组核心公式

# 1. 单个神经元
y = σ( Σᵢ wᵢxᵢ + b )          # LaTeX: $y = \sigma(\sum_{i=1}^n w_i x_i + b)$

# 2. 神经网络中的单个神经元（L = 第 L 层，j = 当前层第 j 行神经元）
a^L_j = σ( Σᵢ wᵢ · a^(L-1)_i + b )   # LaTeX: $a^{L}_j = \sigma(\sum_{i=1}^n w_i a^{L-1}_i + b)$

# 3. 某一层（矩阵形式 / 简写形式）
a^(l) = σ( W^(l) a^(l-1) + b^(l) )   # LaTeX: $\mathbf{a}^{(l)} = \sigma\left( \mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)} \right)$
       (n×m)(m×1) + (n×1)  →  n×1

# 4. 总参数量
Σ(l=1..L) ( n_l × n_{l-1} + n_l )
     = (n₁n₀ + n₁) + (n₂n₁ + n₂) + … + (n_L n_{L-1} + n_L)

链路一句话：上一层输出 → 乘本层权重 → 加本层偏置 → 逐元素过激活函数 → 本层输出，逐层往下走就是前向传播。

符号与维度速查

符号含义大小
a^(l)第 l 层的输出向量n × 1
a^(l-1)第 l-1 层的输出向量（本层输入）m × 1
W^(l)第 l 层的权重矩阵n × m（行 = 本层神经元数，列 = 上一层输出维）
b^(l)第 l 层的偏置向量n × 1
σ(·)激活函数（如 Sigmoid、ReLU 等）形状不变，逐元素作用

维度自检：(n × m)(m × 1) → (n × 1)——中间维度 m 必须相等，输出行数由 W 的行数决定。

一层怎么算
n_l × n_{l-1} + n_l：权重矩阵元素数 + 偏置向量元素数。
和 batch 的关系
参数量只由各层神经元个数决定，与一次喂多少样本无关；批量只把 a^(l-1) 从 m × 1 变成 m × B，公式不变。
易错 ①
把 W 记成 m × n：矩阵乘法维度对不上，直接报错。
易错 ②
把偏置写成 1-D 的 (n,) 而不是 (n, 1)：NumPy 广播会把结果撑成 (n, n)，不报错但结果全错。
易错 ③
用 * 代替 @：* 是逐元素相乘，不是矩阵乘法；矩阵乘法用 @ 或 np.matmul。
易错 ④
激活函数套错位置：必须是 σ(W a + b)，不是 W·σ(a) + b，也不是 σ(W a) + b。
