函数速查表

配合《函数互动教学课程》与《5.函数》使用。建议打印一份放在手边。

术语表

位置参数
按定义顺序传参：add(3, 5)。
默认参数
带默认值，调用时可省略；必须放在非默认参数后面。
关键字参数
按参数名传参，顺序任意：f(age=25, name="Alice")。
*args
收纳多余的位置参数，内部是元组。
**kwargs
收纳多余的关键字参数，内部是字典。
多返回值
return a, b 本质是返回元组，接收端解包。
docstring
函数体第一行的三引号字符串，f.__doc__ 可查看。

参数速查

def f(a, b=2, *args, **kwargs):
    #   位置  默认  多余位置→元组  多余关键字→字典
    pass

f(1)                      # a=1, b=2, args=(), kwargs={}
f(1, 3)                   # a=1, b=3
f(1, 3, 4, 5, x=10)       # a=1, b=3, args=(4, 5), kwargs={'x': 10}
f(1, b=3, x=10)           # 关键字参数传默认参数，合法

# 混合调用：位置参数必须全部在关键字参数之前
f(1, 2, x=10)             # ✅
f(a=1, 2)                 # ❌ SyntaxError

常见误区

  • 可变默认值陷阱：def f(items=[]) 的 [] 只在定义时创建一次，多次调用共享同一列表。 
    def f(items=[]):          # ❌ 共享同一个列表
    items.append(1)
    return items

def f(items=None):        # ✅ 每次调用新建
    if items is None:
        items = []
    items.append(1)
    return items
  • 默认参数必须放后面：def f(a=1, b) → SyntaxError。
  • 没有 return 返回 None：result = print("hi") 后 result 是 None。
  • 多返回值是元组：return a, b 得到 (a, b)。
  • 位置参数不能在关键字参数后：f(x=1, 2) → SyntaxError。
  • 参数顺序固定：位置 → 默认 → *args → **kwargs。
