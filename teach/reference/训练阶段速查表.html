训练阶段速查表

配合《训练阶段互动教学课程》使用。

预训练 vs 后训练

对照项预训练后训练
解决的问题 造能力底座：模型「能做什么」 教怎么用：模型「怎么说、说不说」
耗时 最长，通常占总计算时间的 90% 以上 很短：几小时、几天、几个月
学习方式 自监督学习（监督信号来自文本自身） 监督学习 + 强化学习
主要成本 算力 数据与人力（标注、评分、数据构造）
产出 语言、知识、基础推理、模式识别、上下文学习 对话格式、价值观、能力校准、CoT、专业领域知识

一句话：预训练造能力，后训练教怎么用。只做预训练的 base 模型不是「不会说话」，而是不好用、不可控——该停不停、该拒答时硬答。

预训练赋予模型的六种基础能力

能力课件里的例子
理解人类语言的语法规律语言组织的通用规则
感知上下文语境识别不同语境下词语含义的变化
知晓世界的基本事实太阳系有几大行星、第二次世界大战哪一年结束、Python 创始人是谁
基础的推理能力凡人均有一死，苏格拉底是人 → 苏格拉底会死
基础的模式识别能力2, 4, 6, 8, ?
基础的上下文学习能力「你是一个智能客服，请在回答时称用户为宝宝」——规则写在提示里就能照做

量级参考：NVIDIA 公开的 Nemotron 3 Nano 配方中，Stage 0 预训练是从零开始在 25 万亿 token 上训练，之后才是 SFT 与 RL 阶段。

后训练到底做了什么

后训练目标做法效果
学会对话格式 喂带特殊标记的完整对话（<|im_start|>system / user / assistant…<|im_end|>） 学会对话格式、对话中的角色身份、对话语气；知道轮次在哪结束
竖立价值观 人类标注「好/坏」回答对比 → 训练奖励模型 → 强化学习 让模型趋利避害：回答安全、有用、诚实
能力校准 加入大量「承认无知」问答对（如「你知道明天会发生什么吗？」→「作为 AI，我无法预测未来……」） 有效降低 AI 幻觉：不知道就承认不知道
思维链 CoT 训练与引导模型先输出推理步骤、再输出最终回答 推理过程可见，最终答案的准确率更高（但不保证一定正确）
专业领域知识 用领域数据继续训练 / 微调 把通用助手变成某个领域的熟手

成本与依赖：后训练以 SFT 检查点作为起点，再往上做 RL 对齐（DPO 用偏好对，RLHF 用奖励模型当裁判）；方法选型上，格式与术语交给 SFT，主观语气交给 DPO，复杂多步推理交给 RFT。

两种格式：对话模板与思维链

对话模板（后训练「学会对话格式」看的就是它）
<|im_start|>system<|im_sep|>你是一个AI聊天助手，你的名字叫袁大炮<|im_end|>
<|im_start|>user<|im_sep|>你好，你是谁？<|im_end|>
<|im_start|>assistant<|im_sep|>我是袁大炮<|im_end|>

思维链 CoT（assistant 回合内部：先想，再答）
<|im_start|>user<|im_sep|>小明有10个苹果，他给了小红3个，又买了5个，现在他有多少个苹果？<|im_end|>
<|im_start|>assistant<|im_sep|>
<think>
开始有10个。给了小红3个，还剩 10 - 3 = 7 个。又买了5个，现在有 7 + 5 = 12 个。所以，答案是12个。
</think>
最终答案是 12。<|im_end|>
特殊标记的职责
<|im_start|> 开一轮对话、<|im_sep|> 分隔角色与内容、<|im_end|> 结束当前轮次——模型靠它们学会「谁是用户、轮到谁说话、说到哪停」。
CoT 的准确定义
通过训练和引导，让模型在给出最终答案之前，先把内部的推理步骤「说出来」，即先输出思考过程、再输出最终回答。
持续学习
Continual Learning / 增量学习：厂商把 AI 与用户之间的对话内容作为语料，持续对大模型进行训练。
别混淆
上下文学习是把示例写进提示词、模型现学（不改权重）；持续学习是拿真实对话当语料持续更新模型。

易错点

常见说法正确认识
「后训练只是把回答包装成对话格式」 格式只是一项；价值观对齐、能力校准（承认无知）、CoT、专业领域知识都在后训练完成。
「预训练做完，模型就能直接当客服」 base 模型有知识与基础推理，但不守对话格式与角色边界，也没有安全/诚实价值观与「承认无知」校准。
「后训练耗时短，所以很便宜」 耗时短 ≠ 便宜：后训练的主要成本是数据与人力——标注、偏好对、grader 都要人来做。
「CoT 就是让答案变长」 CoT 是「先输出思考过程、再输出最终回答」的输出形态，由训练和引导促成；它提升准确率，但不保证答案正确。
「上下文学习 = 持续学习」 上下文学习只发生在提示词里，不改权重；持续学习是拿用户对话当语料继续训练模型。
「思维链里打印出来的就是模型的真实内部推理」 不同厂商口径不同：一类模型只给推理摘要、原始推理不对外暴露；另一类用平级字段返回思考内容，且是否回传进上下文取决于请求是否带 tools。
