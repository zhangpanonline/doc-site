Monorepo 速查表

配合《Monorepo 互动教学课程》与《29.Monorepo》使用。建议打印一份放在手边。

workspace 三步

# 1. 根项目声明成员
# pyproject.toml
[tool.uv.workspace]
members = [
    "packages/*",
    "app/*",
]

# 2. 创建成员包
uv init --lib packages/shared
uv init --lib packages/agents
uv init app/web-service

# 3. 成员间依赖（packages/agents/pyproject.toml）
dependencies = ["shared"]
[tool.uv.sources]
shared = { workspace = true }   # 从工作区源码链接

# 同步与运行
uv sync --all-packages
uv run --package web-service python app/web-service/main.py

三种引用模式

模式写法场景
workspace{ workspace = true }仓内成员（改码即时生效）
path{ path = "../utils" }工作区外的本地包
git{ git = "URL", rev = "v0.1.0" }未发布到 PyPI 的依赖

同名冲突时 workspace 优先；强制 PyPI 用 { workspace = false }。
