备份与恢复速查表

配合《备份与恢复互动教学课程》使用。来源：官方文档 §25.1（postgres.cn），非渡一课程内容。

基本命令

# 备份（纯文本，输出到标准输出）
pg_dump dbname > dumpfile

# 备份（custom 格式，支持细粒度恢复）
pg_dump -Fc -f backup.dump dbname

# 恢复
psql dbname < dumpfile            # 纯文本
pg_restore -d dbname backup.dump   # custom 格式
pg_restore -d dbname -t 表名 backup.dump   # 单表恢复

# 整个集簇（含角色与表空间）
pg_dumpall > cluster.dump

原则速记

官方思想
SQL 命令文件，回放后重建与转储时状态一样的数据库。
客户端应用
可在任何能访问库的远端主机备份；需读权限，全库备份几乎总用超级用户。
备份三件套
异机存储 + 失败告警 + 恢复演练（能回放才算数）。
选型
常规用逻辑转储（pg_dump）；超大库/短窗口上文件系统级或 PITR（§25.2/25.3）。
