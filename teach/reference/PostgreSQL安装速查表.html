PostgreSQL安装速查表

配合《PostgreSQL 安装互动教学课程》与《01.PostgreSQL安装》使用。建议打印一份放在手边。

安装四步（Docker 方式）

# ① 装 Docker Desktop → Settings → Docker Engine 加镜像加速器
"registry-mirrors": ["https://docker.m.daocloud.io", "https://docker.1ms.run", "https://docker.aityp.com"]

# ② 拉取镜像
docker pull postgres:16

# ③ 启动容器（密码必填 + 端口映射 + 数据卷持久化）
docker run -d \
  --name pg16 \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=123123 \
  -p 5432:5432 \
  -v "你的本地路径:/var/lib/postgresql/data" \
  postgres:16

# ④ 进入容器验证
docker exec -it pg16 psql -U admin -d admin

docker run 参数表

参数说明
-d后台运行容器
--name pg16容器命名 pg16
-e POSTGRES_USER=admin超级用户名（默认 postgres）
-e POSTGRES_PASSWORD超级用户密码（必填）
-p 5432:5432宿主机端口:容器端口
-v 本地:容器路径数据卷持久化，删容器不丢数据

psql 验证命令

命令作用
\conninfo查看当前连接信息
\l列出所有数据库
SELECT current_user;查看当前用户
\q退出 psql

pgAdmin（可选）

docker run -d \
  --name pgadmin4 \
  -e PGADMIN_DEFAULT_EMAIL=admin@qq.com \
  -e PGADMIN_DEFAULT_PASSWORD=123123 \
  -p 5050:80 \
  dpage/pgadmin4
# 浏览器访问 http://localhost:5050

核心要点

  • PG 定位：开源免费 · 原生 ACID · MVCC 并发 · Extension 生态 · JSONB · 最贴近标准 SQL
  • 镜像加速器：只加快拉取镜像，与 SQL 性能无关
  • 数据持久化：不挂卷 → 删容器丢数据；挂卷 → 数据在宿主机
  • 端口映射：左宿右容（-p 宿主机:容器）
  • psql：\ 开头是元命令（客户端处理），SELECT 才是 SQL
