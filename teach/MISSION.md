# Mission: 为 Python 课程站点生成「协程」互动教学课程

## Why

用户的文档站（doc.zhangpan.online）正在沉淀一套 Python 语言核心课程。《24.协程》这一章讲清了协程对象、Task、事件循环与 `asyncio.run`，但只有讲解没有练习——读者（和用户自己）缺少一个用「即时反馈」检验理解、把知识转化为技能的环节。

## Success looks like

- 《24.协程.mdx》文档末尾出现课程入口，点击即可跳转到互动课程页面（通过 `static/teach/` 发布，随站点部署）
- 课程是自包含的 HTML 页面，样式（course.css）与测验组件（quiz.js）可复用于后续章节
- 测验覆盖文档核心概念：协程对象、`await`、Task 与 Future、事件循环、`asyncio.run`、执行顺序预测，每题有即时反馈与解释
- 有配套《协程速查表》参考文档（术语表 + 语法速查 + 线程/协程对比），可打印
- 读者与用户都能在 5–10 分钟内完成课程并感受到收获

## Constraints

- 课程内容为中文，风格与文档站一致
- 受众：网站读者 + 用户自己（两者兼顾）
- 范围：先只做协程一章；效果满意后再考虑后续章节
- 内容严格落在《22.事件循环》《23.Future类》《24.协程》已覆盖的知识范围内（ZPD），不引入 asyncio 高级话题

## Out of scope

- 其它章节的互动课程（待本次效果评估）
- asyncio 高级话题：`TaskGroup`、`gather`、超时/取消、异步生成器、`trio`/`anyio`、`uvloop`
